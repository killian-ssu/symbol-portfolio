# 结构

- `design/current.json`：当前策划文档及分组。
- `design/catalog.json`：包含历史来源的完整目录。
- `design/sources/`：公开阅读版 Markdown。
- `scripts/build-design.py`：生成当前阅读页、策划首页和历史目录；依赖见 `scripts/requirements-design.txt`。
- `design/docs/`：当前与历史阅读页；旧路径保持有效。
- `design/archive.js`：历史检索、旧 URL 兼容及阅读目录。
- `design/archive.css`、`design/planning.css`：基础视觉与策划阅读布局。
- 根 `index.html`、`styles.css`、`app.js`、`reader.html`：视觉作品集。
- `play/`：已有游戏发布构建，由各游戏交付流程维护。
