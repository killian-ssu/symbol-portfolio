1. 基础规则定案#

一句话解释：商人用五朵魔法蘑菇编成一道孢子咒，魔法按排列依次经过每朵蘑菇，逐渐增强，最后由第五朵释放，击破前方阻碍。

玩家规则只使用下列常见词：

名词定义
初始孢子每轮计算开始时的分数，基础为 10
当前分数按 1—5 号位置依次传递的唯一分数
蘑菇孢子第 1 朵、异类相接以及其他明确效果每次加上的数值，基础为 10
同类相接这张蘑菇与上一张同类；每次行动使当前分数 ×2
异类相接这张蘑菇与上一张不同类；每次行动使当前分数 +蘑菇孢子
行动次数此处完整执行基础规则的次数；候选上限为 8
位置标签命中蘑菇牌上的数字与它所在的位置相同

单次行动的伪代码：

current_score = initial_spores

for slot in 1...5:
  actions = 1 + 此处永久行动 + 道具临时行动 + 标签行动 + 工具行动
  actions = min(actions, 8)

  repeat actions times:
    if slot == 1:
      current_score += mushroom_spores
    else if 这张蘑菇与上一张同类:
      current_score *= 2
    else:
      current_score += mushroom_spores

round_score = current_score after slot 5

额外行动不新建批次，不回传，不改成只加固定分。此处是同类相接时，每次额外行动都再 ×2；此处是异类相接时，每次都再 +蘑菇孢子。

普通位置标签命中时使此处额外行动 1 次；炫彩标签额外行动 2 次。标签因此同时读取此处的相接关系和已有构筑，而不是另外发放一笔无关分数。

2. 分层成长结构#

v0.4 不把同类和异类分成两个流派，而是让一套构筑可以在不同层互相放大：

  1. 成长来源：过关、工具使用、位置标签命中、换货、混合排列和保留金币，每次只使蘑菇孢子 +4/+5。
  2. 成长自增：活性菌种首次只 +4，但每触发一次，它以后的提高数值再 +4。
  3. 阶段触发放大：月相菌钟使其他“过关时提高蘑菇孢子”的道具再触发 1 次，但不递归触发自己。
  4. 成长转行动：孢子计数盘读取“蘑菇孢子永久提高的次数”，每 4 次使一个位置的行动次数永久 +1。
  5. 排列兑现：玩家再根据手牌、标签和道具位置，决定把多次行动用于异类累加、同类共鸣，或在一轮中先累加后共鸣。

这个结构对应“小数值→更多成长触发→更大的每次成长→更多行动→排列放大”。百万分来自多层互相成就，不来自某件道具直接 +500/+1000。

4. 三档难度曲线#

原运行时曲线 250 / 400 / 650 / 1,000 / 2,500 / 4,000 / 6,500 / 10,000 / 25,000 / 40,000 / 65,000 / 100,000 / 250,000 / 400,000 / 650,000 / 1,000,000 在第 3—6 个场景就连续筛掉尚未购入成长引擎的构筑。后续 250…1,000,000 的机制验证曲线虽让成熟样例越过百万，但整局通关率仍只有 0.8%。它只是上限证明，不再作为玩家难度候选。

当前三档使用同一套蘑菇、道具、位置标签、工具与商店规则，只改变场景目标与最多轮数：

难度最多轮数16 个场景的目标分数解锁与用途
简单5200 / 250 / 300 / 350 / 420 / 500 / 600 / 720 / 900 / 1,100 / 1,400 / 1,800 / 2,500 / 4,000 / 7,000 / 20,000首次远行默认使用；先让玩家看到构筑成熟和爆分
标准4200 / 260 / 320 / 380 / 450 / 550 / 650 / 800 / 1,000 / 1,250 / 1,600 / 2,200 / 3,500 / 6,500 / 12,000 / 50,000通过简单后解锁；作为长期基准
困难4250 / 340 / 420 / 500 / 620 / 780 / 1,000 / 1,300 / 1,800 / 2,600 / 3,800 / 5,500 / 9,000 / 12,000 / 20,000 / 250,000通过标准后解锁；检查更稳定的成长与兑现

第一次进入不先弹出三档选择，直接使用简单。通过后才逐档解锁，避免新手在还不理解构筑前先误选高难度。百万分不再是首次通关的强制门槛，而是所有难度都可追求的超额爆分里程碑。

下表使用 8,000 组相同随机种子比较三档。模拟代理会同时考虑即时分数、位置标签、永久成长、道具条件和下一张准备；这是同模型内的相对校准，不是真实新手胜率预测。

难度通关率抵达成熟阶段进入最后一章抵达最终场景成熟构筑体验率
简单31.8%96.1%73.1%49.5%54.3%
标准12.0%80.8%53.0%26.0%40.5%
困难3.7%50.9%23.7%12.4%21.7%

“成熟构筑体验”定义为：进入最后一章，且曾经达到单位置 5 次行动或蘑菇孢子至少 100。模拟器另单独记录单轮破万、破 10 万与破百万，不再把“少数胜局最终分很高”当成普通玩家已经体验过爆分。

指标8,000 局结果解读

开局 / 成长 / 成熟28.5% / 30.0% / 32.1%成熟比开局高 3.6 个百分点，尚差 0.4 个百分点达到原 4 点增长目标

尚有两个不应被通关率掩盖的边界警告：标准难度的成熟期有意义出牌率比开局高 3.6 个百分点，仍差 0.4 个百分点达到原定 4 点目标；简单难度的异类弹簧成熟占比为 66.1%，高于 65% 警戒线 1.1 个百分点。这两项保留为实机前的道具稀有度/效果复核，不通过再压低目标或暗中发放其他强件来掩盖。

位置标签不是单纯的强度包。在标准曲线中，启用标签的通关率约为 12.0%，禁用标签约为 11.5%；相同场景对照中，标签使有意义出牌率加权提高 1.5 个百分点。它主要在成熟期提供排列维度，而不是“买了就自动提高胜率”。

成熟功能组合前六为：行动+位置标签 24.9%、行动+排列 17.6%、成长+位置标签 13.9%、行动+成长 11.9%、行动+孢子数值 5.2%、行动+工具 5.1%。这些是远行结束后的事后归纳，不是预设流派。

6. 成熟组合样例#

6.1 孢子培育，双位共鸣：1,561,600#

  • 道具：活性菌种、月相菌钟、菌丝结、4 号孢子计数盘、5 号轮转菌床。
  • 成熟状态：蘑菇孢子由多次 +4→+8→+12…… 与阶段额外触发累计到 505；4 号位置行动 4 次，5 号位置行动 6 次。
  • 排列：A-B-C-C-C。
  • 过程：前三朵先把当前分数累积到 1,525；4 号位置连续共鸣 4 次到 24,400；5 号位置再共鸣 6 次。
  • 结果：1,561,600。

6.2 标签供能，连续行动：424,320#

  • 道具：生长标记、数字菌谱、接续标记、2 号扩散标记、5 号汇聚标记。
  • 成熟状态：蘑菇孢子 310；1/2/3/5 号标签命中。
  • 排列：A-B-B-C-C。
  • 过程：标签命中既提高蘑菇孢子，又让当前和下一个位置多次行动；3 号位置共鸣 3 次，5 号位置共鸣 5 次。
  • 结果：424,320。

6.3 工具循环，局部连发：128,000#

  • 道具：工具菌株、采样菌袋、工具培养皿、4 号工具弹簧、5 号同类弹簧。
  • 成熟状态：通过实际使用工具把蘑菇孢子提高到 330；本轮使用 3 张工具。
  • 排列：A-B-C-C-C。
  • 过程：4 号位置行动 4 次，5 号位置行动 3 次；工具同时是长期成长来源和本轮行动来源。
  • 结果：128,000。

6.4 初始孢子，长段共鸣：4,218,880#

  • 道具：年轮册、双生菌盖、3 号共生孢囊、4 号轮转菌床、5 号共鸣回响。
  • 成熟状态：年轮册通过每打出 10 张牌 +10 累计，再被双生菌盖放大，本轮初始孢子为 1,020。
  • 排列：A-A-A-A-A，4/5 号标签命中。
  • 过程：4 号和 5 号各行动 5 次，结果来自长期 +10 成长与末段共鸣的组合。
  • 结果：4,218,880。

7. 实现状态与下一步#

v0.4 已作为一次跨层迁移进入正式运行时：

  1. 玩家名词已迁移为“初始孢子 / 蘑菇孢子 / 行动次数”，稳定道具和蘑菇 ID 保持不变。
  2. Core 输出每次行动的完整轨迹；标签、工具和成长行动都重复此处基础规则，不新建分数批次。
  3. 42 件道具、商店金币、购买/出售/换货/离开、普通与彩色位置标签、8 次行动上限已由正式 JSON 与 Core 执行。
  4. 已选难度、16 个目标、最多轮数、商店与标签状态进入运行快照；最高已通过难度进入档案。
  5. UI 只消费 Core 状态和轨迹；商店在局内主界面连续购买，安装标签时使用原地蘑菇选择态，不另建 Dialog。
  6. 下一步是实机分别验证通关率、抵达成熟阶段、商店决策频率、成熟构筑体验、单轮破万和百万里程碑，不再只报最终胜负。
