幽灵白盒版规则

状态：当前已实现规则，并接入 2026-08-26 版正式背景、五种幽灵、一体猎手小猫、飞弹和六张天赋图标。

核心循环#

  1. 幽灵先处于低透明度虚化状态，此时不可瞄准、不可受击，近战幽灵也不移动。
  2. 幽灵显形后开始移动或准备攻击，并成为可瞄准目标。
  3. 玩家按住战场进入子弹时间，耐力持续消耗；没有可选目标时不会启动专注或消耗耐力。
  4. 准星完成后留下标记并继续寻找目标。玩家松手或耐力耗尽时，标记优先按即将接触玩家的威胁顺序结算。
  5. 标记完成后不会被虚化吞掉；攻击前摇可以继续推进，但已承诺的命中仍会兑现。

耐力与瞄准#

  • 耐力是唯一的索敌资源，HUD 不显示弹药，也不存在累计锁定容量。
  • 基础耐力为 2.7秒，非专注状态以 1.25秒/秒 恢复；至少有 0.7秒 耐力才可开始专注。
  • 基础锁定一只需 0.52秒，满条持续长按在目标充足时可锁约五只；这是耐力自然消耗的结果，没有额外锁定上限。
  • 玩家本次能累计多少标记，只取决于按压时长、耐力、瞄准速度和场上显形目标数。
  • 基础同时只有一个准星工作；瞄准卡达到 Lv.4、Lv.8 时分别提升为两个、三个并行准星。
  • 并行准星数不是锁定上限。一组准星完成后会继续并行寻找下一组目标。
  • 专注时世界移动为正常速度的 26%，敌人的显形/攻击机会时钟为 62%，生成节奏为 72%。

幽灵状态#

状态表现可瞄准行为
虚化低透明度冷色轮廓否停止行动，等待下一次显形
显形中透明度由低到高否只做短暂入场过渡，不再钻洞
显形完整实体是近战移动，远程进入攻击节奏
预警红色感叹号、脉冲是攻击倒计时，可由实际命中打断
重新虚化透明度降低否返回虚化等待

瞄准完成只代表“已标记”，不当场打断攻击。玩家必须及时松手，让射击在预警结束前真正命中。攻击已经飞出后，攻击物仍可单独瞄准清除。

四种常规幽灵#

  • 普通幽灵：近战单位，显形后向玩家接近，进入距离后以红色预警蓄力抓击；一击击破。普通/护甲基础移动速度为 72 / 57.6，随关卡每关增加 2.5%（最多20%）；出手和命中必须在玩家中心 92 距离附近，配合落在角色身上的抓痕。
  • 远程幽灵：基础远程单位，显形后蓄力，第二、三关显形后约 0.63–0.74秒 开始前摇，前摇约 0.79–0.83秒；后期逐步加快。瞄准和完成标记不会停止攻击计时。每次攻击严格只生成一枚攻击物；不承担连发或散射能力，为后续远程怪保留空间。
  • 护甲幽灵：近战单位，带两层可见护甲。普通命中先逐层破甲，穿透高等级可一次击穿额外护甲层。
  • 法术幽灵：远程场面单位，长前摇结束后错峰生成三个咒术攻击物；在预警阶段击破可取消施法。

所有危险行动使用威胁预算控制：普通/远程占 1，护甲/法术占 2。关卡预算为 2 / 1 / 2 / 2 / 3 / 4 / 4 / 5 / 6；Boss 关总预算 5，其中 3 点保留给 Boss，随从最多占 2 点，避免画面退化为持续清理大量弹幕。

索敌优先级#

自动索敌同时检查距离、攻击方向与预计命中时间（远程前摇还需加上弹道飞行时间）：

  1. 预计1.25秒内命中玩家的攻击；
  2. 已贴近玩家的近战（抓击距离外再留42的预备区）；
  3. 预计3秒内命中的飞弹；
  4. Boss 弱点；
  5. 其余朝玩家飞来的攻击、远处预警，再到普通显形目标。

新近身威胁可以抢占尚未完成的准星，原目标保存本次长按中的进度。已经完成的标记保留；松手和每次实际开火前都重新按紧迫程度排序。快要完成的瞄准只有在仍来得及处理新威胁时才先做完。飞离玩家或轨迹不会碰到玩家的子弹不抢占紧急优先级。导弹改追也使用相同排序。

六张升级卡#

卡牌已实现成长卡面状态
耐力每级上限 +0.22秒、恢复系数 +0.04，最多强化10级被动，无冷却
瞄准首级速度+10%，后续每级乘1.025；Lv.4/8 将并行准星提升到2/3被动，无冷却
爆炸首级半径175、冷却4.8秒；每级半径+12、冷却−0.22秒；光波匹配范围整卡圆角裁切冷却遮罩
穿透光束在命中目标后方追加2—5个目标；逐级增宽，7级额外破甲整卡圆角裁切冷却遮罩
导弹主齐射后扇出3—6枚追灵导弹，弧线追踪，可改追整卡圆角裁切冷却遮罩

六种能力均最多强化10级。普通/紫/红升级卡分别强化1/2/3级。每局70%概率在第7—9关中掉一张红卡，最多一张；第3关起非红卡约22%为紫卡。

六张能力卡在局内拥有固定卡位，右下角数字表示等级。首关提供爆炸/导弹，第二关首次提供瞄准/穿透；后续优先提供已拥有卡的升级，帮助构筑成形。

十关内容#

  • 第1关教学普通幽灵与显形规则，首只保留单独教学，完成后进入4–6只的敌群压力。
  • 第2关加入基础远程幽灵，最多同时1只远程、1枚敌弹，保留普通怪占多数的过渡。
  • 第3关加入护甲幽灵，同时最多1只护甲、1只远程，避免群攻刚起步就被多层护甲卡住。
  • 第4关加入法术幽灵，三种特殊怪各最多1只；第4—5关普通怪占65%，让群攻开始发挥。
  • 第6关普通怪占48%，逐步转向混编；第7—9关护甲/远程/法术占比为29%/27%/20%。第9关弹速提高到365—410，匹配更多准星和辅助攻击。
  • 第10关为 Boss 战。
  • 第1–9关击破目标：12 / 16 / 20 / 28 / 40 / 54 / 72 / 88 / 108；同时在场上限：6 / 6 / 7 / 10 / 13 / 17 / 23 / 27 / 30。

掉落与连续强化#

  • 每只击破怪掉1金币，约0.26秒弹起落地，停留0.35—0.55秒后飞入金币框，飞行0.42—0.50秒；到达时数字才增加。
  • 第1—9关分别掉 1 / 1 / 2 / 2 / 2 / 3 / 3 / 4 / 4 张卡，分散在关卡进度中。卡片落地0.45秒后飞入金币下方卡区。普通掉落的队列额外等待最多0.14秒。
  • 最后一只怪击破时立即收拢所有奖励，取消落地/排队等待，已在飞行的也加速；测试中剩余奖励约0.4秒收完，约0.5秒进入关间状态，再用0.28秒抽卡进入选择。清场清除敌弹并结束无目标长按，每张卡提供一次二选一，全部用完才开始下一关。
  • 地面掉落归属场景地面层，位于敌人和子弹时间遮罩之下，附带小阴影；只有离地飞向HUD时才移入前景，保持世界坐标连续。
  • 暂停冻结收集；重开取消旧局在途回调。

Boss#

  • Boss 本体不可直接锁定，初始有三枚可锁定封印和九格生命，开场携带十只小怪。每枚封印有两层光环，每次命中削一层；7级穿透可一次击破两层。
  • 部位命中不再反复打断 Boss。它用紫色咒环表达不可打断的蓄力；红色感叹号仍只代表普通怪的可打断攻击。
  • 三枚封印拆完，Boss 完成一次反击后才暴露三枚弱点。清完一组弱点后重建三枚封印，最快也要三轮反击才能击破。
  • 每次行动发射分离起点的咒弹，随九格生命降至六格、三格从3发增强到4发、5发，隔次行动追加召灵。行动间隔1.45/1.20/0.95秒，蓄力0.95/0.85/0.75秒，均受机会时间缩放影响；场上Boss咒弹最多10枚，小怪弹最多8枚。
  • 战斗中持续补充随从，三段目标数量为10/14/18只，总上限18只，不计入关卡击破目标。随从使用第九关的显形周期与365—410弹速，不使用Boss本体的独立计时。暂停与齐射冻结补怪，子弹时间放慢补怪。
  • 弱点窗口为4秒，结束后保留已造成的生命进度；正在瞄准或已经承诺的弱点命中会兑现后再收回。
  • 弱点显露期间Boss仍会攻击；拆封印、打完弱点都不会取消正在进行的蓄力，已标记弱点仍兑现命中后才收回。

HUD 与反馈#

  • 左上为三颗心和实际收集金币。升级卡库存位于金币框下方，左边缘与币框对齐，按普通、稀有、传说纵向排列；仅显示数量大于零的种类，用完一类后下方行补位，全部用完隐藏整个库存。金币接收时的弹跳不影响库存位置。顶部居中为关卡数，右上为设置按钮，耐力条位于关卡下方。
  • HeartsLabel、RemainingLabel、LevelLabel、PauseButton、StaminaProgress 和 OwnedUpgrades 都保留在游戏 Prefab 中作为可拖动锚点，运行时美术会跟随这些位置。
  • 耐力正常填充为薄荷绿，低耐力变红，与地面保持对比。
  • 专注中显示当前累计标记数 ×N，但不把它包装成弹仓或容量。
  • 红色感叹号只表示可打断攻击。
  • 胜利文案为“子时已过”，玩家身份统一为“幽灵猎手”。

当前美术边界#

  • 五种幽灵显示尺寸为约 90–140；虚化时为低不透明度，完全显形时固定为原图不透明度。
  • 普通击杀用真正的圆点为主、少量星形为辅，16颗连续外抛粒子按幽灵配色表现，Boss28颗；速度、尺寸与消散时点错开；六帧彩色爆炸序列仅在爆炸天赋就绪时播放。
  • 远程、法术、Boss 分别使用独立飞弹，玩家额外导弹使用独立图标；敌方飞弹保留 MotionStreak 与轨迹光带；玩家普通射击使用三层渐尖的曲面光尾，去掉全长直条和实体残影。

2026-09-07 反馈优化#

  • 幽灵开始显形、开始虚化时，分别弹出一次“显形”“虚化”动效字：快速放大、回弹、略微上浮，约0.5秒淡出。平时不显示状态字，逐帧更新不会重播，身体完成显形或进入虚态也不重复提示；红色感叹号仍表示攻击前摇。连击保留固定位置的 ×N。
  • 普通击杀粒子约0.50—0.89秒，单颗尺寸约16—36，扩散速度比上一版提高约23%；枪口、光尾、导弹与命中主体放大约25%。粒子约1/4较实、1/2半透、1/4轻薄，分别淡入与淡出；六帧爆炸主体约0.40秒，扩散中逐渐消散。末次击杀让回收与击破同时播放，不用装饰粒子的剩余寿命阻塞关间切换。
  • 冷却遮罩与卡片尺寸、位置完全重合，用卡底原图透明轮廓裁切，覆盖边框和图标；原生径向填充从十二点方向顺时针恢复亮度。等级始终在遮罩上方，冷却完成遮罩完全消失。
  • 移除怪物或敌弹时同步移出连射队列；开火前先清理失效目标再按威胁排序，范围击杀和导弹不能留下已销毁目标阻断连射。
  • 暂停、胜利、失败采用同套独立 Prefab 面板；根节点不再使用半透明 Sprite，遮罩独立为兄弟节点，文字与面板保持完全不透明。
  • 这是一轮针对试玩反馈的调参，实际通关难度与长局疲劳仍需后续试玩校准。验证范围见 COMBAT_TUNING_2026_09_07.md。
