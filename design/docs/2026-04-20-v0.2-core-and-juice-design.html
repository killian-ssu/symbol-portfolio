档案说明

这是 2026-09-19 从工程收录的文本，可能包含后来补写的注释。正文中的“当前”“已实现”保留原有语境，不代表本站试玩版已逐项复验。

1. 核心机制：万能牌 (Wildcard) 实装#

根据 GDD 设计，我们将在本版本正式接入万能牌，并略微扩展其能力，使其更符合“爆分构筑”的预期爽感。

1.2 万能牌定义与判定#

  • 定义：万能牌可以充当任意花色与任意点数（GDD中最初建议仅任意花色，但为了提升顺子和同点的容错率，建议扩展为双向万能）。
  • 底层数据 (PokerCard)：在原有的扑克牌数据结构上，增加 isWild?: boolean 字段。
  • 消除算法 (MatchResolver)：
    • 同色判定：万能牌可以与任何花色组队。
    • 同点判定：万能牌可以与任何数字匹配（如 7-万能-7 算作 3 张 7）。
    • 顺子判定：万能牌可以填补任何点数空缺（如 4-万能-6 算作 4-5-6 顺子）。

1.3 视觉表现与产出#

  • 产出途径：万能牌算作工具牌的一种，产出途径和概率与普通工具牌完全一致（通过回合结算后的额外发放机制进入手牌区）。
  • 使用方式：虽然是工具牌，但它可以像扑克牌一样拖放到格子里参与消除。
  • 开局随机掉落：在关卡初始化的 fillInitialBoard 阶段，有较小几率直接在格子区刷出万能牌。
  • 视觉特征：万能牌会有一张专用的、区别于普通牌的炫彩/特殊卡牌背景图（SpriteFrame），或者在卡牌上增加特效光环。

2. 视觉表现与爆分爽感 (Juice & Game Feel)#

消除游戏的核心爽点在于视觉反馈。我们将把之前瞬间发生的底层数据变动，转化为流畅且充满力量感的动画。

2.1 卡牌物理下落动画 (Gravity Tween)#

  • 触发时机：补牌（从缓冲行下落）和重力下落（行/列消除导致的下移）。
  • 表现：不再是直接修改坐标（setPosition），而是使用 Cocos 的 tween，让卡牌从上方的 from 坐标，带有回弹效果（EaseBounceOut 或 EaseBackOut）地砸向 to 坐标。

2.2 消除与爆炸特效 (Match Tween)#

  • 触发时机：当满足三消/四消/顺子时。
  • 表现：被消除的卡牌不会立刻消失，而是先瞬间**微微放大（Scale Up）以示高亮，随后快速缩小至 0（Scale Down）**并伴随淡出（Fade Out），最后才销毁节点。

2.3 得分飘字 (Score Floating Text)#

  • 触发时机：每次消除一段卡牌时。
  • 表现：在被消除卡牌的中心位置，生成绿色的动态飘字（如 <color=#00FF00>+240</color>）。飘字会向上漂浮并逐渐透明消失。

2.4 连击特效与震动 (Chain Popups & Camera Shake)#

  • 触发时机：同一回合内，重力下落引发了第 2 次或更多次的消除（即 ChainIndex >= 1）。
  • 表现：
    • 在屏幕显著位置（如 HUD 旁或盘面中央）弹出巨大的提示，例如 "Chain x2!", "Chain x3!"，字体带有弹性缩放效果。
    • 盘面微震：当发生连击时，给整个 BoardRoot 节点施加一个极短的位移震动（Shake），强化爆分的打击感。

3. 异步流程控制重构 (Async Resolution)#

核心难点与技术方案： 目前的 GameSession.ts 消除逻辑是一个瞬间执行完的 while(true) 同步死循环。 为了让动画有时间播放，我们需要将它重构为基于 Promise 的异步流程（async/await）：

  1. 判定消除 -> 播放消除动画 (await)
  2. 计算分数 -> 播放飘字 (await)
  3. 结算重力 -> 播放下落动画 (await)
  4. 再次判定消除（循环）...

4. 后续预留#

  • 本版本暂不实装复杂的 Boss 关卡机制（如禁用某种花色），优先确保常规流程的“手感”打磨至完美。
  • 工具牌（改色、删牌等）的 UI 拖拽交互将在万能牌与动画系统跑通后进行实装对接。
