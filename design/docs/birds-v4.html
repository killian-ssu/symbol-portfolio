档案说明

这是 2026-09-19 从工程收录的文本，可能包含后来补写的注释。正文中的“当前”“已实现”保留原有语境，不代表本站试玩版已逐项复验。

原文件未署完整写作日期。版本顺序可供追溯，具体日期未补写。

状态：鸟类主题历史方案，仅用于设计追溯；当前实际规则以 PROTOTYPE_RULES.md 为准。

一、版本结论#

v0.4 不直接扩成十关，也不加入局外成长。版本目标是验证两件事：

  1. 在完全自动锁定的前提下，不同敌人组合能否真正改变玩家“继续按住”还是“立刻松手”的判断。
  2. 每次二选一升级，能否在随后两波内被玩家直接看见并感受到，而不是只改变后台数值。

版本规模建议从三关扩为五关，形成约 4—6 分钟的一局。同步制作一套代表性场景、角色、敌人、爆破和声音样板，但不批量生产十关美术。

二、体验目标#

玩家首先注意到#

  • 长按后整个场景进入明显的灰化、减速、镜头推进和声音降速状态。
  • 准星自动选择最危险目标，不需要移动手指寻找目标。

玩家接下来想做#

  • 观察场上还能否再锁一个目标。
  • 在“多锁一个形成更大齐射”和“先拦下临近弹丸保命”之间决定松手时机。

一局的情绪节奏#

观察来敌 → 长按蓄势 → 威胁逼近 → 决定松手 → 快速齐射 → 连续爆破 → 二选一强化 → 下一关立刻感到变化

三、保持不变的核心规则#

  • 竖屏、角色固定、三颗心。
  • 只有长按和松开，不加入移动、拖动准星与弹药库存。
  • 自动锁定，来袭弹丸优先于鸟。
  • 固定敌人编排，清场后换波，不使用倒计时通关。
  • 锁定和齐射属于不可截断的完整收益段。
  • 每关结束二选一，分数与连击不作为通关条件。

五、敌人设计#

敌人不能只更换颜色和速度。每一种都必须改变长按或松手的判断。

1. 普通鸟#

  • 清楚的单次感叹号预警。
  • 发射一枚普通弹丸。
  • 作用：建立基本节奏，也是群体齐射的主体。

2. 快枪鸟#

  • 体型较小，使用紫红色羽毛和双感叹号预警。
  • 预警时间较长且清楚，但发射的弹丸速度很快。
  • 作用：迫使玩家提前注意威胁，减少无脑长按到专注耗尽。
  • 设计要求：快的是弹丸，不是完全无法反应的预警。

3. 连发鸟#

  • 体型较宽，枪口或喙部有两个依次亮起的发射点。
  • 连续发射两枚普通弹丸，间隔约 0.45秒。
  • 作用：制造最核心的松手判断——拦下第一枚立即开火，还是继续按住等待第二枚进入锁定范围。
  • 设计要求：第二次发射必须在视觉与声音上提前承诺，不能偷袭。

暂不加入护甲鸟、无害诱饵、二心伤害炸弹与 Boss。自动锁定尚未证明能良好处理这些目标，过早加入会把问题变成目标选择与例外规则。

六、五关节奏#

敌人类型、出现时间和方向使用固定脚本；只允许高度或间隔有很小的随机扰动，方便重复试玩与定位问题。

关卡波次单位数新内容主要判断
第1关2 / 3 / 4普通鸟与无文字教学学会按住、锁定、松手
第2关3 / 4 / 5快枪鸟看到快弹预警后提前准备
第3关3 / 4 / 4 / 5连发鸟第一弹后松手，还是等待第二弹
第4关4 / 5 / 5 / 6三类混编在鸟群收益与弹丸威胁间切换
第5关4 / 5 / 6 / 7高密度综合考核用四次强化完成最终齐射高潮

波次模板#

  • 铺场波：慢速普通鸟依次入场，鼓励长按积累三到四个标记。
  • 抢断波：鸟群形成后，快枪鸟的弹丸插入，迫使玩家提前松手。
  • 连发波：两只连发鸟错开射击，测试玩家是否理解第二发预警。
  • 混编波：普通鸟提供收益，快枪鸟和连发鸟负责打断贪心。
  • 高潮波：先提供一次四至五连的爽点，再用明确预警制造最后一次防守压力。

每关第一波承担“展示上一项升级”的职责，不在玩家刚选完强化后立刻塞入最危险组合。

七、升级系统#

v0.4 不扩大升级目录，先验证现有六项是否都能被玩家察觉。四次选择从未获得的升级中二选一。

升级验收规则#

  • 玩家选完后两波内必须存在一次自然触发机会。
  • 不依赖另一项升级才能首次生效。
  • 试玩后不展示升级文字，让玩家描述刚才发生了什么。
  • 如果多数玩家只能说“好像更强了”，但说不出变化位置，则该升级的表现未通过。

八、表现层样板#

美术最小交付#

  • 一张完成度较高的 720×1280 黄昏或夜幕防守场景。
  • 主角四个状态：待机、进入专注、快速连射、受击。
  • 普通鸟、快枪鸟、连发鸟各一套清楚轮廓。
  • 三种弹丸轮廓：普通弹、快速弹、连发弹；颜色不是唯一辨识手段。
  • 一套命中爆破、弹丸拦截、震荡波与五连高潮特效。

先用“场景＋角色＋一种鸟＋一次完整齐射”制作动态风格样板，通过后再扩另外两种鸟，避免只凭静态图批量生产。

子弹时间表现#

  • 用真正的场景灰化或低饱和处理替代单纯半透明遮罩。
  • 镜头推进保持轻微，HUD不随场景缩放。
  • 暗角只作为边缘气氛，不出现独立圆环或抢眼边框。
  • 锁定目标保持原有重点色，非目标轻微压暗。
  • 松手先恢复高对比色，再快速连射，形成“压住—爆开”的反差。

声音最小交付#

  • 一段 20—30秒 可循环背景音乐样板。
  • 一份正常速度与一份子弹时间低速、低通版本，可平滑切换。
  • 核心反馈音：进入专注、锁定推进、锁定完成、松手、连续五档枪声、鸟命中、弹丸拦截、受击。
  • 连续枪声的档位覆盖玩家感知的一整次齐射，不因目标类型重置。

九、界面调整#

  • 顶部保留关卡、波次、三颗心、专注和锁定容量，不增加总分。
  • 波次从大号文字逐步改成更轻的点阵或段落指示，减少顶部信息拥挤。
  • 连击数字保留为爽感反馈，但在没有连续命中时快速退场。
  • 第一局仍以手势和真实慢速弹丸教学；不增加规则说明页。
  • 新敌人第一次出现时，优先用轮廓、预警节奏和发射动作教学，最多补一句短提示。

十、试玩与数据验证#

试玩样本#

  • 至少 5名 没听过口头说明的新玩家。
  • 至少 3名 已玩过v0.3的玩家，用于比较内容差异与升级感知。

通过标准#

  • 新玩家中至少 4/5 在十秒内完成第一次有效长按与松手。
  • 至少 4/5 能说出“三颗心耗尽失败、清完敌人过关”。
  • 至少 3/5 会主动提到一次“想再锁一个”和“必须先松手保命”的权衡。
  • 快枪鸟和连发鸟的行为辨认率达到 4/5，且不是只靠颜色猜测。
  • 每项被选择的升级，至少 70% 的玩家能在随后两波内注意到其效果。
  • 已锁定齐射被换波或结算截断的次数必须为 0。
  • 首次完整一局目标时长为 4—6分钟。

建议记录事件#

  • 每次长按持续时间、手动松手或专注耗尽。
  • 一次齐射的锁定数、鸟与弹丸比例。
  • 弹丸命中玩家前剩余距离。
  • 每关受击数、失败波次与所选升级。
  • 快枪鸟与连发鸟出现后，玩家第一次松手发生在什么阶段。

十一、本版本明确不做#

  • 不扩成十关，不制作 Boss。
  • 不加入分数通关、金币、局外成长、任务与广告系统。
  • 不加入角色移动、手动准星、换弹与枪械库存。
  • 不超过三种敌人行为。
  • 不增加大量升级；先证明现有六项都能改变体验。
  • 不批量制作多场景；先通过一套动态美术和声音样板。

十二、制作顺序#

v0.4a：白盒内容版#

  1. 把鸟的生成配置改成可编排敌人类型、时间、方向和高度的波次脚本。
  2. 实现快枪鸟和连发鸟。
  3. 扩成五关、四次二选一。
  4. 为六项升级补齐明确的运行时表现。
  5. 完成第一轮内部节奏测试。

v0.4b：表现样板版#

  1. 替换一套代表性场景、主角和三种鸟。
  2. 完成真实灰化、镜头、暗角与齐射爆破。
  3. 接入背景音乐正常/低速版本和核心反馈音组。
  4. 完成陌生玩家试玩与数据记录。

只有v0.4证明敌人会改变松手判断、升级能被直接感知后，v0.5才扩展十关、精英敌人或Boss。
