1. 这轮要解决什么#

旧设计的问题不是“分数不够”，而是三种体验没有说成一条规则：

  1. 玩家看到同类伙伴越多，天然会追求更高倍率。
  2. 玩家把伙伴放进 1→5 的行动格时，又会感到道具应当向右逐段传导。
  3. 原目录把加分、道具复写、伙伴再行动、成长和倍率混在长条件句里，读完仍无法预测下一步。

v0.2 的统一回答是：伙伴组合决定本轮倍率，排列决定右侧传导的落点，道具把传导变成更多伙伴行动与可见养成，工具牌负责临场修型或点火。

右链不是唯一流派，而是所有构筑共用的空间语法。五连、四连、两对都可以使用它；区别在于玩家选择把有限的五个位置用来换更高的组合倍率、更多行动次数，或更快的探索值成长。

2. 固定术语与卡面语法#

术语固定含义
探索值伙伴每次行动提供的基础数值。
倍率本轮伙伴组合倍率，加上卡面明确写出的本轮/本局倍率。
此处这件道具所在的行动格。
右侧紧邻右边的一格；不存在右侧时，效果不生效。
A+N右侧伙伴额外行动 N 次。
R+N右侧道具额外触发 N 次，不产生伙伴行动分。

卡面写法必须遵守以下合同：

  • 伙伴探索值永久+2/+5/+10：增加该伙伴种类本局探索值，当前这次行动起就有效。
  • 伙伴本次行动探索值+2/+5/+10：只加给下一次指定伙伴行动，绝不伪装成永久成长。
  • 本轮倍率+0.1/+0.2/+0.5 与 本局倍率永久+… 必须写明时效。
  • 自动道具不写“再次触发”作为模糊动词；统一写成 伙伴行动次数+N 或 道具触发次数+N。
  • 每件道具的原始触发必须有价值。计数型成长可以附带在一个已经有效的基础效果之后，不能让第一次触发是空白。

2.1 伙伴组合#

伙伴组合条件倍率
单张五张伙伴均不重复×1
一对恰有一组两张相同伙伴×2
两对恰有两组两张相同伙伴×4
三连恰有三张相同伙伴×5
四连恰有四张相同伙伴×10
五连五张均为同一伙伴×15

组合按最高成立项识别。例如 鹰、鹰、鹰、狼、狼 是“三连”而不是“两对”；鹰、鹰、狼、狼、龟 是“两对”。“齐行”“队势”“未成”不作为玩家要学习的组合名称。

3. 一轮结算：先看到谁在动，再看到什么被传过去#

行动格1 → 行动格2 → 行动格3 → 行动格4 → 行动格5
每一格：收到左侧效果 → 原始伙伴行动（道具→伙伴得分）
       → 处理到达的A+N与R+N → 前往右侧
  • 伙伴额外行动仍会触发此处道具，再结算伙伴探索值；它才是爆分的主体。
  • 道具额外触发只触发道具，不直接得到伙伴探索值；它只承担“把右侧再点亮”的辅助角色。
  • 倍率道具每轮最多生效一次。复写可以让它被点亮，但不会让同一张倍率牌在同一轮无限叠加。
  • 每张成长道具每轮最多为同一种伙伴永久增加 20 探索值；每格每轮最多结算 40 次伙伴行动与 40 次道具触发。第 13 次起的同类事件合并播放。这两个上限防止数值和动画失控，而不是让玩家在每张卡上背额外条件。

4. 30 件候选道具#

6. 三条可玩构筑与实际事件量#

A. 右链养成（五连）#

手鼓 → 背包 → 风铃 → 木偶 → 木雕
 A+2    A+2    A+2    A+2/R+1  链尾永久+10
  • 行动次数按格变成 1 → 3 → 7 → 15 → 31。
  • 木偶送到右侧的 R+1 会额外点亮木雕，但木雕每轮对同一伙伴的永久成长上限为 +20；因此玩家看见的是“末端被养大”，不是无限增长的数字错误。
  • 成熟后的五连在第16关普通目标下三轮累计 1,317,735 / 1,000,000；“满载”终页目标 1,250,000 下同样三轮通过。

B. 两对调整（两对）#

手鼓 → 背包 → 双结旗 → 算盘 → 木雕
 A+2    A+2    A+3/+0.5  A+2/全体+2  链尾永久+10
  • 示例伙伴为 鹰、鹰、狼、狼、龟，基础倍率×4；双结旗把它变为本轮×4.5。
  • 行动次数为 1 → 3 → 7 → 22 → 40（上限）。它不是五连的降级版：两对更容易在手牌波动时保住，两种成对伙伴也能分别承接中段成长。
  • 第16关普通目标恰好在四轮累计 1,062,855 / 1,000,000 通过。若地点终页提前公开“满载”（目标+25%），四轮只有 1,062,855 / 1,250,000，因此应使用印章/网兜转成四连或五连；这是“提前公开终页后做准备”的压力，不是封锁右链。

C. 四连爆发（四连）#

手鼓 → 背包 → 算盘 → 木偶 → 木雕
 A+2    A+2    A+2/全体+2  A+2/R+1  链尾永久+10
  • 示例伙伴为 鹰、鹰、鹰、鹰、狼，倍率×10；允许保留一张异类伙伴，修型成本低于五连。
  • 行动次数为 1 → 3 → 7 → 15 → 31，但中段算盘把大量行动转成全体永久探索值。
  • 第16关普通目标四轮累计 1,303,760 / 1,000,000；“满载”终页也能四轮累计 1,303,760 / 1,250,000 通过。

7. 16关测算结论#

测算不是用“链路因子”估算，而是逐格回放原始行动、A+N、R+N、永久探索值、本轮倍率和每格事件上限。假设每页最多四轮；核心第五件道具在第8页开始稳定出现，而非第5页就理想凑齐。

构筑普通16关满载终页（第16关）结论
右链养成（五连）3轮，1,317,735 / 1,000,0003轮，1,317,735 / 1,250,000高上限、终局最快。
两对调整4轮，1,062,855 / 1,000,0004轮，1,062,855 / 1,250,000普通终局可过；满载需工具修型。
四连爆发4轮，1,303,760 / 1,000,0004轮，1,303,760 / 1,250,000稳定的终局保底路线。
纯探索值堆叠（反例）第13关失败，224,400 / 250,000未继续证明成长不能脱离行动链独立通关。

体验曲线由测算得到：第1～4页以 1～2 轮熟悉组合；第5～7页开始需要更好排列或更多轮数；第8页拿到完整链后出现一轮高爆发；第13页后目标暴涨，五连以三轮、两对和四连以四轮面对终局压力。这个曲线仍需要将来接入真实掉落概率、手牌随机与全部特别状况后再做 Monte Carlo 验证，但已经排除了“纯加分也能躺过”与“右链早期直接碾压后16关”的两种明显错误。

8. 地点终页的设计边界#

  • 每章入口提前公开终页的特别状况，玩家可为它选择组合与工具，而不是结算时被随机断链。
  • 不再使用“所有右侧道具触发次数-1”这种攻击底层语法的全局限制。若保留逆风，应改为一个公开连接本轮首次 A/R 减 1，玩家可通过重排绕开或用低价值节点承受。
  • “满载”作为纯目标+25%是可保留的终局压力；它鼓励两对路线在第16页改成四连/五连，却不让任何道具突然失效。
  • 随机变身、随机封锁和随机交换应改为提前公开目标；玩家需要解题，不该失去因果关系。

9. 给其他 AI 的生成约束#

新增道具前，先回答四个问题：

  1. 它在原始触发时立刻做什么？
  2. 它增加的是探索值、倍率、伙伴行动、道具传导、工具，还是明确的特殊规则？
  3. 它把价值留在此处，还是送到右侧？若送右侧，是否仍能由玩家看懂目标？
  4. 放进一个五格布局后，它让哪一格的伙伴行动更多，还是让哪一种伙伴永久变强？

禁止再产生这些写法：

  • “此道具再次触发时才有效”的空白初始卡。
  • 一张卡按三种牌型分别给三套不同次数的分支表。
  • 没有来源的“再次触发”。
  • 以全局扣除右侧触发来充当终页难度。

运行时实施前，需要把候选 ID 映射回现有稳定 ID、在 Core 中实现按格事件队列、补齐工具合法目标与测试；本轮没有修改 assets/resources/config/gameplay/、Core、Prefab 或 Cocos Inspector 参数。
