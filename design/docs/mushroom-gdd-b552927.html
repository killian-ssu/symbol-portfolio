1. 产品概述#

《远行商人》是一款轻量构筑爆分游戏。玩家将五色薯团地精伙伴牌放入 1—5 号行动格，让同一批宝贝依次经历加货、翻倍和道具加工，最后整批交付以达到路段目标。

核心决策是：三张伙伴手牌下，如何安排相同和不同的先后，并将五件简单道具放到能被后续运算放大的位置。

2. 单轮核心循环#

  1. 每轮入口生成基础底货 10。
  2. 伙伴手牌维持 3 张；打出 1 张就补 1 张。工具独立保留，与伙伴牌合计上限 6 张。
  3. 伙伴按 1—5 号位落位。前四张不计分，第五张落位后锁定本轮颜色序列。
  4. Core 先处理工具、构型道具和特别状况对五张牌的最终改动。
  5. 同一批货物从 1 号位加工到 5 号位：1 号每次加货；之后同色×2、异色+加货。
  6. 当前格的所有额外行动在原地完成，然后货物只向右移动一次。
  7. 5 号位货值一次性加入本关进度。达标即过关；未达标才清空伙伴进入下一轮。

3. 基础公式#

cargo = 10

for slot in 1...5:
  repeat action_count(slot) times:
    if slot == 1: cargo += load
    else if goblin(slot) == goblin(slot - 1): cargo *= 2
    else: cargo += load

round_score = cargo after slot 5

基础加货为 10；道具、工具、信条和成长可修改底货、加货、当前格货值或行动数。

排列运算本轮得分
AAAAA(10+10)×2×2×2×2320
ABCDE10+10+10+10+10+1060
ABBBC10+10+10→×2→×2→+10130

不再识别牌型，不再求五位伙伴分数和，不再存在道具向右发送触发或另建一批货物。

4. 伙伴牌、道具与工具#

  • 五种伙伴牌各5张，没有固定分数或个人能力；只通过颜色建立相同/不同关系。
  • 30 件道具分为基础件、成长引擎、兑现件和构型件；全局道具也占用一个道具位。
  • 当前格最多 10 次行动。额外行动重复当前格的 +加货 或 ×2，它不传货也不新建批次。
  • 8 张工具用于变色、接续上一张、换牌、定向找牌、增加底货、增加行动和复制即时道具/上一工具。
  • 道具成长状态跟随道具移动；替换或主动删除该道具时，其累计一同移除。

完整目录见 relic-tool-catalog.md 与运行时 JSON。

5. 路线、信条与奖励#

  • 四章、每章三层路段+一个终页的形式保留。
  • 六条启程信条分别支持首次相同、首次不同、多色底货、过关成长、章节工具和 5 号位压轴。
  • 奖励仍有均衡、道具、工具三种布局。引导候选补齐“基础→引擎→兑现→构型”，同时必须匹配玩家公开选择的路线标签；自由候选仍不受引导。
  • 第一次远行关闭信条、特别状况和补给改选，前七次道具奖励用固定顺序介绍底货、相同、成长、构型、关系阈值、货值阈值和压轴。

6. 特别状况#

  • 每章 5 条，共 20 条；稳定 ID、目标倍率、解除数量和额外候选奖励保留。
  • 效果已改为流水线事件：货值减半、某格行动/道具失效、交换位置、额外行动改为加货、工具限制和强制改色等。
  • 原始打出目标颜色用于解除状况；如在本轮计分前解除，本轮不再应用该限制。

7. 关卡与数值#

  • 16 关目标保留为 250、400、650、1,000 到 1,000,000；每关最多 4 轮、2 次伙伴手牌刷新。
  • 零道具 3,125 种五格颜色排列得分范围 60—320，中位数 70。
  • 第一次远行的同色教学策略纸面模拟通关率约 77%；六条定向成熟路线都能在百万目标下通关。
  • 后期会进入百万到千万数值，但不存在无限队列；Core 使用安全整数封顶并输出精度警告。

8. UI 与实现合同#

  • Core 输出初始货值、五格轨迹、每次行动、运算符、来源和最终货值；UI 只播放。
  • HUD 结算区只显示当前货值，不显示牌型或独立倍率区。加货用 +N，相同用 ×2，特别状况可显示“失效”或 ×0.5。
  • 额外行动继续在当前格播放；每格完成后才播放一次向右交接。
  • 远行手册的旧牌型页改为三条加工规则。视觉、时长、粒子、锚点和布局继续由 Prefab / Inspector 管理。

完整的 30 件道具、8 张工具、6 条构筑、20 条特别状况、表现分层、模拟方法和验收项见 potato-goblin-pipeline-design-v0.2.md。
