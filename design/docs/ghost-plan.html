档案说明

这是 2026-09-19 从工程收录的文本，可能包含后来补写的注释。正文中的“当前”“已实现”保留原有语境，不代表本站试玩版已逐项复验。

原文件未署完整写作日期。版本顺序可供追溯，具体日期未补写。

状态：核心功能白盒已落实。正式幽灵与猎手小猫美术尚未接入，当前暂用旧角色素材作为占位；实际运行规则以本文与 docs/PROTOTYPE_RULES.md 为准。

一、版本结论#

游戏正式名称改为《子时已到》。主题从牛仔小猫打地鼠调整为“幽灵猎手小猫在子时捕猎形态各异的小幽灵”，整体气质是可爱微恐，不依赖血腥、惊吓或重口表现。

本版不再继续围绕“子弹时间多锁几个、敌人弹丸多少”反复调数值，而是进行三项结构性改造：

  1. 删除子弹数量，只保留耐力作为长按索敌的唯一可见资源。
  2. 将成长从三项基础数值扩展为六张固定类别卡：耐力、瞄准、爆炸、穿透、导弹、保护罩。
  3. 将难度从“更多弹丸”改为“更多种可预判、可打断的敌人行动”，用四种幽灵与一个 Boss 建立行为差异。

玩家后期应该感受到的不是“我的子弹数变大了”，而是“我一松手，灵弹、爆炸、贯穿与背后飞出的导弹会形成一整段越来越华丽的猎鬼齐射”。

二、目标体验与节奏#

玩家第一眼看到#

  • 夜色里形态各异、若隐若现的可爱小幽灵。
  • 幽灵猎手小猫与幽灵的冷暖色形成明确对比。
  • 虚化是低透明度且不可锁定，显形后实体变亮，可立即瞄准。

玩家接下来想做#

  • 等幽灵显形，长按进入子弹时间，尽量多标记目标。
  • 看到红色感叹号时，判断是继续贪锁定，还是提前松手射击、打断危险行动。
  • 通过升级让同一次松手齐射产生完全不同的可见结果。

一局的情绪曲线#

  • 前期：读懂“虚化等待—显形锁定—松手收割”。
  • 中期：敌人不再只是面板目标，红色打断时机开始迫使玩家提前松手。
  • 后期：两至三种已成形升级在齐射中连锁爆发，同时玩家要在 Boss 部位、打断点、小怪与攻击物之间决定处理顺序。

三、基础操作与资源契约#

保留的核心语法#

  1. 玩家长按战场进入子弹时间，耐力持续消耗。
  2. 准星自动选择当前最值得处理的可锁定目标。
  3. 瞄准完成后形成一个已承诺标记，然后继续锁定下一目标。
  4. 玩家松手或耐力耗尽时，按标记顺序快速齐射。
  5. 已完成标记保留到齐射结束；幽灵不会在标记完成后突然虚化、吞掉玩家已承诺的收益。

删除子弹数量#

  • HUD 不再显示子弹图标或“可射几发”。
  • 不再存在玩家可见的锁定容量上限。只要仍有耐力和可锁目标，就继续瞄准。
  • 程序可以保留一个足够高的内部安全上限，用于防止异常循环，但不对玩家显示，也不参与常规平衡。
  • “同时瞄准数”定义为同一时刻并行工作的准星数：基础一次瞄一个，升级后可以一次同时瞄两个或三个。它不是另一个变相的子弹上限。
  • “本次总锁定数”不设独立数值；玩家按住多久、耐力剩余多少，就能继续累计多少个已完成标记。

长按边界#

  • 全场没有显形目标时，长按不进入子弹时间、不消耗耐力，只用轻量视觉反馈告诉玩家“尚未显形”。这样虚化时机才有意义，也不会白白烧掉整条耐力。
  • 耐力耗尽自动提交已有标记，不清空成果。
  • 射击、爆炸、穿透和导弹是同一个玩家感知的结算段，过关、暂停或时间状态不得在中间吞掉后续效果。

四、幽灵状态语法#

通用状态#

状态表现可否锁定规则
虚化25%—35% 透明度、冷色轮廓、轻微漂动否近战幽灵在虚化时不移动；不受射击、爆炸或穿透影响。
显形由虚到实，轮廓亮起转换完成后可幽灵开始移动、蓄力或施法。
行动完整实体是执行该敌人的普通行为。
预警头上红色感叹号与可读蓄力环是只表示“这个行动可被当前齐射打断”，不用作普通仇恨标记。
受挫短暂压扁、退后或飘散视怪物而定攻击被打断，护甲怪可在此时露出下一层。
重新虚化快速降低透明度否幸存敌人等待下一次显形行动。

打断契约#

  1. 敌人进入预警后才显示红色感叹号。
  2. 瞄准完成只是“已标记”，不会当场打断。
  3. 玩家必须在蓄力结束前松手，让射击真正命中打断点。
  4. 打断成功后，取消本次整组行动，而不是只少飞一枚弹丸。
  5. 如果打断失败，敌人的行动进入战场，玩家仍有二次处理机会，不会因一次没看见就必然掉血。

打断发生在“松手后命中”而不是“瞄准完成”，是为了保留核心的松手决策：玩家要在多贪一个标记和及时中断攻击之间做判断。

五、四种敌人#

敌人结构固定为两个近战、两个远程。近战压力通过“显形后接近”产生，远程压力通过“可提前打断的远程行动”产生，不让全部敌人都变成射子弹的面板。

敌人定位显形行为红色打断状态未打断的结果与构筑的关系
普通幽灵近战、一击击破每次显形向小猫推进一段近身后蓄力抓击对小猫造成一点伤害爆炸适合清理一群同时显形的普通怪
远程幽灵远程、一击击破在远处显形并蓄力射击前的短蓄力窗口每次只发射一枚攻击物提前击破可取消这次射击；攻击飞出后仍可紧急拦截，也为后续新远程怪保留设计空间
护甲幽灵近战、多阶段显形时携带两层可见护甲，并向小猫推进近身重击蓄力造成一点伤害并保留剩余护甲普通射击一次破一层并使其受挫；穿透可让溢出伤害继续作用于下一层
法术幽灵远程、场面制造者显形后开始召唤三个错峰的咒术物整段施法的长蓄力窗口三个咒术物依次进场，可分别锁定清除在施法完成前击破施法者，可取消未生成的整组咒术

关键区别不是攻击力和血量数值，而是玩家的处理方式：普通怪要阻止它走近，远程怪要处理单次射击，护甲怪要分阶段剥状态，法术怪则是“提前解决源头”与“事后逐个清理”的效率差。

六、Boss 方案：护甲、部位与打断#

Boss 不使用“一个大血条、锁上就一直扣血”，也不使用纯等待型无敌。它的受击机会必须由玩家打断或破坏部位主动创造。

阶段一：护甲封印#

  • Boss 本体暂不可锁定，身边有三个独立的可锁定护甲部位。
  • 每击破一个部位，Boss 丢失一层护甲，且当前行动被短暂打断。
  • 三个部位全部破坏后进入脆弱窗口。

阶段二：脆弱部位#

  • Boss 显露两至三个可同时标记的脆弱点，让一次齐射可以明确造成多段伤害。
  • 脆弱窗口结束后，Boss 恢复部分护甲，但不重置已经完成的阶段进度。
  • 整场 Boss 战建议经历两至三次“拆护甲—脆弱齐射”，不用单纯增加轮数拖长时间。

两种 Boss 行动#

  1. 召灵：Boss 蓄力召唤小怪。蓄力期的红色感叹号可被打断；成功打断则取消本轮未出现的小怪，并提前打开一个短脆弱窗口。
  2. 大型咒术：Boss 蓄力生成三个大型攻击物。蓄力时可整体打断；如果打断失败，攻击物会错峰进场，玩家仍可逐个锁定清除或交由保护罩抵挡。

Boss 同时检验三件事：是否能识别高价值打断点，是否愿意提前松手，以及是否能在脆弱窗口中让构筑形成大齐射。

七、难度建立方式#

不再使用攻击概率推动攻击欲望#

  • 每次有意义的显形都有行动目的：接近、远程射击、重击或施法。
  • 导演决定的不是“它攻不攻击”，而是“什么时候让它的危险行动进场”。
  • 后期通过行动组合、蓄力窗口错峰和护甲阶段增加难度，不以投射物数量作为主升级轴。

威胁预算#

建议把危险行动当作“威胁组”管理，而不是按单枚弹丸计数：

威胁组预算权重
普通幽灵近身蓄力1
远程幽灵单次射击1
护甲幽灵近身重击2
法术幽灵整组咒术2
Boss 大型咒术3
  • 前期同时威胁预算上限为 1，中期为 2，后期为 3；这些是首测候选值，不是最终平衡。
  • 前期同时最多一个红色打断点，后期最多两个；Boss 可用一个大打断点配一个小怪压力。
  • 远程幽灵每次固定一枚攻击物；多枚、散射或连发留给以后新增的远程怪，不叠加到这个基础单位上。

自动索敌优先级#

不再让“所有敌方攻击物”永久绝对优先。可锁目标按以下逻辑混合排序：

  1. 即将完成且能一次取消整组攻击的红色打断点。
  2. 按预计命中时间排序的已进场攻击物。
  3. 即将进入近战伤害距离的幽灵。
  4. 其他已显形幽灵。

这个优先级要用剩余蓄力时间、预计命中时间和近战距离共同计算，不能只靠目标类型写死。

八、六张升级卡#

六张卡的关系是：耐力和瞄准加强全局基础语法；爆炸、穿透和导弹改变输出表现；保护罩提供容错。它们是六个固定卡位，同类升级只增加右下角等级，不另外生成一排同名小卡。

卡牌首次获得后续成长冷却与触发直观改变
耐力耐力上限 +0.45秒，恢复速度 +8%每级继续增加同样两项，最高5级被动，无冷却蒙版可长按更久，两次齐射间恢复更快
瞄准Lv.1 瞄准时间缩短 12%Lv.2 同时瞄准数由1变2；Lv.3 再加速 12%；Lv.4 同时瞄准数由2变3；Lv.5 再加速 12%被动，无冷却蒙版多个准星同时工作，完成一组后再同时寻找下一组；累计总数仍只受按压时长和耐力限制
爆炸技能就绪时，本轮首个命中产生半径 110 的一次爆炸半径约 110→210，冷却约 8→6秒自动触发；只有命中有效目标后才进入冷却小幽灵群被波及，附近攻击物也可被清除
穿透技能就绪时，下一轮灵弹可穿过首个目标，命中射线窄带内的第二目标增加射线宽度、可贯穿数，并在中高级让伤害穿过护甲层自动触发，首测冷却候选 8秒灵弹形成长尾迹，串起对齐目标；护甲怪的多层状态可被压缩
导弹主齐射结束后，从小猫背后飞出2枚导弹导弹数 2→4，冷却约 10→6秒自动触发；场上无有效目标时保留就绪与主齐射完全不同的弹道，优先追踪未标记的高威胁目标
保护罩即将受到伤害且技能就绪时，自动抵消一次伤害冷却约 12→8秒，高级延长护罩窗口或提供第二层首版建议自动触发受击前立即张开、挡下攻击后破碎

保护罩首版建议做自动触发，因为长按瞄准已持续占用单指；如果再把保护罩做成可点按的唯一主动卡，会产生“正在长按时怎么同时点护盾”的输入冲突。如果后续确实要主动防守，应单独验证滑动手势或双指方案，不应直接混进本轮核心改造。

升级牌面与选择池#

  • 所有已获得卡在局内固定位置展示，右下角用数字显示当前等级。
  • 爆炸、穿透、导弹和保护罩使用黑色径向蒙版表示冷却进度；就绪时短暂发亮，不使用长文字提示。
  • 耐力与瞄准是常驻被动，不显示假冷却蒙版。
  • 爆炸、穿透和导弹没有有效目标时不消耗就绪次数。
  • 第1至2次升级保证至少出现一张爆炸、穿透或导弹，让玩家在第3关前就看到基础攻击以外的可见变化。
  • 获得某张战斗卡后，后续二选一尽量保证至少有一张是已有战斗卡的升级，不让成型路线只依赖连续随机命中。
  • 九次升级中，正常构筑目标是两至三张战斗卡成形，而不是六张卡各拿一级。

九、十关内容展开#

关卡新内容或组合教给玩家的事
1普通幽灵虚化时不可锁，显形时可锁，近身红色预警要提前松手
2普通 + 远程学会打断单次远程射击，或在攻击飞出后紧急拦截
3护甲幽灵有些精英怪一次齐射只剥掉一层状态
4法术幽灵长打断窗口可换取一整组减压
5普通 + 远程 + 护甲第一次三种职责混编，检查前半程构筑
6普通 + 法术近战接近与远程施法同时需要排序
7护甲 + 远程短打断与多阶段击破出现竞争
8护甲 + 法术决定是先压制近战高压目标，还是解决场面源头
9四种混编 + Boss 机制预演用强化法术怪预演一次大型可打断行动
10Boss + 受控小怪综合检验护甲部位、红色打断、脆弱窗口与构筑爆发

关卡数量增长只负责稍微增加节奏，主要难度必须来自“两种行动窗口如何叠加”。同一组合先单独教学，再混编，不能在怪物登场的第一关就配上另一个新机制。

十、HUD 与表现契约#

HUD#

  • 顶部只保留关卡、三颗心和耐力条，删除子弹数量。
  • 当前已标记数量主要由目标身上的标记反馈，必要时只在准星附近显示短暂 ×N，不再伪装成弹仓。
  • 六张升级卡使用固定卡位；未获得卡不在战场 HUD 中显示。
  • 右下角数字始终表示升级等级；中心或蒙版才表示冷却，两者不共用同一数字语义。

战场可读性#

  • 低透明度幽灵仍要保留完整轮廓，不得与暗背景融为一体。
  • 显形除了透明度改变，还需要一个短促的轮廓或明度提示，让玩家知道“现在可锁”。
  • 红色感叹号只给可打断攻击，并必须配合可读的剩余时间，不能只闪一下。
  • 近战幽灵通过距离变化制造压力，远程幽灵通过蓄力动作制造压力；玩家不看文字也能说出它们的差别。

可替换美术接口#

本版开始时就应将幽灵做成可独立替换的 Prefab，不再把角色形状、洞口和动画全写在运行时绘制代码里。每个敌人 Prefab 至少预留：

  • Body：主美术节点。
  • VirtualFX：虚化叠层或材质节点。
  • WarningAnchor：红色感叹号和蓄力环挂点。
  • AimAnchor：瞄准环与已标记图标挂点。
  • HitFXAnchor：受击、破甲和消散效果挂点。
  • ArmorSlots：护甲怪和 Boss 可独立开关的状态部位。

程序只控制状态、可选性、位置与效果触发；后续替换小猫和幽灵美术时，不需要重写规则代码。

十一、实施顺序#

A. 主题与基础语法#

  1. 更名为《子时已到》，清理对外文案中的地鼠、洞口、牛仔和子弹容量语义。
  2. 删除子弹 HUD 与可见锁定上限，让耐力成为唯一锁定资源。
  3. 建立虚化、显形、行动、预警、受挫、重新虚化的通用状态机。
  4. 用一个白盒普通幽灵验证“显形才可锁”和“命中才打断”。

B. 敌人与威胁导演#

  1. 完成普通、远程、护甲、法术四种白盒行为。
  2. 把旧攻击概率和同屏攻击意图计数改为威胁预算。
  3. 把自动索敌从“弹丸绝对优先”改为按剩余时间排序。
  4. 先验证第1至4关的单怪教学，再实现后期混编。

C. 六张升级卡#

  1. 先完成耐力、瞄准、爆炸三张，验证“基础语法 + 一个可见攻击变化”。
  2. 再完成穿透，并检查敌人站位是否真的经常提供可读直线；如果穿透只能偶然触发，必须先修站位供给，不靠扩大隐形判定拯救。
  3. 完成导弹与保护罩，统一卡牌冷却蒙版、就绪闪光和右下角等级。
  4. 加入二选一的成型保障，再验证九次升级的前、中、后期路径。

D. Boss 与完整十关#

  1. 用白盒部位先验证 Boss 的护甲、脆弱点、召灵和大型咒术。
  2. 完成第5至9关混编与第10关 Boss 战。
  3. 在整体玩法节奏成立后再接入正式幽灵和猎手小猫素材。

十二、验证指标#

基础可理解性#

  • 首次玩家在无文字解释时，能通过一次失败或视觉反馈理解“虚化不能打，显形才能锁”。
  • 玩家不再询问“耐力还有，为什么不继续瞄准”。
  • 玩家能说出红色感叹号表示“需要在蓄力结束前命中打断”。

难度与防卡关#

  • 第5关后，熟练玩家每关至少有一次因威胁时机而主动提前松手。
  • 玩家无视红色打断点时，第4至5关开始有明显失去生命的风险，但任何单个脚本局面都不是不可避免伤害。
  • 常规压力下，攻击物平均占用的锁定数不超过总锁定的 40%。
  • 不允许连续两次齐射都只处理攻击物、没有击破或剥除任何敌人状态。
  • 战场持续有效操作时，最长无关卡进度时间首测目标不超过 6秒。

构筑成长#

  • 第3关开始前，至少获得一种可见的额外攻击手段。
  • 前期获得一级爆炸、穿透或导弹时，第一次正常触发必须立即有效，不需要另一张卡来拯救。
  • 第8关后，正常构筑至少有两种容易辨认的额外攻击表现。
  • 不同构筑的差异要能用行为说出：爆炸等群聚，穿透等直线，导弹则适合在主齐射后补掉高优先目标。

Boss#

  • Boss 的失败主要来自错过打断和目标排序错误，不是因为一条长血条只能重复射击。
  • 玩家能不看文字说出当前要打的是护甲部位、红色打断点还是脆弱点。
  • 一场 Boss 战用两至三次主动创造的脆弱窗口收束，不通过大量重复循环拖时间。

十三、当前确认、本案建议与待验证项#

已确认方向#

  • 游戏名称为《子时已到》。
  • 可爱微恐幽灵主题，玩家为幽灵猎手小猫。
  • 幽灵虚化时低透明且不可选，显形时才可瞄准攻击。
  • 删除子弹数量，耐力成为主要索敌资源。
  • 升级围绕耐力、瞄准、爆炸、穿透、导弹和保护罩展开。
  • 本版至少四种幽灵与一个最终 Boss，核心差异来自行为和打断，不是只增加数值。

本案明确建议#

  • “同时瞄准数”只表示并行工作的准星数；累计总锁定数不设上限，只由按压时长与耐力决定。
  • 打断在松手后射击命中时发生，不在瞄准完成时立即发生。
  • 普通、护甲为近战，远程、法术为远程；其中基础远程怪每次只发射一枚攻击物。
  • 难度由威胁预算与行动组合控制，不再靠攻击概率和弹丸数量堆叠。
  • 保护罩首版自动触发，避免与单指长按瞄准冲突。

待首测回答#

  • 同时瞄准数增加到2、3后是否会让后期自动化过强，削弱提前松手的决策。
  • 穿透的站位供给是否足够稳定，玩家能否有意识地等到对齐，而不是靠隐形吸附偶然命中。
  • 自动护罩是否只降低难度而没有提供可感知的构筑价值；如果过于被动，再单独验证不与长按冲突的主动手势。
  • Boss 的护甲轮数和脆弱点数是否在两至三轮内形成高潮，而不是重复劳动。
