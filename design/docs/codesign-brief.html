0. 给参与设计的 AI#

你现在是《远行商人》的系统策划。你的任务不是替现有道具换一批名字，也不是一次输出几十件孤立的新道具，而是从玩家体验出发，重新思考哪些动态机制能让“伙伴队势”和“从左向右结算”真正形成一套玩法。

你拥有较高设计自由度：可以重新定义构筑家族、道具数量、工具体系、成长资源、奖励结构和特别状况。本文末尾会介绍一份已有候选实验，但它不是标准答案，你可以批判、拆分、替换或全部放弃。

请严格区分三种内容：

  • 当前事实：游戏现在已经采用的规则；不能在无说明的情况下改写。
  • 设计目标：新方案必须努力实现的玩家体验。
  • 开放空间：允许自由提出替代方案，但必须解释收益、代价和验证方法。

如果提出的机制需要改动当前事实，请单独列为“底层规则变更提案”，给出修改理由和影响范围，不要把它混进普通道具设计。

1. 游戏是什么#

《远行商人》是一款轻量构筑爆分游戏。玩家带领鹰、狼、龟、蜂、鼠五位伙伴，在一本旅行笔记中完成不同地点的探索记录。

玩家每轮从3张伙伴手牌中连续选择伙伴，依次放入5个行动格。放满后，系统自动从行动格1结算到行动格5。每个行动格可以配置1件道具；道具会加工伙伴行动，并把行动、触发或状态传向紧邻右侧。工具牌则让玩家在结算前临场改变伙伴类型、顺序或点火位置。

玩家需要在每页最多4轮内达到探索度目标。理想体验不是简单获得大数字，而是：

我先组成一支有明确队势的伙伴队，再把它放进自己搭建的五段装置；前段的小动作经过传导、转换和积累，最终在右侧形成看得懂来源的爆发。

2. 当前事实#

2.1 伙伴牌#

  • 五种伙伴：鹰、狼、龟、蜂、鼠。
  • 稳定ID：eagle/wolf/turtle/bee/mouse。
  • 每种5张，共25张，初始基础分均为10。
  • 伙伴手牌维持3张；每打出1张便补回3张。
  • 每累计打出某伙伴10次原始行动，该伙伴本局永久+2，第10次当轮立即生效。
  • 再次行动不进入伙伴累计。

玩家文案必须使用“伙伴牌”“伙伴手牌”“所有伙伴”，不能把伙伴称为职业或行动类型。

2.2 五种队势#

队势条件倍率
成双任意2名相同伙伴×2
成势3名相同伙伴×5
齐行鹰、狼、龟、蜂、鼠各1名×7
领衔4名相同伙伴×10
满贯5名相同伙伴×15

成双→成势→领衔→满贯是集中同一伙伴的进阶路线；齐行是五种伙伴共同出动的独立路线。

当前探索度仍按以下方式结算：

本轮探索度 = floor（伙伴行动与道具产生的行动贡献 × 最终队势倍率）

这五种队势与倍率是当前设计基线。若认为它们必须改变，可以另做替代方案，但不能只因为其他游戏采用不同计分方式就删除它们。

2.3 五个行动格与向右规则#

  • 每轮放满5张伙伴后自动结算。
  • 每个行动格最多配置1件道具，共5个道具位。
  • 原始伙伴行动先触发本格道具，再读取伙伴当前分数。
  • 道具产生的新触发只能去紧邻右侧行动格或右侧道具。
  • 不跳格、不向左、不回传；行动格5的向右效果自然失效。
  • 道具可以成长并跨轮保留状态；替换道具会移除该道具自身的成长状态。
  • 每轮放下第1张伙伴前可以重排道具，之后锁定。

“1→5”是所有构筑共用的空间语法，不是要求所有构筑都成为同一种“增加右侧触发次数”流派。

2.4 工具牌#

  • 当前有10张工具牌，独立于3张伙伴手牌持有。
  • 工具不进入伙伴牌库，不因刷新被丢弃。
  • 工具可用于改变伙伴类型、过滤抽牌、交换位置、让伙伴再次行动、让道具再次触发或复制上一张工具。
  • 新生成的工具从下一轮开始可用，避免同轮生成—复制—再生成无限循环。

工具牌应该承担主动决策：修正队势、重排链路、精准点火、救场、转型或应对终页状况，而不只是另一种固定加分。

2.5 16页目标#

当前每页最多4轮。每章第4页为地点终页。

章节第1页第2页第3页第4页终页
雾叶林2504006501,000
回声湾2,5004,0006,50010,000
风草坡25,00040,00065,000100,000
晶砂谷250,000400,000650,0001,000,000

目标节奏希望呈现：前几页容易理解和生存，随后开始出现压力；构筑形成后允许明显爆发；最终章节的压力再次快速上升。

2.6 地点终页#

  • 当前每个场景拥有5条特别状况，共20条。
  • 进入一章时，应提前公开该章终页将面对的状况。
  • 玩家利用前3页奖励和成长为第4页做准备。
  • 状况可以要求重排、替换局部组件、改变兑现位置或提高资源成本。
  • 状况不应无预警地随机关闭玩家已经建立的整套构筑。

当前需要重点警惕的状况类型包括：全局减少右侧触发、随机关闭核心道具、随机改变关键伙伴、让整类再次行动失去价值，以及让某张牌不参与队势但不给替代路线。

3. 需要统一的核心体验#

当前四种决策应当成为一条连续链：

伙伴组合 = 本轮形成什么队势（我派谁）
伙伴排列 = 相邻条件与触发路径（怎么排）
道具布置 = 五段装置如何加工输入（怎样放大）
工具牌 = 何时修型、改链、点火或救场（何时调整）

3.1 MDA目标#

层次本游戏中的含义
机制 Mechanics3张手牌连续选牌、5张队势识别、伙伴成长、1→5结算、相邻道具传导和工具改写。
动态 Dynamics玩家在更高队势、更好排列、构筑成长和终页准备之间做取舍。
美学 Aesthetics玩家感觉自己组成了有明确队势的伙伴队，并亲手搭出一台会逐层放大的装置；爆发超出预期，但仍能理解来源。

3.2 新设计应提供的感受#

  1. 蓄势：能预想左侧的小输入会怎样启动后续结构。
  2. 因果可读：行动、触发、成长与倍率变化都有明确来源。
  3. 递进爆发：结算从左到右形成节奏高潮，不是五个位置同时报数。
  4. 构筑表达：不同构筑像不同机器，不是同一效果换数值。
  5. 发现与掌握：玩家能通过队势、排列、位置和工具发现组合规律。
  6. 相对成长：玩家感觉自己逐渐超过当前目标压力，而不只是数字越来越大。
  7. 适应：公开的终页状况促使调整，但不直接摧毁核心乐趣。

4. 当前设计问题#

这些问题是设计输入，不代表已经指定了解法。

  1. 队势与右链仍可能割裂：玩家一边凑同类或齐行，一边搭与伙伴组合关系较弱的道具机器，两者主要只在最后乘法处相遇。
  2. 道具存在纯数值重复：例如本格+5/+10、右侧行动1次/2次，奖励选择容易变成单纯选更大的数字。
  3. 构筑生命周期不足：有很多中间传导器，但前期方向提示、中期分支和后期独特兑现不够完整。
  4. 成长偏向集中路线：某伙伴每10次行动+2会自然鼓励重复打出同一伙伴，齐行缺少同等清晰的长期成长方式。
  5. 工具生态较窄：工具生成主要停留在随机工具、固定铜镜或固定网兜，尚未形成按构筑方向准备、转换和消耗工具的玩法。
  6. 部分终页状况攻击底层语法：全局右触发-1或随机关闭核心节点会让玩家的构筑直接失去作用，而不是形成一道可准备的题。
  7. 高分不一定等于爽：指数触发可能只带来长动画和难以理解的报数，未必形成蓄势、转折和兑现。

5. 开放设计空间#

你可以自由提出：

  • 新的构筑家族及其核心资源。
  • 道具的保留、合并、删除、改名和重做。
  • 新道具与新工具，以及道具/工具总数。
  • 队势如何成为链路输入，而不只在结算末尾乘分。
  • 集中路线、齐行路线、混合路线和转型路线。
  • 再次行动、道具复写、蓄能释放、长期成长、工具工坊或其他全新机制。
  • 奖励池、稀有度、工具组和道具替换方式。
  • 终页状况及其目标补偿。
  • 16页目标调整，但必须提供新旧对照和理由。

不要为了显得创新而增加大量新名词。每种新增资源都必须回答：玩家能否看懂、是否创造新决策、UI是否值得表现、它与现有资源有什么不同。

6. 你的设计任务#

请一次完成以下五部分。先设计动态机制，再设计具体道具。

第一部分：复述理解#

用不超过300字说明：

  • 为什么队势、伙伴排列、道具布置和工具使用应是一条连续决策链。
  • 为什么向右是底层空间语法，而不是唯一构筑流派。
  • 你认为本游戏最重要的爽感是什么。

如果你的理解与本文冲突，请先指出冲突。

第二部分：提出3—6种动态机制或构筑方向#

这一部分不要先列几十件道具。每个方向填写：

方向名称：
核心幻想：
链中传递或积累的资源：
它如何读取队势或伙伴排列：
玩家在结算中看到的节奏：
与其他方向真正不同的地方：
主要风险：

不同方向不能全部围绕“让右侧多触发几次”。至少应覆盖两种以上不同资源，例如伙伴行动、道具触发、队势信号、成长、工具类型、蓄能、受阻事件或其他自定义资源。

第三部分：选出最值得继续的2—3个方向#

对每个入选方向完整描述生命周期：

阶段必须回答的问题
前期种子只有1件核心组件时是否有用，玩家如何看出方向？

后期兑现链尾如何形成明显高潮，而不是只把数字乘大？
终页准备哪类状况能通过重排、工具或替换局部组件应对？
失败形态缺少关键组件时能否过渡，还是整套成为白板？

同时给出每个方向的一套示例布局，格式为：

行动格1 → 行动格2 → 行动格3 → 行动格4 → 行动格5

示例可以使用机制职责代替具体道具名，例如“点火器→蓄能器→转换器→放大器→终点载荷”。

第五部分：目标相对验证#

不要求在缺少真实引擎时伪造精确结果，但必须写清假设。至少检查以下页：

检查点目标体验作用

第5页2,500第一轮明显压力
第8页10,000第一次章节爆发
第9页25,000新章节重新施压
第12页100,000成熟构筑兑现
第13页250,000终局压力跃迁
第16页1,000,000最终构筑与终页状况检验

每个入选方向提供不顺、中位、顺利三条样本，至少说明：

  • 单轮探索度约占当前目标多少。
  • 预计需要几轮完成。
  • 首次成型和后期兑现发生在哪一页。
  • 缺少核心组件时如何过渡。
  • 最大行动次数、道具触发数与大致动画负担。
  • 哪些终页状况会改变这条曲线。

使用以下目标比作为讨论语言：

R = 单轮探索度 / 当前页实际目标
R < 0.25：四轮仍可能失败
R = 0.25—0.40：明显压力
R = 0.40—0.70：稳定推进
R = 0.70—1.20：强构筑或顺利爆发
R > 1.20：超额爆发，需要判断是高潮还是常态失控

7. 审核标准#

请在方案最后进行自评，每项0—2分。任何0分项都要解释是否应淘汰该方向。

维度0分1分2分
位置决策顺序基本无意义部分组件依赖位置全程存在可理解的位置取舍
队势耦合完全不读取伙伴组合只在结尾乘倍率队势会改变链路条件、资源或兑现
因果可读看不懂爆发来源能理解局部能逐段理解蓄势、转换和兑现

后期高潮只有大数字有明显强化结算节奏和终点兑现共同形成高潮

一票否决#

  • 存在可稳定复现的无限循环。
  • 新道具只是现有效果换数字或换名字。
  • 只有理论最大分，没有前中后期曲线。
  • 需要跳格、向左或回传，却没有单独提交底层规则变更理由。
  • 特别状况随机删除核心构筑，玩家无法提前准备。
  • 构筑必须拿齐所有核心组件才有任何作用。
  • 为了保留某个数字而倒推目标或模拟结果。

附录：已有候选实验，仅供批判#

此前已经做过一份非运行时实验，将当前40件道具和10张工具尝试收敛为30件候选道具、12张候选工具，并形成六个构筑家族：

实验方向核心输入预想体验已发现的问题
领队集结主导伙伴、集中层级围绕同一伙伴逐层加速容易继续强化本就占优的集中路线
五伴接力不同伙伴、异类相邻五种伙伴的信号在链尾会合齐行成型成本和四种伙伴过渡仍需实测
行动回声伙伴再次行动同一高价值节点越来越响触发和动画可能过长
机关共振道具再次触发一件道具成为下一件的动力最容易出现同质化与指数失控
旅途养成永久成长、成长里程碑前期投资在后期成为燃料前中期偏苦，晚获得可能成为陷阱
工具工坊工具数量和类别用主动工具改链并启动机关必须阻止生成—复制循环

这份实验使用参数化“链路因子”而不是真实事件队列，因此只能证明大致分数曲线可以成立，不能证明实际爽感、触发节奏、动画长度或无限循环安全。

你可以：

  • 保留其中有价值的体验，但重做实现方式。
  • 把两个方向合并，或把一个方向拆成不同玩法。
  • 提出完全不同的核心资源与构筑家族。
  • 证明其中某个方向不值得继续，并说明淘汰依据。

不要因为已有实验恰好是“六个家族、30件道具、12张工具”，就继续维持这些数量。最终目录应由体验、奖励密度、构筑生命周期和真实队列模拟共同决定。
