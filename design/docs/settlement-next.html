版本：vNext 讨论稿
整理日期：2026-05-30
用途：MVP 后续迭代、数值讨论、论文研究与项目汇报

这份文档不直接覆盖 MVP v0.1 策划案。它记录 MVP 开发后暴露出的体验问题，并提出一套可以继续验证的结算流程、UI 反馈、数值曲线和 30 个随身物方案。

1. 当前问题与设计目标#

1.1 当前版本已经成立的方向#

  • 玩家每个路段最多进行 4 次探索轮。
  • 玩家依次将 5 张行动牌放入 5 个行动格。
  • 每张行动牌具有当前分数，行动牌之间可以形成同源关系。
  • 路段具有一个目标盘缠；每轮结算后，目标盘缠减去本轮总得分。
  • UI 只保留三个核心数字节点：剩余目标、分数、倍率。
  • 总得分继续使用简单公式：
本轮总得分 = 分数 x 倍率

这个简化很重要。它保留了数值膨胀的空间，又比同时展示基础分、倍率、总分、累计分更适合小游戏屏幕。

1.3 核心体验目标#

本作不是简单删减版的复杂卡牌游戏。它应当形成自己的体验合同：

玩家只需要理解“同源越多，倍率越高”；但当构筑成型后，简单规则能够连续触发，产生远超初始数值的爆发。

可以将目标概括为：

低认知成本 + 清楚的即时反馈 + 后期数值爆炸

2.2 可以借鉴，但不照搬的部分#

可以借鉴《小丑牌》的两点：

  1. 简单数学节点承载复杂构筑。 玩家始终盯着分数与倍率，但背后允许多个来源连续改变它们。
  2. 触发必须有来源。 哪张牌、哪个道具、哪一次再触发改变了数字，动画都应当指向对应节点。

可以借鉴《炉石传说：酒馆战棋》的三类效果词汇：

  1. 重复触发： 某个清楚的事件再执行一次。
  2. 相邻影响： 左右位置决定收益，形成容易观察的摆位组合。
  3. 成长触发： 每次刷新、每次使用工具或每次通关都会积累收益。

不建议照搬的部分：

  • 不增加大量扑克牌型。
  • 不把道具顺序优化变成首版必学内容。
  • 不让再触发无限生成新的再触发。
  • 不在 UI 中同时摆出过多中间数字。

3. 三节点 UI 方案#

3.1 三个常驻节点#

节点作用出牌阶段正式结算阶段
剩余目标当前路段还需要获得多少盘缠保持不变吸收本轮总得分并向下扣减
分数区本轮行动牌和道具累计出的分数保持初始显示，不要求提前展示精确分数从 0 开始，按照触发顺序逐项增长
倍率区当前同源牌型和道具累计出的倍率实时显示牌型预览锁定基础牌型倍率，再接受道具修改

最终结算：

本轮总得分 = 最终分数 x 最终倍率
剩余目标 = max(0, 结算前剩余目标 - 本轮总得分)

本轮总得分不需要成为第四个常驻节点。结算末尾可以临时放大显示一次，然后直接用于扣减“剩余目标”节点。

3.2 三个 UI 状态#

状态玩家操作分数区倍率区设计目的
出牌中依次放置第 1-5 张行动牌；可在填满前使用工具保持初始显示实时更新当前牌型和倍率让玩家边操作边理解目标
结算中暂停操作按事件逐项增加按事件逐项增加或乘算展示构筑为什么生效
结算后进入下一探索轮或通关临时显示本轮总得分保留最终倍率片刻形成收束和结果反馈

当前版本保持轻操作：第 5 格填满后直接自动开始结算，不新增结算按钮。

这里仍有一个值得记录的问题：自动结算让流程更顺，但最后一张牌出错时没有撤回窗口，也限制了“填满后再使用工具”的空间。这个问题暂时不做结论，后续通过实机测试观察误操作频率，再决定是否需要长按撤回、短暂延迟或其他不增加常驻按钮的交互方式。

3.3 倍率区同时承担教学#

倍率区在出牌阶段不应只是一个静态数字。当前确定的表现是：

三同源
x3

上方是当前牌型的文字图片，例如“双同源”“三同源”；下方是倍率区节点文本，例如 x2、x3。

每放置一张牌：

  • 达到新的同源层级时，倍率数字跳动一次。
  • 上方牌型文字图片同步切换，例如“双同源 -> 三同源 -> 四同源”。
  • 结算开始时锁定牌型，之后再播放道具带来的倍率变化。

这相当于用倍率区替代复杂教程。玩家在第一局就会自然感知“再来一张同色牌会更强”。

4. 同源牌型建议#

4.1 建议改为单一阶梯#

当前 MVP 从三同源开始奖励倍率，而且“二对牌”单独形成双同源。为了强化即时感知，建议改为更直观的阶梯：

牌型条件建议基础倍率出牌阶段反馈
散货尚未形成同源x1默认状态
双同源至少 2 张同货源x2第二张同色牌放下时立刻点亮
三同源至少 3 张同货源x3倍率区升级并加重反馈
四同源至少 4 张同货源x5进入明显爆发区
五同源5 张同货源x8使用最强牌型反馈
五源齐备5 种货源各 1 张x4作为独立杂色流入口

识别规则：

  1. 五源齐备优先单独识别。
  2. 其余情况只看数量最多的一种货源。
  3. 出现 2+2+1 时仍按双同源计算，不额外引入二对牌规则。

4.2 双同源定义调整#

MVP 文档中的“双同源”原本指 2+2。vNext 建议将它调整为“至少 2 张同货源”，因为本作最重要的教学语句是：

同一种行动牌越多，倍率越高。

如果同时要求玩家理解“两个对子也是一种特殊结构”，规则会稍微偏离这个主轴。2+2 可以留给未来的特殊道具，不再作为默认牌型。

5. 正式结算协议#

5.1 数值运算类型只保留五种#

运算类型UI 表达示例使用阶段
加分 ADD_SCORE沿用已有的飘分表现+10 分前期常见
单牌乘分 MULTIPLY_CARD_SCORE行动牌或格子印记亮起，飘出变化后的分数本牌分数 x2中期常见
加倍率 ADD_MULT红色印记飞入倍率区+2 倍率前中期常见
乘倍率 MULTIPLY_MULT大号印章落在倍率区倍率 x2后期稀有
再触发 RETRIGGER_CARD原行动牌再次亮起本牌再结算 1 次中后期引擎

所有直接改变数字的道具都尽量落到这五种语言里。这样道具数量可以增加，玩家仍然只需要认识少量视觉语法。

此外允许少量“规则修正”道具，例如“开矿与采集视为同源行动”。规则修正不直接加分，也不作为新的动画运算类型；它们在牌型锁定前先修改判定方式。

5.2 固定阶段#

阶段内部事件处理内容画面表现
0onExploreStart清除上轮临时状态，处理探索轮开始道具全局道具依次轻亮
1onCardPlaced玩家放置行动牌，刷新实时同源倍率；处理“每打出一张牌”类成长行动格、成长道具与倍率区同步变化
2onAutoSettle第 5 张牌放下后锁定输入并自动开始结算不新增按钮，直接进入结算表现
3beforePatternLock处理规则修正道具，例如“开矿与采集视为同源”对应全局道具轻亮
4onPatternLocked锁定本轮牌型，倍率区获得基础倍率；触发牌型道具上方牌型图片定格，倍率区变化
5onCardScore按格子 1 到 5 结算行动牌沿用已完成的逐张飘分表现

出牌阶段的实时牌型预览也需要读取规则修正道具。例如拥有“山野图谱”后，开矿与采集在预览时就应该显示为同源，而不是等到结算时才突然改变牌型。

Boss 异象暂时不进入当前实现协议。等基础结算和构筑循环稳定后，再单独设计异象插入点。

5.3 单张行动牌的内部顺序#

格子从 1 到 5 依次结算。每一格内部遵循：

行动牌当前分
-> 行动牌自身标签
-> 当前格子印记效果
-> 全局的“行动牌结算时”效果
-> 本格产生的再触发
-> 进入下一格

全局道具如果同阶段同时触发，按 UI 中从左到右的固定顺序播放。首版不要求玩家拖拽调整全局道具顺序。

5.4 防止连锁失控的规则#

规则原因
再触发可以重复行动牌计分，但默认不能再次生成新的再触发事件防止无限循环，也便于解释
每次正式结算保留完整事件日志方便动画、调试和论文分析
连锁超过 6 次后缩短单次动画，超过 12 次后允许合并显示 连续触发 xN兼顾爽感与节奏
玩家可点击加速，但最终乘算动画始终保留快速玩家可以提速，爆发落点仍然明确

6. 格子印记、动画与可读性#

6.1 格子印记不是额外底座#

程序逻辑上，部分随身物仍然会绑定某一个行动格。但视觉上不增加“底座 -> 道具 -> 行动牌”的多层结构。

当前确定的表现是：

  • 初始行动格是空的旧纸槽。
  • 获得格子随身物后，对应行动格增加专属底纹、符印或拓印。
  • 部分格子印记可以改变边框样式，例如铜边、双层纹或相邻连纹。
  • 行动牌仍然直接放在格子上。
  • 不在格子上额外摆放一个实体道具图标。

这样既保留格子构筑的策略意义，也让画面保持清楚。后文将这类效果统一称为“格子印记”。

6.2 每类变化使用固定视觉语言#

变化建议视觉表现声音节奏
行动牌加分沿用已完成的行动牌飘分表现短促、逐张上扬
格子印记加分格底纹样或边框亮起，随后沿用飘分表现比普通行动牌稍厚重
全局随身物加分对应小符牌亮起，随后沿用飘分表现与行动牌音色区分
增加倍率红色小印落入倍率区清脆盖印声
倍率乘算大印章压下，倍率数字明显放大低频重音
再触发行动牌回弹，再次亮起，牌角显示“再算”快速回声
成长型随身物全局小符牌直接显示当前值，例如 x1.0 -> x1.1轻微递进音
规则修正随身物对应货源图标之间出现连纹，例如“开矿 = 采集”获得时提示，结算时轻亮
最终乘算分数和倍率同时强调，总得分短暂放大，目标分开始扣减本轮最强反馈

6.3 出牌阶段重点预览倍率#

出牌阶段可以展示：

  • 当前牌型的文字图片。
  • 当前已形成的同源倍率文本。
  • 一定会触发的格子印记状态。

分数区不必提前展示精确预估分。随机效果和额外触发统一留到正式结算阶段，避免玩家把预览误解为最终结果。

8. 建议保留的五条流派#

流派一句话目标前期入口中期引擎后期爆发
同源爆发流尽量凑出 4-5 张同货源同源牌匣、来源专属道具破货架、空货箱火漆契
五源齐备流5 种行动牌各放 1 张百色绳、染货布五色转经筒、集市串铃五方路引
格子连锁流把高收益牌放进关键格子印记中格铜印、旧罗盘双层箱、回声铃、连环扣压箱底
工具连锁流一轮内使用多张工具，累积倍率旧货铃、加价印古玩匣行商腰牌
刷新蓄力流把刷新次数转换成临时爆发旅人靴、狐火灯风雨斗笠、余香炉与任意再触发或乘倍率终结器组合

这些流派不是互相隔离的职业。每局只需要形成一条主线，再拿到一两个跨流派零件，就有机会产生意外组合。

9.1 首轮投放建议#

  • 第 1 章只投放表中最早解锁为 1 的道具。
  • 第 2 章加入格子印记再触发、刷新再触发和成长型随身物。
  • 第 3 章加入规则修正、连环扣、火漆契、五方路引。
  • 每个奖励选项都应显示效果属于 +分、+倍率、倍率 xN、再触发、成长 或 规则修正 中的哪一种。

10. 连锁示例#

10.1 同源爆发#

组合：

五同源 x8
+ 同源牌匣 +3 倍率
+ 火漆契 倍率 x3
+ 破货架提高行动牌分数
+ 空货箱提高五同源稳定性

玩家体验：

  • 出牌阶段持续看到 双同源 -> 三同源 -> 四同源 -> 五同源。
  • 结算末尾火漆契盖下大印，倍率从 x11 变为 x33。
  • 规则非常短，但数字增长明显。

10.2 格子连锁#

组合：

第 1 格：高分行动牌
+ 回声铃：第 1 格再算 1 次
+ 第 3 格：中格铜印
+ 双层箱：关键格再算 1 次
+ 连环扣：本格首次计分后，右侧相邻牌再算 1 次

玩家体验：

  • 行动牌不是单纯按颜色凑牌，还要考虑放在哪一格。
  • 再触发动画反复回到同一张牌，构筑强点肉眼可见。
  • 连环扣产生的额外计分不再生成新的连环扣事件，避免无限循环。

10.3 工具连锁#

组合：

本轮使用 3 张工具牌
+ 旧货铃：每张工具牌 +1 倍率
+ 古玩匣：本轮用过工具时，搜罗牌额外加分
+ 行商腰牌：至少使用 2 张工具牌，最终倍率 x2

玩家体验：

  • 玩家在结算前主动安排一串操作。
  • 旧货铃连续响起，倍率逐步增长。
  • 行商腰牌最后翻倍，形成清楚的收尾爆发。

10.4 刷新蓄力#

组合：

旅人靴：额外刷新
+ 风雨斗笠：每次刷新 +2 倍率
+ 狐火灯：刷新后下一张牌分数 x2
+ 余香炉：刷新后下一张牌再算 1 次

玩家体验：

  • 刷新不再只是补救坏手牌，而是主动蓄力。
  • 玩家会观察哪张牌值得承接刷新后的双重强化。

10.5 成长与规则修正#

组合：

商路账簿：每打出 1 张交易牌，自身倍率永久 +0.1
+ 山野图谱：开矿与采集判断牌型时视为同源
+ 矿灯：开矿牌持续获得加分
+ 药草袋：采集牌持续获得加分

玩家体验：

  • 商路账簿会从 x1.1 慢慢成长到 x1.8 或更高，玩家能直观看见构筑积累。
  • 山野图谱本身不直接加分，但会改变玩家挑选行动牌的方式。
  • 开矿和采集仍保留各自的加分道具，因此规则修正可以把两条简单效果组合起来。

10.6 后期 10 万分量级示意#

一个成型构筑可以出现：

行动牌与格子印记累计分数 = 900
五同源基础倍率 = x8
同源牌匣 = +3 倍率
工具连锁 = +4 倍率
火漆契 = 倍率 x3
行商腰牌 = 倍率 x2

本轮总得分 = 900 x (8 + 3 + 4) x 3 x 2
           = 81,000

再叠加一次关键格再触发，就能突破 10 万。第 16 路段的 120000 目标允许普通成型构筑用 2-4 轮通过，也允许优秀构筑单轮爆发通关。

11. 程序实现建议#

11.1 分离预览和正式结算#

建议维护两个状态：

previewState
settlementState
  • previewState 只计算当前牌型、倍率和可见状态，用于出牌阶段 UI；不要求提前算出精确总分。
  • settlementState 使用事件队列正式执行，记录每个道具来源和每次数值变化。

11.2 事件日志最小结构#

{
  "phase": "onCardScore",
  "sourceType": "relic",
  "sourceId": "relic_double_box",
  "targetId": "slot_03",
  "operation": "RETRIGGER_CARD",
  "value": 1,
  "depth": 0
}

事件日志可以同时服务：

  • 结算动画播放。
  • 调试数值错误。
  • 复盘玩家为何获得高分。
  • 论文中分析构筑行为和认知负荷。

12. 后续验证问题#

第一轮原型测试建议重点记录：

  1. 玩家是否会在第一次出牌时注意倍率区的实时变化。
  2. 玩家是否自然理解“同源越多，倍率越高”。
  3. 第 5 张自动结算是否容易造成误操作；轻操作和容错空间应如何取舍。
  4. 玩家是否能说出一轮爆发来自哪个道具。
  5. 连续触发多少次以后，动画开始显得拖沓。
  6. 第 8 路段前是否能够形成一条可辨认的主流派。
  7. 第 12 路段后是否开始出现明显的数值跃迁。
  8. 第 16 路段的 10 万量级目标是否让成型构筑感到兴奋，而不是纯粹疲劳。
