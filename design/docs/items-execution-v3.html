1. 本轮重构结论#

v0.2 的问题不是道具数量不足，而是仍然以“基础效果排列组合”填满30件：探索值只是把小中大数值各列一次，行动道具常把两个无关效果用分号拼接，倍率道具又集中读取牌型。v0.3 改为五种明确职责：

类别数量只回答的问题
伙伴行动8哪一处伙伴会多行动，行动量如何形成链？
探索值6行动满足什么位置或次数条件后，单次行动值多少钱？
成长5本轮或过关时，谁会永久变强？
倍率6行动量、成长量或工具使用如何变成倍率？
构型5怎样让三连、四连、五连真的更容易打出？

30件道具的玩家文案均没有分号。普通道具只有一个效果；条件只用来换取更高价值，不再把“右侧行动+1”强行附在工具生成或成长道具上。

2. 基础“每10张自动成长”怎么处理#

改版前运行时配置是：同一种伙伴每累计原始打出10张，该伙伴永久+2，不是+10。

v0.3 已从基础规则中删除这条自动成长，原因是：

  • 它与成长道具重复，玩家会同时追踪伙伴计数、组合、排列和道具成长。
  • 它不由构筑选择产生，却天然奖励一直打同类，使五连路线得到一份隐性优势。
  • +2很难形成可见爽点；改成+10或+20又会强到必须围绕它重新校准所有关卡。

这个体验不完全删除，而是集中到一件可选道具：

旅行日志：同一种伙伴每累计原始打出10张，该伙伴探索值永久+10。

想玩“长期养一位伙伴”的玩家可以主动拿它；其他路线不需要盯额外计数条。测算 v0.3 时没有再计算基础自动成长，只计算旅行日志与其他成长道具。

3. 探索值文案统一为“行动探索值+X”与“永久+X”#

两种加法使用固定句式，避免“伙伴探索值+10”究竟会不会保留的歧义：

  • “行动探索值+X”：只加入文案指定的行动结算，不改变伙伴的基础探索值。
  • “伙伴探索值永久+X”：立即改变该类伙伴的基础探索值，本局后续回合和关卡都保留。
名称条件与效果设计位置
铜钱此处伙伴每次行动探索值+5。无条件早期载荷。
压舱石放在5号格时，此处伙伴每次行动探索值+10。明确的链尾载荷。
同伴结此处与右侧为同类伙伴时，右侧伙伴下一次行动探索值+10。集中组合的相邻题。
交接旗此处与右侧为不同伙伴时，右侧伙伴下一次行动探索值+10。两对/多伙伴路线的排列题。
满弦弓此处伙伴本轮行动达到8次时，本轮此处每次行动探索值+20。单核爆发兑现。
合奏谱本轮每有1种不同伙伴，所有伙伴每次行动探索值+2。多伙伴共同载荷。

固定的行动探索值加成使用+5/+10/+20，像合奏谱这样的动态累加效果可以每层+2；永久成长使用+2/+5/+10。严格条件提高档位，但不再出现相对初始探索值10而言失去尺度的+100或+500。

4. 伙伴行动：每件只改变行动次数#

名称玩家文案动态作用
海螺右侧伙伴行动次数+1。最基础的右侧种子。
手鼓此处与右侧为同类伙伴时，右侧伙伴行动次数+2。服务集中排列。
彩带此处与右侧为不同伙伴时，右侧伙伴行动次数+2。服务交替排列。
领队笛此处为本轮数量最多的伙伴时，右侧伙伴行动次数+2。将组合中的主力伙伴接入链路。
回声板此处伙伴第5次及之后行动时，右侧伙伴行动次数+1。把中段高频行动截取到链尾。
行军鼓本轮所有伙伴行动次数+1。全员路线种子。
轮班牌与左侧不同的伙伴，本轮行动次数+1。让交替排列平均增动。
号角每使用1张工具，所有伙伴行动次数+1，最多+2。把工具使用转换为全队节奏。

这些道具不再附加永久成长、工具生成或倍率。成长和倍率是否加入构筑，由另外的道具位置决定。

5. 倍率来源不再等同于牌型清单#

名称玩家文案对应路线
旅旗本轮倍率+0.2。简单通用。
行旅账簿每累计12次伙伴行动，倍率永久+0.5，最多+20。总行动量成长。
成长册永久成长总计每达到100，倍率永久+0.2，最多+10。成长兑现。
领队旗有一处行动达到8次时，本轮倍率+0.5。单核爆发。
齐步箱五处都行动至少2次时，本轮倍率+0.5。全员连动。
工具印每使用1张工具，本轮倍率+0.2，最多+0.6。工具流。

伙伴组合仍提供×1、×2、×4、×5、×10、×15的基础倍率，但倍率道具不再把六个组合名称抄一遍。它们读取玩家实际构筑产生的行动量、永久成长和工具使用。

6. 构型道具与8张工具#

五连若只靠25张牌、3张手牌和2次刷新，不能被当成默认前提。v0.3 增加了五件纯构型道具。只有印泥盒直接给工具，其他道具需要通过组合、伙伴行动或工具使用来产出：

名称效果
印泥盒每关开始时，获得1张远镜。
染布包本轮组成三连或更高组合时，获得1张铁锹。
镜筒箱此处伙伴本轮行动达到3次时，获得1张锦囊。
铜镜匣每累计使用3张工具，获得1张明珠。
同伴名册打出第3张伙伴后，下一张补牌必定与已放置最多的伙伴相同。

工具从6张扩到8张。原有六张全部保留，并补回构型真正需要的铁锹和锦囊：

工具效果
铁锹选择1张伙伴手牌，变为任意伙伴。
远镜变为上一张打出的伙伴。
宝盒丢弃1张伙伴手牌，补1张。
锦囊丢弃1张伙伴手牌，查看牌库顶3张并选择1张。
手杖选择1处，伙伴行动次数+1。
巧锁选择一件触发型道具，道具触发次数+1。
司南下一张打出的伙伴，本次行动探索值+10。
明珠变为上一张使用的工具。

构型道具需要先形成一点组合、行动或工具循环，再持续产出修型工具；印泥盒是唯一直接提供启动资源的道具。已储存的工具可以继续承担四连/五连修型，因此高组合来自构筑投资，不是每关免费发放。

7. 真实构型概率#

以每种伙伴5张、初始手牌3张、放牌后补牌、每轮2次刷新为基础，用10万次定种子模拟。策略是选择初始手牌中数量最多的伙伴作为目标，优先打目标伙伴，并在缺牌时使用工具。

准备三连或更高四连或更高五连
只用2次刷新75.1%32.5%4.1%
1张远镜94.9%67.5%19.0%
远镜+铁锹100.0%94.6%51.9%
远镜+铁锹+锦囊+宝盒100.0%98.4%72.1%
2张远镜+铁锹100.0%100.0%82.3%
同伴名册+远镜+铁锹100.0%100.0%78.2%

结论很明确：五连裸出只有约4%，不能作为常态；投入一张远镜和一张铁锹后升到约52%，形成构型套装后达到72%～82%。四连则可以作为前中期稳定过渡。

8. 三条连锁路线#

8.1 单核爆发#

1 海螺 → 2 手鼓 → 3 领队笛 → 4 回声板 → 5 木雕
行动次数：1 → 2 → 5 → 11 → 8

触发过程：

  1. 海螺让2号格多行动1次，所以2号格共2次。
  2. 手鼓每次给同类右侧+2，2次共送4次，3号格变为5次。
  3. 领队笛每次送+2，5次共送10次，4号格变为11次。
  4. 回声板只从第5次开始送出行动；第5～11次共7次，5号格因此是原始1次+额外7次=8次。
  5. 木雕从此处第5次行动开始，每次让主力伙伴永久+10。5号格一轮8次行动时，当轮共永久成长40；如果换成满弦弓，则8次行动每次临时+20。

这条链已经满足“一个地方稳定行动7～8次”的目标，而且每张道具只有一件事。

8.2 全员连动#

行军鼓 + 轮班牌 + 号角（本轮使用2张工具）
行动次数：4 → 5 → 5 → 5 → 5，总计24次

行军鼓让所有伙伴+1；交替排列让2～5号格再+1；号角在本轮使用两张工具后让所有伙伴再+2。最终不是把所有次数塞到最右端，而是五格都至少行动4次。石雕每累计2次伙伴行动就让所有伙伴永久+2；24次行动把很多次小成长累积起来，行旅账簿再将总行动量转换为永久倍率。

8.3 成长兑现#

海螺 → 手鼓 → 领队笛 → 木雕 → 成长册
行动次数：1 → 2 → 5 → 11 → 1

4号格每轮稳定达到11次。木雕从第5次开始生效，因此当轮会发生7次永久+10，共成长70；成长册每累计100点永久成长再给永久倍率+0.2。它没有单核路线的链尾8次，但会形成“多次小成长→倍率成长”的长期双阶段兑现。

9. 16关测算#

测算已移除基础每10张+2，只计算当前布局、工具投入、道具成长和倍率成长。

路线第16关普通目标高压章末关1,250,000判读
单核爆发4轮，1,156,2004轮，1,156,200，未通过普通可过；主力伙伴最终探索值810，满载需临时载荷或倍率。
全员连动4轮，1,327,8244轮，1,327,824可过；五格行动为4/5/5/5/5。
成长兑现3轮，1,122,8594轮，1,550,028可过；主力伙伴由多次永久+10成长到约1,280。

三条路线都能通过普通16关。章末关目标+25%会让没有倍率道具的单核爆发差约7.5%，因此章末规则提前公开仍然有意义；玩家可以把木雕临时换成满弦弓/领队旗，或提前储存司南和明珠，而不需要把基础探索值加成扩大到三位数。

10. 落地状态与试玩重点#

  • v0.3 已成为当前运行时基线；v0.1、v0.2 仅保留为历史候选。
  • 优先试玩三种事件形状：1/2/5/11/8、4/5/5/5/5、1/2/5/11/1，确认动画节奏与爽感。
  • UI只需要显示当前行动次数、永久探索值和倍率来源，不再增加基础伙伴熟练度条。
  • 后续应继续把20条特别状况逐一跑入 v0.3 模型，并校准工具奖励频率；目前的构型概率表示“持有这些工具时的成功率”，不代表每关都能获得这些工具。

本轮已修改 assets/resources/config/gameplay/、Core 和现有 UI 逻辑适配；没有修改 Prefab、SpriteFrame 或 Inspector 美术参数。
