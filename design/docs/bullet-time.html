档案说明

这是 2026-09-19 从工程收录的文本，可能包含后来补写的注释。正文中的“当前”“已实现”保留原有语境，不代表本站试玩版已逐项复验。

当前去色、锁敌反馈和音效以 轻量修订 为准，下面保留首轮实现记录。

目标：爆炸播到一半再按住，也能看见碎屑、烟雾、导弹和怪物动作一起放慢，松开再恢复。参考方向来自 Symbol 提到的林克时间与「午时已到」：进入有听觉落差，世界去色聚焦，释放有速度回弹。没有使用原游戏音频、旋律或声线，也没有把公开文档当作两款游戏内部源码。

首版实现（强度已由轻量修订替换）#

  • 原本的灰色整屏覆盖改成材质去色。亮度按 RGB 的 0.2126 / 0.7152 / 0.0722 计算，以 0.42 为对比中心，黑白对比提高至 1.62 倍。0.32 秒渐入、0.24 秒渐出，连续按松从当前进度反向过渡。边缘只保留柔和压暗；玩家、准星和 HUD 保持可读。
  • 战场最终速度为 0.18 倍，进入/退出使用连续速度过渡。敌人移动、施法/显隐计时、身体动作、导弹飞行、爆炸帧切换、特效缓动、烟雾、原生拖尾以及奖励粒子均接入世界时钟。现有缓动直接变更 timeScale，不重播动画。
  • 连射中再次按住会承接到连射结束，耐力足够且有目标时立即开始子弹时间；提前松手、暂停和重开取消承接。
  • 松手恢复正常世界速度，移除原来的齐射期间 0.1 倍移动减速；施法原本独立的 0.62 倍倒计时改成跟世界同步。锁定、耐力、冷却、界面仍按操作时间推进。此项会改变战斗节奏：瞄准时安全窗口更长，齐射后敌方行动更快，仍需真人试玩判断难度。
  • 幽灵身体漂浮、横摆、挤压拉伸的幅度加大；施法会提前收缩/抬身，出手后有衰减回弹。只改变身体表现，不移动锁定与碰撞中心。
  • 爆炸主体约 0.7 秒，碎屑基础约 0.76—1.31 秒，枪口烟约 0.45 秒。保留快速亮起，延长扩散与消失；池化粒子上限仍为 220。
  • 原创音效包含下沉音高、玻璃泛音、带通空气声及持续悬停和声，退出时上扬回弹。使用手机较容易发出的 96—291 Hz 泛音补足原先 48 Hz 低频。
  • 原创 BGM 为 84 BPM、D 小调、约 22.86 秒循环，包含拨弦/钟声旋律、低音及轻节拍。子弹时间渐压音乐音量与高频，松开恢复；没有在切换时重启音乐。

依据#

时间缩放参考 Unity Time.timeScale 与 粒子 scaled/unscaled time 的公开接口约定。实际接入使用 Cocos Tween.timeScale，并检查本机 3.8.7 的 Tween、Graphics 和 MotionStreak 实现。Graphics 使用独立材质实例，需要同步更新实例，不能只更新共享材质。

验证与复查#

npm run check、npm run check:combat、npm run check:audio、npm run check:time、TypeScript 检查。真实引擎入口：node scripts/runtime-focus-check.mjs，拒绝过期导入，检查渐入/恢复、中途减速、暂停、连续反向切换与重开清理。

试听来自实际导出的 NoonFeedbackAudio，经 OfflineAudioContext 渲染，见 BGM（工程内附件，未随本页公开） 与 进入/持续/退出音效（工程内附件，未随本页公开）。导出音量统计只能证明有波形且未削波；手机扬声器听感与移动端材质性能仍需真机体验。

连续效果回放（工程内附件，未随本页公开）：同一批怪物与爆炸先正常播放，再减速、恢复、再次减速。录像按真实帧时间生成，无补帧；该视频无声，音效与 BGM 在上方分别试听。

世界时钟检查（工程内附件，未随本页公开）验证 30/60/120 帧下已有碎屑、导弹、身体与施法倒计时的推进量相同，并检查暂停、恢复和清理回调。真实引擎检查（工程内附件，未随本页公开）额外覆盖实际材质、原生缓动、爆炸换帧及连续按松。

十关连续运行（工程内附件，未随本页公开）：真实引擎 108 秒走完十关，458 次击破，异常 0。验证使用加速标记/出生与免伤，覆盖真实开火、收集、升级及 Boss 阶段；不代表真人难度或通关率。该整局检查在最后的按住承接修正前完成，承接修正另有自动输入回归。
