档案说明

这是 2026-09-19 从工程收录的文本，可能包含后来补写的注释。正文中的“当前”“已实现”保留原有语境，不代表本站试玩版已逐项复验。

日期：2026-07-31 状态：独立机制实验，不覆盖当前 GDD、运行时配置、Core 或 UI。

1. 设计命题#

删除伙伴牌型、固定伙伴行动值和独立倍率区。一轮只有一批探索成果，五张伙伴牌依次加工同一个数值：

1号位发现成果
    → 2号位加工
    → 3号位加工
    → 4号位加工
    → 5号位加工
    → 送入地点目标

基础参数：

  • 初始成果 S = 10。
  • 不同伙伴的补充量 A = 10。
  • 1号位每次加工：当前成果 +S。
  • 2—5号位与前一位为相同伙伴：当前成果 ×2。
  • 2—5号位与前一位为不同伙伴：当前成果 +A。
  • 一轮只把5号位最终送出的成果加入地点目标；中间值不重复计分。

再次加工#

再次加工始终作用于同一批当前成果：

  • 相同伙伴再次加工：再执行一次 ×2。
  • 不同伙伴再次加工：再执行一次 +A。
  • 1号位再次加工：再执行一次 +S。
  • 成果不会返回左侧，不新建独立批次。
  • 当前格全部加工完成后，成果只向右移动一次。

玩家规则可以压缩为：

1号伙伴找到成果，后面的伙伴依次加工；相同伙伴翻倍，不同伙伴补充。

2. 基础事件示例#

五位不同伙伴#

10 → +10 → 20 → +10 → 30 → +10 → 40 → +10 → 50

五次相同伙伴#

10 → ×2 → 20 → ×2 → 40 → ×2 → 80 → ×2 → 160

相同、不同、相同、不同#

10 → ×2 → 20 → +10 → 30 → ×2 → 60 → +10 → 70

不同、相同、不同、相同#

10 → +10 → 20 → ×2 → 40 → +10 → 50 → ×2 → 100

在 S=A=10 时，第一个相邻关系无论相同或不同都会得到20。它可以作为新手容错：第二张牌没有数值陷阱，真正的加工顺序差异从第三张开始。

3. 三张手牌与刷新模拟#

模拟使用五种伙伴各5张、伙伴手牌3张、打出后补牌、每轮2次刷新。简单策略根据当前可见收益选择伙伴；从第3张开始，如果手中没有当前更优的相邻关系则使用刷新。

每种条件模拟100,000轮：

条件单轮均值P10中位数P90五连率平均相同连接
不使用刷新81.8760801200.17%1.85
使用2次刷新99.30701001603.41%2.39

结论：

  • “连续相同更高”是直观方向，但三张手牌并不能稳定保证后段连续相同。
  • 玩家每轮通常只能形成约2—3条相同连接，五连仍是低概率结果。
  • 手牌与补牌不确定性足以阻止玩家稳定执行一条固定算式；后续仍需验证工具牌是否会把它变成过度稳定的答案。

以下名称和稳定 ID 仅用于与当前目录对照；效果是纸面候选，不写回运行时。

稳定 ID名称候选效果主要职责

double_layer_box酒葫芦此格为相同伙伴时，额外加工1次。局部乘法

tempering_furnace斗笠每累计完成4次不同伙伴的首次加工，补充量永久+5。补充成长
spring_scale玉佩此格相同加工次数+1；每累计完成6次相同伙伴的首次加工，再永久+1，最多+8。连续加工成长
five_color_book镜子本轮最后一次相同加工次数+1；每累计完成6次不同伙伴的首次加工，再永久+1，最多+8。补充转精加工

设计原则：

  • 普通道具只有一个主要用途。
  • 道具只修改全局参数或当前格加工，不直接描述“右侧伙伴”。
  • 永久成长只统计每条连接的首次加工，不让额外加工反过来加速自身成长。
  • ×2因子固定；成长增加的是可见的加工次数。

重要假设#

这是一轮“机制能否达到目标”的乐观筛查，不是正式平衡结论：

  • 每条路线按固定理想顺序获得5件指定道具，不模拟奖励池暴露率。
  • 每轮使用一副重新洗好的25张伙伴牌。
  • 局部道具在五张牌全部明确后按最高收益位置摆放。
  • 不使用工具牌，不应用特别状况。
  • 使用简单可见策略和每轮2次刷新，不读取未来抽牌。

6. 数值结论#

当前目标与单批加工并不冲突#

单批成果仍能达到百万目标，不需要独立批次或返回左侧。但第4章要求成熟构筑在单轮稳定产出约250,000，因此必须具备下列至少一种增长：

  • 较高的初始成果；
  • 较高的不同伙伴补充量；
  • 约8—12次总计有效的 ×2 加工；
  • 加法积累后在尾段接受多次相同伙伴加工。

基础五格最多提供4次相同加工。因此当前百万目标通常要求道具在后期额外提供约6—8次相同加工，或允许初始成果/补充量成长到很大的局部数值。

静态加值不能独立承担16关增长#

饭团、莲花、羽毛笔等固定加值能够改善第一章体验，但“局部加工·临场适配”在第6关完全停止。固定数值道具必须承担前期稳定和过渡，不应被当作完整后期路线。

两条成长路线的节奏不同#

  • 初始成果·连续加工在形成后非常稳定，当前纸面参数偏强。
  • 沿途补充·尾段精加工在第3—4关存在明显成型断层，但成功进入成长阶段后可以覆盖百万目标。
  • 这说明补充路线需要更早的有效种子或更平滑的成长阈值，不能要求玩家先弱四关再突然起飞。

不能让单件成长道具成为唯一通行证#

模拟中玉佩和镜子的最高 +8次加工 是为了检查当前目标的数量级，不代表最终批准值。若完整目录只有这一类道具能覆盖第4章，它们会成为事实上的必选件。

正式内容应把后期加工能力拆成不同来源，例如：

  • 当前格固定多加工1次；
  • 达成相邻条件后多加工；
  • 工具使用后临时多加工；
  • 初始成果和补充量成长；
  • 5号位收尾加工；
  • 把前段加法成果转化为后段加工次数。

7. 视觉与事件合同#

当前格再次加工#

成果不返回左侧：

  1. 粒子团从左侧进入当前伙伴。
  2. 当前数值停留在伙伴上方。
  3. 伙伴每次加工播放一次短促本地动作。
  4. 相同伙伴显示一次 ×2 并复制现有粒子轮廓。
  5. 不同伙伴显示一次 +A 并汇入一小团新粒子。
  6. 多次加工时数字在原地逐次变化。
  7. 当前格全部加工完成后，粒子团只向右移动一次。

高次数使用压缩表现：

×2  ×5
80 → 2,560

可先演出首个和末个加工，中间用快速连击与次数角标压缩；Core仍返回每次加工后的精确数值序列。

5号位结算#

5号位先完成自身全部加工，再把唯一成果团送入地点卡目标。地点目标只在成果抵达时扣减，不保留独立牌型或固定倍率撞击阶段。

出牌预览#

连接上直接显示本次运算和预览结果：

10 → +10 → 20 → ×2 → 40 → +10 → 50 → ×2 → 100

不得显示容易触发数学优先级误读的单行算式 10+10×2+10×2。

8. 下一轮原型检查#

  1. 用真实牌库持续状态替换“每轮新牌库”假设，核对整关与跨轮方差。
  2. 加入铁锹、远镜等修型工具，检查五连率和尾段连续加工是否被推到过度稳定。
  3. 不扩充完整30件目录；先调整补充路线的第3—4关断层，并把后期额外加工能力拆分到多件道具后重跑获取概率。

完整机器结果见 outputs/arithmetic-pipeline-v0.1-simulation.json，可复现脚本见 scripts/simulate-arithmetic-pipeline-v01.mjs。
