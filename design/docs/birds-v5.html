一、版本结论#

v0.5 从五关扩展到十关，但重点不是把现有波次复制一遍。当前体验平淡的根源是：玩家进入专注后拥有很大的行动优势，而鸟通常只攻击一次，弹丸又会被优先、快速锁定；因此玩家很少真正面对“继续贪一只鸟，还是立刻松手保命”的压力。

本版同时解决三件事：

  1. 用持续攻击、错峰威胁和两种新敌人建立中后期挑战。
  2. 把九次二选一改成可升级的构筑过程，让后期常见六至八个标记、九至十二声枪响的夸张齐射。
  3. 补齐主界面、暂停、继续、重新开始和返回主界面的局内闭环。

二、当前难度平淡的结构性原因#

  • 世界在专注时降至 22%，但准星仍按真实时间推进，玩家对弹丸拥有很大的相对速度优势。
  • 弹丸锁定只需 0.22—0.28秒，且自动优先，单枚威胁几乎不会迫使玩家提前松手。
  • 大多数鸟完成一次攻击后便不再制造压力；玩家只拦弹、不击落鸟也经常可以自然清场。
  • 多枚弹丸若同时命中，会被 0.65秒 受击保护压缩成一次伤害，表面密度没有转化成实际危险。
  • 当前四次升级以数值增强为主，锁定容量通常只从四个变成五个，后期齐射规模没有显著跨越。

因此，本版不采用“所有弹丸直接加速一倍”的办法。纯弹速会缩短反应时间，却不一定增加有趣判断。

三、难度规则调整#

1. 持续攻击#

  • 普通鸟若仍在场，第一次射击后会在 1.8—2.5秒 后再装填一次；单次飞越最多攻击两次。
  • 快枪鸟仍保持一次高速射击，避免连续快弹造成不可读伤害。
  • 连发鸟保持一轮两发，但高关卡允许完成第二轮连发；第二轮必须重新展示双发预警。
  • 击落攻击者因此成为真正的减压手段，不能长期只拦弹等鸟飞走。

2. 错峰威胁#

  • 关卡脚本把危险弹丸间隔控制在 0.55—0.9秒，让受击保护不再吞掉整轮攻击。
  • 同一批威胁必须有连续可见预警，不用不可见随机数偷袭玩家。
  • 中后期每波至少形成一次“当前准星快锁完鸟时，第一枚弹丸进入”的抢断局面。

3. 基础参数候选#

以下是首轮测试值，不视为最终平衡：

参数v0.4v0.5首测值目的
专注世界速度22%26%保留子弹时间感，同时让威胁仍有轻微推进
受击保护0.65秒0.48秒让明确错开的攻击可以分别造成伤害
普通弹锁定0.28秒0.32秒避免弹丸优先等于无条件化解
快弹锁定0.22秒0.25秒快枪鸟仍可反应，但需要更早松手

齐射世界速度8%10%仍保护已承诺齐射，不削弱爽点

公平底线：玩家已看见预警、拥有至少 0.6秒 专注并立刻反应时，不允许脚本制造必定受伤的局面。

四、两种新敌人#

1. 回旋鸟#

  • 第一次飞出边缘后掉头返回，不算清除。
  • 每次经过战场只攻击一次，最多经过两次。
  • 轮廓使用回旋翼或弧形尾迹，边缘掉头前显示回转箭头。
  • 作用：让“只拦弹、不击落攻击者”的保守打法付出持续压力。

2. 俯冲鸟#

  • 入场后先横向飞行，出现清楚的向下箭头预警，再转向玩家俯冲。
  • 俯冲阶段被视为最高优先级威胁，可像弹丸一样快速锁定。
  • 撞到玩家失去一颗心，鸟同时消失。
  • 作用：制造必须松手的明确时刻，同时仍使用原有长按、自动锁定、松手齐射语法。

本版不加入护盾、无敌、反锁定和不可拦截弹丸。这些规则会否定自动锁定的核心便利，而不是压力玩家的松手判断。

五、十关结构#

总计 31波，目标一局 6—9分钟。

关卡波数单位数内容职责
第1关22 / 3无文字教学，完成第一次有效齐射
第2关33 / 4 / 5普通鸟二次装填，第一次出现持续压力
第3关33 / 4 / 5快枪鸟抢断长按
第4关33 / 4 / 5连发鸟测试等待第二弹的判断
第5关34 / 5 / 6三类混编，作为前半程检查点
第6关34 / 5 / 6回旋鸟登场，不能靠放走敌人清场
第7关34 / 5 / 6俯冲鸟登场，第一次明确强制松手
第8关35 / 6 / 7回旋、快枪与连发形成持续战线
第9关45 / 6 / 7 / 8多轮错峰攻击，测试专注管理
第10关46 / 7 / 8 / 10综合决战，以大规模齐射收束整局

难度情绪：1—2关理解 → 3—4关第一次受压 → 5关小胜 → 6—7关改变习惯 → 8—9关构筑兑现 → 10关连续大齐射。

六、升级架构#

1. 九次二选一与等级#

  • 前九关结束后均进行二选一。
  • 升级不再全部“一次获得后永久移出池”，而是带有 Lv.1—Lv.3。
  • 卡面必须显示当前等级和升级后的确切变化。
  • 选择池保证至少一个选项不是纯数值强化，避免连续两次只看到速度或时长。

2. 现有升级等级化#

升级等级效果建议
快眼每级锁定速度 +15%，最高3级
多重标记每级容量 +1，最高3级；容量上限7

3. 六项新升级#

升级效果改变的行为
连珠准星每完成第3个锁定，额外标记一个可用目标；Lv.2改为每第2个更容易积累大齐射，但仍受容量限制
顺风眼同一次长按内，每完成一个锁定，后续锁定加速10%，上限30%/50%鼓励继续按住形成连锁节奏
屏息每个锁定返还0.10/0.16秒专注，单次长按最多返还0.6/0.9秒为六至八标记提供可控成长路径
余响弹松手时已有4个标记，主齐射后追加2/3枪攻击仍存活威胁明确奖励贪到四标，制造后半段枪声高潮
追凶拦截弹丸时，将仍在场的发射者追加为一个奖励标记；每次长按1/2次把防守操作转化为反击齐射
双枪主齐射每第3/第2枪追加一发副枪，攻击最近未标记目标后期枪数显著超过标记数，形成视觉跨越

奖励标记和副枪不会再次触发连珠准星，避免无限递归。所有追加射击都属于同一个玩家感知齐射段，枪声音阶与连击不得重置。

4. 后期规模目标#

  • 无容量升级：常见 4标记 → 4—7枪。
  • 一至两级容量：常见 5—6标记 → 7—10枪。
  • 成型连射构筑：峰值 7—8标记 → 9—12枪。
  • 追加枪必须优先寻找仍存活目标；没有目标时不空放大量无意义枪声。

七、暂停与主界面规则#

  • 主界面提供“开始游戏”。
  • 局内右上角提供暂停按钮。
  • 暂停后保留当前关卡、波次、专注、锁定队列和飞行物位置。
  • 暂停菜单提供“继续游戏、重新开始、返回主界面”。
  • 重新开始直接开启全新第一关，不弹第二次确认；当前原型没有不可恢复的长期资源。
  • 返回主界面清空本局状态。
  • 暂停时玩法更新与程序化音频同时停止；恢复后继续原有子弹时间或齐射状态。

八、验证标准#

  • 熟悉玩法的玩家不能再无脑长按到容量满；第5关以后每关至少出现一次主动提前松手。
  • 没有升级的自动测试应在第6—8关出现明显失败风险，但任何单个脚本局面都不得造成不可避免伤害。
  • 正常构筑在第8关以后平均齐射规模达到6枪以上，第10关至少出现一次8枪以上齐射机会。
  • 玩家能从行为而非颜色说出回旋鸟和俯冲鸟的区别。
  • 暂停中等待5秒，关卡时间、专注、目标位置与弹丸位置均不变化。
  • 暂停后继续、重新开始、返回主界面三条路径均无残留锁定、音效或旧弹丸。
  • 锁定、奖励标记、主齐射和追加枪的整个收益段不会被换波、暂停或过关截断。

九、实施顺序#

v0.5a：压力骨架#

  1. 完成主界面与暂停闭环。
  2. 为鸟加入装填次数、再次预警和错峰攻击脚本。
  3. 调整五个基础参数，先把现有五关打出压力。
  4. 将配置扩成十关31波。

v0.5b：成长与新敌人#

  1. 升级系统支持等级、等级文案和选择池约束。
  2. 实现连珠准星、余响弹、屏息，先验证大齐射路径。
  3. 再实现顺风眼、追凶、双枪。
  4. 实现回旋鸟与俯冲鸟并放入第6—10关。
  5. 完成完整十关自动测试和至少三名玩家压力测试。

十、本版不做#

  • 不制作或细化正式美术素材。
  • 不加入角色移动、手动准星、弹药库存和换弹。
  • 不加入局外成长、金币、广告与任务系统。
  • 不用不可拦截攻击、强制禁用子弹时间等方式制造难度。
  • 暂不制作多阶段Boss；第10关先验证高密度综合战能否成立。
