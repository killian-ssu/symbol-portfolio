1. 共通规则#

  • 道具容量为5件，全部放在区域1–5，没有独立全局道具栏。
  • 区域按 1 → 5 从左到右结算。
  • “右侧”只指紧邻的下一个区域。
  • 产生行动再触发或道具再触发的效果只能影响右侧。
  • 作用于所有行动或当前牌型的道具也占据区域，也可以被再次触发。
  • 区域5的右侧触发效果失效，摆放时显示失效箭头。
  • 每小关结束后可以重新排列全部道具。
  • 成长先执行当前效果，再增加永久数值；同一轮后续触发使用成长后的数值。
  • 玩家只看到短文本；事件来源、条件、成长计数和防循环字段保存在配置中。

文本只使用“此区域行动、左侧行动、右侧行动、右侧道具、所有行动、当前牌型”等表达。直接加分写作“+5”，倍率写作“+0.5倍率”。

2. 40件道具#

下表按阅读目的分组，不是玩家可见流派。所有道具遵守相同的区域放置规则。

2.1 分数、位置与成长效果#

道具玩家短文本开发说明
斧头此区域行动+5。每次触发给此区域行动增加5分。
手锯此区域行动+10。无条件单区域加分。
木楔此区域行动+2；每次触发永久+1。初始+2；每执行1次，后续效果值永久+1。
木槌此道具再次触发时，此区域行动+10。原始触发不加分，只奖励道具再次触发。
鱼叉此区域行动再次触发时，+10。只在行动再次触发事件中执行。
渔网此区域与右侧行动同类时，两张行动各+5。比较紧邻两张行动的最终玩家类型。
鱼篓此区域与右侧行动不同类时，右侧行动+10。为混合行动排列提供位置收益。
猎夹此区域行动类型永久+1。每次触发使此区域行动类型的本局基础分+1。
锄头每触发5次，当前牌型永久+0.5倍率。分别记录每种牌型的永久倍率成长。
铁锹每触发5次，获得1张随机工具牌。结算中获得，下一轮开始可以使用。

2.2 行动再次触发#

道具玩家短文本开发说明
草叉右侧行动再触发1次。增加右侧行动次数，并再次触发右侧道具。
种袋右侧行动再触发2次。草叉的高强度固定版本。
药袋右侧行动再触发1次；每触发5次永久+1次。每累计5次自身触发，重复次数永久+1。
矿灯此道具再次触发时，右侧行动再触发1次。需要左侧道具或扳手启动。
水壶此区域行动低于右侧时，右侧行动再触发1次。比较进入结算前的行动当前分数。

2.3 道具再次触发#

道具玩家短文本开发说明
药铲右侧道具触发1次；每触发4次永久+1次。通用成长型触发放大器。
竹篮右侧道具触发2次。通用固定放大器。
药瓶右侧道具触发2次；每触发6次永久+1次。后期核心成长放大器。
淘盘每轮第1次触发时，右侧道具触发3次。每轮强力启动一次，之后不再执行。
矿镐此道具再次触发时，右侧道具触发2次。需要其他放大器先触发矿镐。
铁筛此区域行动再次触发时，右侧道具触发1次。把行动再次触发转成道具再次触发。
火把本轮每使用1张工具牌，右侧道具多触发1次。本轮使用N张工具时触发右侧道具N次。
雨衣此区域与右侧行动同类时，右侧道具触发2次。同类行动条件放大器。
背包此区域与右侧行动不同类时，右侧道具触发2次。异类行动条件放大器。

2.4 全场范围效果#

这些道具仍然占据一个区域。“全场”只是效果目标，不是另一种道具栏位。

道具玩家短文本开发说明
罗盘所有行动+5。每次触发使五张行动各+5。
绳索所有行动+2；每次触发永久+1。初始全体+2，每次触发后效果值永久+1。
帐篷本轮每有1次行动再次触发，当前牌型+0.5倍率。触发时读取当轮累计行动再次触发次数。
木桶每触发5次，当前牌型永久+0.5倍率。以自身触发数培养当前牌型。
木箱三同类以上+1倍率。三、四、五同类都可以生效。
铁钉本轮每使用1张工具牌，所有行动+5。触发时按本轮工具使用数计算。
手套获得1张随机工具牌。获得的工具从下一轮可用。
皮靴获得1张拓纸。固定生成拓纸。
帽子本轮每有1次道具触发，所有行动+2。触发越晚或被重复触发时收益越高。
围巾五个区域都有道具时，所有行动+10。鼓励填满完整五件机器。
剪刀所有行动永久+1。每次触发使五类行动本局基础分各+1。
夹子每种行动类型使所有行动+2。按本轮五张行动中的不同类型数量计算。
小刀当前牌型+0.5倍率。每次触发都可以重复增加当前倍率。
布袋下个小关+1次刷新。多次触发可以积累下个小关刷新数。
提灯下次刷新多保留1张行动牌。保留数量最多为3张行动牌。
口哨获得1张网兜。固定生成换牌工具。

3. 10张工具牌#

3.1 工具手牌规则#

  • 行动手牌始终固定为3张。
  • 工具牌显示在同一手牌区域，但不占行动手牌数量。
  • 打出行动后补1张行动；打出工具不补牌。
  • 工具不进入行动牌库，只来自奖励或道具生成。
  • 未使用工具整局保留，同一轮没有使用数量上限。
  • 第5张行动确认前可以使用工具；确认后自动进入结算。
  • 结算中生成的工具从下一轮开始可用。

3.2 工具表#

工具牌玩家短文本目标与开发说明
彩布1张行动变为任意类型。选择手牌或已入场行动；影响行动累计。
磨石1张行动+10。选择手牌或已入场行动，本轮有效。
印板下一张补牌复制所选行动。选择1张行动手牌，只复制行动类型。
挂钩交换两张已入场行动。第5张行动确认前使用。
网兜丢弃1张行动手牌，补1张。不消耗刷新次数。
镜筒重抽1张行动手牌，可选3张。从3张候选中选1张替换目标。
木哨1个区域的行动再触发1次。登记到结算队列，同时触发该区域道具。
扳手1个区域的道具再触发1次。登记到结算队列，不增加行动次数。
拓纸上一张工具牌再生效1次。保存上一张工具的具体效果，不递归复制“复制指令”。
麻绳本轮所有行动再触发1次。五张行动各增加1次，并分别触发区域道具。

工具奖励应以工具组形式出现，避免单张消耗品与永久道具等价。普通工具组提供3张控制工具；木哨、扳手、拓纸和麻绳属于强工具，可单张或两张成组出现。

4. 组合纸测#

4.1 层层回声#

区域1 火把
→ 区域2 药瓶
→ 区域3 药铲
→ 区域4 药袋
→ 区域5 木楔
  • 火把根据本轮工具数触发药瓶。
  • 药瓶反复触发药铲。
  • 药铲反复触发药袋。
  • 药袋使区域5行动和木楔反复触发。
  • 木楔在同一轮中持续成长，越到后面单次加分越高。

4.2 牌型养成#

竹篮 → 药铲 → 药瓶 → 锄头 → 高价值行动

前三件道具不断触发锄头。锄头每5次使当前牌型永久+0.5倍率，使同一种牌型从前期过渡组件成长为后期爆分核心。

4.3 工具工厂#

火把 → 药瓶 → 药铲 → 铁锹 → 铁钉

第一轮大量触发铁锹，为下一轮积累工具；下一轮连续使用工具又强化火把和铁钉，形成“准备一轮、爆发一轮”的节奏。

4.4 全场加分#

竹篮 → 药瓶 → 药铲 → 绳索 → 帽子

绳索每次触发都永久成长并强化所有行动；帽子把整条链的道具触发数量再次转换成全场分数。该组合不要求固定行动类型。

4.5 分数标尺#

以下使用固定行动值的保守估计，没有计算木楔在同一轮继续成长产生的额外收益：

阶段分支次数核心效果次数单轮估分
三件基础链27360
五件基础链2312,910
成长链312136,500
成熟链4341375,500
极限成长链57812,343,600

极限成长链通过木哨、扳手和拓纸点燃10次，约为2,343万；点燃50次约为1.17亿。分数与触发次数不设置硬上限，但所有道具产生的新触发必须向右移动，保证队列最终结束。
