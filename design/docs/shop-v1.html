1. 主题与规则语言#

商人通过排列五类蘑菇释放孢子，突破沿途场景阻碍。

玩家规则只使用分数、目标分数、蘑菇、同类、异类、位置、行动、位置标签、旅费等常见词。场景、现象和道具名称可以使用菌雾、孢子、菌丝、菌环等主题包装，但效果文字必须直接说清条件、对象、数值和持续时间。

旧的“价值、伙伴、同色、异色、底货、货值、本格、加工、流水线”等词不再进入新增玩家文案。

2. 商店与位置标签候选规则#

  • 每关后进入商店，基础货架为 2 件道具、1 组位置标签、1 张工具牌。
  • 玩家可以连续购买、出售道具、花旅费换货，或直接离开并保留旅费。
  • 基础过关收入按章节为 8 / 10 / 12 / 14 旅费，章节终页额外 +2。
  • 普通、精良、稀有道具价格为 5 / 8 / 12；工具牌 3；换货 3。
  • 一组位置标签价格为 4，包含 3 枚同号普通标签，分别贴在 3 张蘑菇牌上。
  • 位置标签命中时只再次执行同类或异类基础规则，不再次触发道具。
  • 道具每轮第一张蘑菇打出前可以自由换位；第一张打出后锁定到本轮结束。
  • 一个道具货架位保护玩家当前缺少的功能角色，但只从一组候选中随机，不直接发指定道具；另一个位置完全自由抽取。

三枚同号标签和当前价格只是为解决“第一枚标签长时间抽不到”的候选数值，不是正式实现结论。

3. 目录设计原则#

42 件道具由 30 个旧稳定 ID 和 12 个新 ID 组成。功能分类只用于目录管理和事后分析，不作为玩家开局选择的流派。

  • 单件作用尽量只有一个主要目的。
  • 单件可以偏好某种位置或条件，但不能自动安排多张未来蘑菇。
  • 同类与异类是基础操作，不拆成两条预设流派。
  • 永久成长必须有多种入口，避免所有成熟构筑都必须拿同一件成长道具。
  • 位置标签道具分别支持首次命中、数字覆盖、长期成长、前后位置和向下一位接续，不由一件道具包办全部标签体验。
  • 经济道具占用正式道具位；玩家获得更多旅费的代价是少一个直接加分位置。

11. 自适应模拟方法#

模拟代理没有同类、异类或混合预设。每次打牌都独立比较五类理由：

  1. 这张牌此刻能产生的分数变化。
  2. 是否命中具体牌上的位置标签。
  3. 是否推进持有道具的永久成长。
  4. 是否满足当前道具位置的条件。
  5. 打出后给下一张牌留下什么选择。

“有意义出牌”要求至少存在另一个未被当前选择完全压倒的动作，并且它在关系、标签或某个非即时分数理由上更好。构筑组合只在远行结束后按最终道具功能归纳，不用于代理购买或出牌。

“构筑收敛率”使用至少通过前 8 个场景的成熟构筑作为样本，计算占比最高的事后功能组合。胜率单独报告，避免只用极少数通关样本得出构筑结论。

12. 800 次完整远行结果#

指标结果当前判断
有意义出牌率26.2%未达到 30% 目标；无构筑单轮对照为 28.1%
强制优势选择率29.9%偏高，部分道具条件仍把即时答案拉得过开
标签参与出牌率12.1%已从偶发彩蛋进入可感知选择，但仍不是主要决策来源
构筑收敛率21.4%通过；没有单一功能组合占据多数
最高单件成熟构筑占有率44.8%通过 65% 上限
平均道具组合相似度13.4%分散度良好
单件导致固定排列0 / 42通过；旧版两件 DDDD 风险已消除
占比至少 5% 的成熟组合4 组未达到 5 组目标；另两组均为 4.8%，接近边界
完整 16 场景通关率2.3%明显过低，当前目标分数下成长仍不够稳定

成熟构筑中占比最高的四组是：

  • 永久成长 + 位置标签：21.4%。
  • 排列条件 + 永久成长：21.0%。
  • 行动与位置 + 排列条件：15.1%。
  • 行动与位置 + 永久成长：7.1%。

商店行为不是摆设：平均购买 4.24 件道具、2.75 组标签和 1.91 张工具；34.5% 的远行出售过道具，36.1% 发生过主功能转向，6.7% 的商店被直接跳过。换货平均只有 0.28 次，说明当前代理更愿意存钱或购买现货，换货价值仍偏低。

13. 当前结论#

这版证明了两件事：

  1. 商店、标签和完整目录可以让构筑结果明显分散，且不需要预设同类、异类流派；42 件中没有一件单独把出牌压成固定排列。
  2. 构筑分散不等于出牌更丰富。当前目录把不少策略留在购买阶段，有意义出牌率反而比无构筑单轮对照低 1.9 个百分点，完整通关率也只有 2.3%。

因此 v0.1 不应直接接入正式配置。下一轮应优先做：

  • 把 2—3 件只提供数值的道具改成“眼前分数较低，但能推进标签或永久成长”的明确出牌权衡件。
  • 让工具和经济组合更稳定地进入成熟构筑；目前成长、排列和标签仍占据主要组合。
  • 继续提高非“落脚菌床”成长入口的后期稳定性，但不把单件数值继续无条件放大。
  • 用无标签商店对照和完整商店对照比较同一阶段的有意义出牌率，分清是标签密度不足，还是强道具条件压缩了选择。
  • 重新校准最后四个场景的目标或成长速度，使自适应构筑有足够通关样本，再测试胜局收敛。
