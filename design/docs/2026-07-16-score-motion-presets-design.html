档案说明

这是 2026-09-19 从工程收录的文本，可能包含后来补写的注释。正文中的“当前”“已实现”保留原有语境，不代表本站试玩版已逐项复验。

日期：2026-07-16

目标#

把网页试播中的四种分数动效保存为可长期检索、可跨组件复用的预设，并确定《远行商人》当前使用方向：

  • 分数区、倍率区、目标分等固定位置数值统一使用 B“累计滚分弹跳”。
  • 行动格使用 C“短延迟爆分”和 D“连击递进”的合成版；每次行动都产生一条独立上浮分数，并与行动格重击保持同一节拍。

本设计只改变表现，不改变计分公式、触发次数或目标判定。

保存的预设#

四个原始候选必须保留，不能因为当前未接入而删除：

  1. A score_setter_pop_video_v1：视频原版 Setter 数值弹跳。
  2. B score_value_roll_pop_v1：累计滚分弹跳。
  3. C score_cell_burst_v1：单击后的短延迟上浮爆分。
  4. D score_combo_ramp_v1：同一个计数器在连击中递进弹跳。

新增第五个组合预设：

  1. score_cell_combo_burst_v1：每一击独立上浮淡出，同时采用递减间隔和递增强度。

稳定 ID、中文名、首版参数和使用记录统一登记在 docs/ui-motion/UI_MOTION_CATALOG.md。实现后五个条目都写入共享 ui_motion_library.prefab，业务 Prefab 只保存稳定 ID。

固定数值区：B#

使用范围#

  • 结算分数区
  • 倍率区
  • 目标分
  • 后续其他固定位置的资源数值

行为#

  • 数字从当前画面值滚动至目标值，递增和递减使用同一模板。
  • 数值变化开始时播放一次克制的 Back Out 弹跳和轻微随机旋转。
  • 动画尚未结束又收到新值时，从当前画面值和当前变换接管，不先跳回旧值或原尺寸。
  • 数字格式继续使用现有格式化函数；动效组件不决定小数位、倍率前缀或大数缩写。

行动格：C+D 合成版#

单一节拍源#

行动格和浮字不得各自计算一遍连击时间。board_impact_combo_strong_v1 产生唯一的击次调度；每个调度点同时执行：

  1. 行动格打击回弹。
  2. 创建该击专属的分数浮字。

这样两者始终处于同一帧，不会随着击数增加逐渐错拍。

连击规则#

  • 击数等于 Core 实际 ORIGINAL_ACTION 与 RETRIGGER_ACTION 次数，不设上限。
  • 第 1 击到第 2 击间隔 0.31s，之后每次乘 0.82，最短 0.09s。
  • 强度从 1.0 开始，每击增加 0.18，在 1.95 封顶。
  • 首击方向随机，后续左右交替；浮字与行动格使用相同方向。
  • 每击浮字都是独立实例，按自己的 0.78s 上浮淡出。高连击允许多条浮字同时存在。
  • 幅度可以封顶，击数不能封顶。

分数数据#

每击显示值必须来自 Core。实现时由结算结果增加按区域组织的行动分数表现批次，至少表达：区域、真实击数和每击分数增量。UI 只按顺序播放，不得将该格总分除以击数，也不得自行应用倍率或道具规则。

如果 Core 将大量相同击次压缩为批次，表现数据可以用“重复次数 + 单击值”保存；只有单击值确实变化时才需要值序列。无论采用哪种结构，展开后的视觉击数必须与 Core 一致。

组件边界#

  • UIMotionPresetLibraryComp：保存和按 ID 查找五种分数预设。
  • 固定数值播放器：负责数字插值、X/Y 缩放和旋转接管，不负责格式化或业务计算。
  • 行动格连击调度：继续负责唯一击次时钟，并在每击回调中同时通知格子和浮字。
  • 浮字播放器：负责单条浮字的缩放、旋转、上浮、淡出和回收。
  • GameMainViewComp：只连接 Core 输出、HUD 与行动格表现，不保存曲线参数。

所有颜色、字体、锚点、浮字偏移和模板参数由 Prefab 与 @property 控制；运行时代码不覆盖 Creator 中调好的美术值。

失败与中断处理#

  • 节点被关闭或销毁时，停止本组件拥有的 Tween，并恢复需要复用的固定节点。
  • 固定数值动画被新值打断时接管当前状态。
  • 行动格开始新一轮结算时停止旧调度；已经生成的独立浮字可以完成淡出，但不能继续修改 HUD 数值。
  • 找不到预设 ID 时记录一次警告并使用安全后备参数，不能中断结算。

验收#

  • 资产库按稳定 ID 能找到 A、B、C、D 和 C+D 五个预设。
  • 分数区、倍率区、目标分都使用 B，并能正确展示递增、递减和中途改值。
  • 13 次行动触发产生 13 次行动格打击和 13 条独立浮字，不存在 8 次上限。
  • 每一击的格子打击与浮字生成发生在同一个调度回调；时间间隔和强度序列与 board_impact_combo_strong_v1 一致。
  • 每击浮字显示 Core 提供的值，UI 不反推分数。
  • 实验室能分别循环预览 B、原始 C、原始 D 和 C+D 合成版，并可修改演示击数。
