本文把行动累计、随机 Boss、右向道具连锁和局末藏品连接成一套可配置规则。机器可读配置位于：

  • data/action_progression.json
  • data/boss_rules.json

可执行参考位于：

  • scripts/action_boss_rules.py
  • scripts/validate_action_boss_config.py
  • tests/test_action_boss_rules.py

1. 行动累计#

顶部同时显示五类行动的当前进度和本局加成：

伐木 7/10 +4  渔猎 3/10 +2  垦荒 5/10 +0
采药 1/10 +2  淘金 8/10 +0

基础规则：

  • 初始行动分数为 10。
  • 每种行动独立累计。
  • 每打出10张同类原始行动，该行动本局永久 +2，进度扣除10后继续累计。
  • 升级发生在当轮分数计算前，所以刚满10张的本轮也使用新分数。
  • 行动再次触发、道具再次触发不增加行动累计。
  • 工具改色发生在玩家选择阶段，按工具改色后的类型累计。
  • Boss 强制改色只改变场景结算类型，不改写玩家行动累计。

推荐状态结构：

type ActionProgress = {
  totalCount: number;
  progress: number;
  level: number;
  scoreBonus: number;
};

type RunActionState = Record<ActionType, ActionProgress>;

当轮应保留两份类型：

type PlacedAction = {
  playerType: ActionType;   // 工具处理后、Boss处理前，用于累计和Boss应对
  resolvedType: ActionType; // Boss处理后，用于牌型和最终分数
};

2. 与右向道具链的边界#

  • 五件道具放在区域1–5，按 1 → 5 结算。
  • 制造新触发的道具只能影响紧邻右侧。
  • 全场效果道具同样占据一个区域，也可以被再次触发。
  • 行动再次触发时，该区域道具再次执行。
  • 行动累计只读取每轮五张 playerType，不读取触发队列。
  • Boss 规则不能永久删除道具、行动成长或整局工具。
  • 不设置整轮总触发次数上限；通过目标区域索引严格递增避免无限循环。

触发顺序：

第五张行动入场
→ 提交五张 playerType
→ 更新行动累计与Boss应对
→ 若达到应对条件，立即解除Boss规则
→ Boss规则生成 resolvedType 与当轮限制
→ 区域1至5执行原始触发和右向连锁
→ 计算行动分数、牌型倍率与本轮探索度

3. Boss 抽取与解除#

每个地点有5条规则。进入Boss关时只按地点等概率抽取1条，不读取玩家道具、工具或行动成长。

进入Boss关的界面顺序：

  1. 抽取并公开场景限制。
  2. 根据规则系数计算并显示最终探索度目标。
  3. 显示应对行动与进度。
  4. 允许玩家重新排列五件道具。
  5. 开始第一轮。

可解除规则使用：

type BossCounter = {
  action: ActionType;
  required: number;
  count: number;
  broken: boolean;
};

达到要求时在当轮结算前解除。强构筑也可以不解除，直接以受限分数过关。

最终目标：

最终Boss目标 = 章节Boss基础目标 × 规则目标系数

规则系数不向玩家显示，只显示最后的整数目标。

5. 藏品联动#

行动次数只改变品类权重，不改变稀有度：

  • 使用次数最高的行动：对应标签权重 ×2。
  • 使用次数第二高的行动：对应标签权重 ×1.5。
  • 同一名次并列时全部获得该档权重。
  • 所有行动均为0时不加权。

标签来自 action_progression.json，地点货品池负责把标签映射到实际藏品。

普通Boss规则在成功解除后额外生成1个地点藏品候选，并保留稀有度较高者。金砂税不可解除，改为通关后额外生成1个候选。

稀有度继续由到达地点、通关情况、最高单轮探索度和高阶牌型决定。行动使用次数不能直接保证高稀有度。

7. 当前不实施#

  • 不根据玩家构筑针对性抽取Boss规则。
  • 不让行动再次触发灌入行动累计。
  • 不让行动累计直接决定藏品稀有度。
  • 不实现地点路线分叉或事件系统。
  • 不给Boss设置永久删除道具、成长或工具的规则。

保留 totalCount、level 和 bossRuleBroken，供未来事件与路线系统读取。
