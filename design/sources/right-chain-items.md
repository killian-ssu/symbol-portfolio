## 1. 共通规则

- 道具容量为5件，全部放在区域1–5，没有独立全局道具栏。
- 区域按 `1 → 5` 从左到右结算。
- “右侧”只指紧邻的下一个区域。
- 产生行动再触发或道具再触发的效果只能影响右侧。
- 作用于所有行动或当前牌型的道具也占据区域，也可以被再次触发。
- 区域5的右侧触发效果失效，摆放时显示失效箭头。
- 每小关结束后可以重新排列全部道具。
- 成长先执行当前效果，再增加永久数值；同一轮后续触发使用成长后的数值。
- 玩家只看到短文本；事件来源、条件、成长计数和防循环字段保存在配置中。

文本只使用“此区域行动、左侧行动、右侧行动、右侧道具、所有行动、当前牌型”等表达。直接加分写作“+5”，倍率写作“+0.5倍率”。

## 3. 10张工具牌

### 3.1 工具手牌规则

- 行动手牌始终固定为3张。
- 工具牌显示在同一手牌区域，但不占行动手牌数量。
- 打出行动后补1张行动；打出工具不补牌。
- 工具不进入行动牌库，只来自奖励或道具生成。
- 未使用工具整局保留，同一轮没有使用数量上限。
- 第5张行动确认前可以使用工具；确认后自动进入结算。
- 结算中生成的工具从下一轮开始可用。

### 3.2 工具表

| 工具牌 | 玩家短文本 | 目标与开发说明 |
|---|---|---|
| 彩布 | 1张行动变为任意类型。 | 选择手牌或已入场行动；影响行动累计。 |
| 磨石 | 1张行动+10。 | 选择手牌或已入场行动，本轮有效。 |
| 印板 | 下一张补牌复制所选行动。 | 选择1张行动手牌，只复制行动类型。 |
| 挂钩 | 交换两张已入场行动。 | 第5张行动确认前使用。 |
| 网兜 | 丢弃1张行动手牌，补1张。 | 不消耗刷新次数。 |
| 镜筒 | 重抽1张行动手牌，可选3张。 | 从3张候选中选1张替换目标。 |
| 木哨 | 1个区域的行动再触发1次。 | 登记到结算队列，同时触发该区域道具。 |
| 扳手 | 1个区域的道具再触发1次。 | 登记到结算队列，不增加行动次数。 |
| 拓纸 | 上一张工具牌再生效1次。 | 保存上一张工具的具体效果，不递归复制“复制指令”。 |
| 麻绳 | 本轮所有行动再触发1次。 | 五张行动各增加1次，并分别触发区域道具。 |

工具奖励应以工具组形式出现，避免单张消耗品与永久道具等价。普通工具组提供3张控制工具；木哨、扳手、拓纸和麻绳属于强工具，可单张或两张成组出现。

## 4. 组合纸测

### 4.1 层层回声

```text
区域1 火把
→ 区域2 药瓶
→ 区域3 药铲
→ 区域4 药袋
→ 区域5 木楔
```

- 火把根据本轮工具数触发药瓶。
- 药瓶反复触发药铲。
- 药铲反复触发药袋。
- 药袋使区域5行动和木楔反复触发。
- 木楔在同一轮中持续成长，越到后面单次加分越高。

### 4.2 牌型养成

```text
竹篮 → 药铲 → 药瓶 → 锄头 → 高价值行动
```

前三件道具不断触发锄头。锄头每5次使当前牌型永久+0.5倍率，使同一种牌型从前期过渡组件成长为后期爆分核心。

### 4.3 工具工厂

```text
火把 → 药瓶 → 药铲 → 铁锹 → 铁钉
```

第一轮大量触发铁锹，为下一轮积累工具；下一轮连续使用工具又强化火把和铁钉，形成“准备一轮、爆发一轮”的节奏。

### 4.4 全场加分

```text
竹篮 → 药瓶 → 药铲 → 绳索 → 帽子
```

绳索每次触发都永久成长并强化所有行动；帽子把整条链的道具触发数量再次转换成全场分数。该组合不要求固定行动类型。

### 4.5 分数标尺

以下使用固定行动值的保守估计，没有计算木楔在同一轮继续成长产生的额外收益：

| 阶段 | 分支次数 | 核心效果次数 | 单轮估分 |
|---|---:|---:|---:|
| 三件基础链 | 2 | 7 | 360 |
| 五件基础链 | 2 | 31 | 2,910 |
| 成长链 | 3 | 121 | 36,500 |
| 成熟链 | 4 | 341 | 375,500 |
| 极限成长链 | 5 | 781 | 2,343,600 |

极限成长链通过木哨、扳手和拓纸点燃10次，约为2,343万；点燃50次约为1.17亿。分数与触发次数不设置硬上限，但所有道具产生的新触发必须向右移动，保证队列最终结束。
