# 《刀刀厨神》式简洁表现迁移清单

> 状态：地鼠主题历史美术路线，当前不再作为实现依据；正式美术将按《子时已到》的幽灵与幽灵猎手方向另行替换。

## 先说明当前差距

目前 Noon 已经有正式背景、拆件玩家、三种地鼠、土堆序列、瞄准环、爆炸、爆分、后坐力和基础粒子，但看起来仍像“功能完整的原型”。缺口不主要是继续增加图片数量，而是下面五套规则还没有统一：

1. **画面层级**：普通单位、特殊单位、Boss、玩家、HUD 的尺寸层级尚未形成。普通地鼠此前过大，无法支持后期成片出现。
2. **UI 皮肤系统**：弹窗、按钮、标题、数值、图标底框仍混用程序色块，没有统一圆角、描边、阴影、按压态和字体规格。
3. **动作语法**：单个动画已经存在，但“预备 → 主动作 → 超调 → 回稳”的节拍还没有覆盖所有事件。
4. **命中反馈栈**：爆炸和爆分已有，仍缺统一的接触闪白、极短停顿、受击压缩、方向性飞散与强弱分级。
5. **威胁可读性**：普通投石、快射、二连射需要在地鼠造型、预警颜色、拖尾形状和声音上形成同一套识别合同。

## 迁移顺序

### 阶段 0：玩法灰盒稳定

- 基础四锁稳定成立。
- 第一关有最低一名攻击者，第五关有三名攻击者；第四关起射手二连发。
- 普通地鼠约为原尺寸的 `52%`。
- 这一阶段只验证“爽感和压力能否同时成立”，不继续增加大量美术内容。

### 阶段 1：三个代表事件的风格样片

先只打磨三个完整事件，并用实际循环或分帧图验收：

1. 地鼠出洞：松土预备、洞口展开、地鼠拉伸钻出、落稳待机。
2. 四连射：锁定确认、松手蓄势、逐发后坐、弹道拖尾、四次命中与连击爆分。
3. 玩家受击：石块命中、角色闪白压缩、表情切换、红色边缘反馈、短暂停顿。

这三个样片批准后，才把同样的时长、曲线、缩放幅度和配色批量迁移到其他事件。

### 阶段 2：UI 统一换皮

- 使用 `午时已到/ui/ 弹窗.png` 制作九宫格弹窗底板。
- 使用 ` 设置框.png` 和 `金币框.png` 形成方形图标按钮与横向主按钮。
- 每个按钮必须有正常、按下、不可用三态；按下态用 `0.94–0.97` 缩放和轻微下沉，不只换颜色。
- 顶部 HUD 固定为关卡、心、耐力、子弹；升级图标等语义确定后再放到玩家下方。
- 统一标题、正文、数值、爆分四级字号和描边规则，避免每个界面单独决定。

### 阶段 3：动作语法覆盖

为所有动作统一四段式模板：

- 预备：`60–120ms`，小幅反方向或压缩。
- 主动作：`80–180ms`，快速完成主要位移/缩放。
- 超调：`50–100ms`，超过目标约 `5–12%`。
- 回稳：`80–180ms`，回到待机状态。

需要覆盖：地鼠出入洞、攻击前摇、枪械后坐、按钮、弹窗、升级获得、关卡切换、失败和结算。

### 阶段 4：战斗反馈分级

- 普通命中：小闪白 + 小爆炸 + 单次爆分。
- 连击命中：爆炸颜色交替、爆分叠加、逐发后坐增强。
- 特殊/范围命中：更大的彩色爆炸、额外飞散、轻微镜头冲击。
- Boss 命中：独立受击层、明显但受控的停顿，不能只把普通爆炸放大。
- 石块拖尾以旧项目 `MotionStreak` 作柔光外层，连续轨迹光带作稳定主体；固定胶囊图不再承担主拖尾。

### 阶段 5：特殊单位与 Boss

- 普通地鼠维持小尺寸和低视觉权重。
- 射手、二连射手通过配件、预警与拖尾区别，不只依靠速度数值。
- Boss 至少为普通地鼠的 `1.8–2.4` 倍，并拥有独立前摇、受击与阶段转换。
- 后期“成片出现”的压力优先来自阵型、攻击组合和连携，而不是所有单位一起放大。

### 阶段 6：声音、资源与性能收口

- 为锁定阶梯、锁满、四连射、普通石块、快射、受击、爆炸配置独立音色层级。
- 小粒子最长边约 `64px`，普通图标约 `128px`；统一透明边界和锚点。
- 合并图集、复用材质，检查移动端同屏粒子、拖尾和爆炸峰值。

## 仍需要补充或确认的美术

- 普通投石与快射各一套清晰的攻击前摇，最好是拆件或 4–6 帧短序列。
- 普通威胁、快射、二连射三种预警符号。
- 最终字体或可商用字体方向，以及数字/爆分描边规范。
- Boss 的尺寸、轮廓和阶段设定。
- 升级颜色与 icon 的正式语义；确认前不显示局内升级卡。

瞄准环不建议制作完整序列帧。最佳结构仍是静态底盘、程序圆弧、旋转准星和锁满击杀图标，这样进度能严格对应真实锁定时间。
