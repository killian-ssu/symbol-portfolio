# 蘑菇格子道具 v0.1 候选设计

> 状态：仅用于规则评审和模拟，尚未替换 Core / JSON 运行时真相源。

## 一、先锁定三种分数对象

1. **本轮分数**：从 0 开始，五个格子依次结算，过轮清空。道具文案必须写“本轮分数 +N / ×N”。
2. **这张蘑菇的分数**：25 张具体蘑菇各自持有，初始为 10。只有明写“这张蘑菇的分数永久 +N”才会带到后续回合。
3. **此道具的加分**：成长道具自己的状态。明写“此道具的加分永久 +N”；替换该道具后状态丢失，已长大的具体蘑菇不回退。

因此，旧文案“当前分数 +5”停用。如果只是本次结算流加分，统一写“本轮分数 +5”；如果改变具体卡，必须写“这张蘑菇的分数永久 +5”。

## 二、格子道具的局部边界

格子道具绑定一个格子，只在该格结算时执行。它可以读取：

- 当前格蘑菇的分数、标签和触发次数；
- Core 已经产生的“同类相接”事件；
- 此道具自己的成长状态；
- 流经当前格的本轮分数。

它不可以读取“左侧蘑菇有几枚标签”、其他格的道具状态、“5 号位”等跨格暗条件。“左侧蘑菇有标签时，此格……”的旧候选已删除。

末端格子的道具把已累积的本轮分数乘大，仍属于“当前格执行的局部效果”，不是常驻全局 Buff。

## 三、用“背靠背”方法组织构筑

不按“30 个独立点子”设计，而是让同一条基础管线的不同层互相做大：

1. **种子**：第一件道具单独拿到就有用，先抬高单次触发价值。
2. **成长值**：把具体蘑菇或道具自身慢慢养大。
3. **触发次数**：让已长大的蘑菇分、道具加分和标签多执行几次。
4. **末端兑现**：后段格子把前面累积的整体分数乘大。
5. **载体接口**：标签、具体蘑菇分和同类相接是多件道具共用的可见变量。
6. **获取规模**：金币不直接变成分数，而是增加购买和刷新机会。

一个格子只放一件道具，所以道具间不靠“同格叠两件”相乘。它们通过共用的具体蘑菇、同类相接、本轮分数和商店经济串成链。

## 四、基础规则和商店候选

- 每轮分数从 0 开始；具体蘑菇初始分数 10。
- 每次触发加入这张蘑菇的分数。
- 同类相接时，当前格额外触发 1 次。
- 单格最多触发 8 次，防止再触发、标签和成长道具形成无限链。
- 标准商店展示 2 件道具 + 2 枚标签；不再出现工具牌。
- 首个商店的其中 1 个道具位，保底一件普通种子道具；另 1 格保留完全随机。
- 最多持有 5 件格子道具，每格 1 件；后续可出售弱件换入成长或兑现件。
- 普通 / 稀有 / 罕见道具候选价格为 5 / 8 / 12 金币。

## 五、标签容量与升级

每张具体蘑菇最多同时持有 5 种不同标签：3 种普通 + 2 种炫彩。炫彩只是视觉层级，不是只能占一个的“封蜡槽”。

| 标签 | 层级 | 作用 |
| --- | --- | --- |
| 加分标签 | +10 / +30 / +100 | 每次触发加入本轮分数 |
| 乘分标签 | ×1.25 / ×1.5 / ×2 | 每次触发放大本轮分数 |
| 金币标签 | +1 / +2 / +4 | 每次触发获得金币 |
| 再触发炫彩标签 | +1 次触发 | 当前卡额外触发 |
| 随左炫彩标签 | 类型转换 | 结算时视为与左侧同类 |

同名数值标签不生成第二个图标，而是升级已有标签。购买后从 25 张牌库中抽出 3 张合法候选卡，放大高亮供选择；如果购买的是可升级标签且已有载体，候选中保底至少 1 张可升级载体。

本轮没把乘分标签设为初级 ×2、满级 ×2.5，因为它会随每次再触发重复执行，8 次触发下会变成指数尖峰。如果后续要采用 ×2 至 ×2.5，需同时改成“每轮首次触发生效”，不能只改数字。

## 七、模拟假设

- 25 张具体蘑菇，5 类各5 张；手牌 3 张，顺序打出 5 张。
- 每一次出牌穷举当前 3 张手牌能形成的合法序列，选择“本轮分数 + 永久成长 + 金币”效用最高的序列。
- 每关最多 4 轮；每次过关后进入商店。
- 商店每次最多模拟购买 1 件道具和 1 枚标签；没有合适道具时允许付费刷新 1 次。
- 道具购入后位置固定；满 5 件后允许出售弱件换入更强的成长 / 兑现件。
- 每条路线运行 300 局，同时对照旧标准目标和新规则候选目标。

## 八、测试结果

### 8.1 单件道具

- 30 / 30 件在自身条件可达成的首轮都能产生分数或金币价值，没有“必须先拿另一件才不是白板”的道具。
- 首轮等价增益中位数为 +20，P10 为 +10，P90 为 +40。
- 持有 8 轮后的单轮等价增益中位数为 +30，P90 为 +192，说明即时件提供下限，成长件拉开后期。

### 8.2 “背靠背”链条样本

| 链条 | 无道具 | 种子 | +触发层 | +末端层 |
| --- | ---: | ---: | ---: | ---: |
| 蘑菇分成长 → 20 分增触发 → 汇聚 | 160 | 400 | 420 | 482 |
| 道具自成长 → 触发数成长 → 汇聚 | 80 | 176 | 206 | 236 |
| 同类成长 → 同类增触发 → 同类倍率 | 80 | 440 | 470 | 611 |
| 标签成长 → 炫彩增触发 → 多触发倍率 | 130 | 349 | 359 | 502 |

每一层都在没有下一层时单独有价值，后一层则放大前面已建立的数值、触发或关系，而不是另起一套无关规则。

### 8.3 完整随机商店对局

旧标准目标最后四关为 3500 / 6500 / 12000 / 50000。在新基础规则下，6 组策略共 1800 局全部无法通关；这不应用“普通道具也 +1000”修补。

| 模拟路线 | 通关率 | 通过关数中位数 | 局内最高单轮分中位数 | 定位 |
| --- | ---: | ---: | ---: | --- |
| 直接加分·触发放大 | 8.7% | 11 | 641 | 起手 / 转型层，不宜当纯终局流派 |
| 蘑菇培育·分数转触发 | 38.3% | 15 | 1697 | 主流终局路线 |

## 九、当前结论

1. **道具不再围着标签打转**：30 件中只有 3 件标签接口道具，其余围绕蘑菇分、道具成长、触发、同类相接、末端兑现和经济。
2. **两个道具售卖位是合理的**：它们用来降低 30 件池子的随机性，不代表玩家每间商店都能买两件。首店再加 1 格种子保底，比恢复工具牌更直接。
3. **五格道具不是五个孤岛**：前格发育分数和触发，后格乘大整个本轮结果；同类相接和具体卡载体让不同格子的道具围绕同一套基础规则构筑。
4. **新道具不能沿用旧目标分**：先采用候选曲线继续人工试玩，再决定运行时目标；否则平衡会被迫变成“不抽到乘分尖峰就必输”。
5. **v0.1 还不是最终平衡**：标签路线应优先调整载体可见性 / 抽取衔接，不再继续暴力加大标签数值；经济道具保持支持件定位。

## 十、建议落地顺序

1. 先只把新基础触发管线、三种分数对象和具体卡永久分实现清楚。
2. 第一批实现 12 件：4 件即时规模 + 3 件蘑菇成长 + 2 件道具成长 + 1 件触发成长 + 2 件末端兑现。
3. 确认“前格发育、后格兑现”的结算时序和动画可读后，再加标签接口和经济道具。
4. 先跑候选目标曲线，不直接改写现行难度 JSON；人工试玩后再将数值升级为真相源。
