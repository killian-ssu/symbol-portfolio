# 《远行商人》视频式 UI 动效修订设计

日期：2026-07-14
状态：用户已确认，进入实现

## 目标

把现有“纯缩放压扁”试作版重做为视频中展示的多轨 Tween 结构，并适配手机触摸：

- `StartBtn` 与 `RefreshBtn` 在触摸开始时播放尺寸自适应的放大和随机方向旋转，触摸结束或取消时恢复。
- 5 个行动格在自动结算时播放并行的 X/Y 异步弹跳、随机方向旋转和延迟回正；分数在短暂打击延迟后出现。
- 保留结算顺序和连锁强度增长，不改变 Core 输出、分数或业务回调。

## 方案比较

### A. 给现有压缩动画补一个旋转

改动最小，但仍然是“压缩—拉伸—恢复”的串行动画，和视频的多轨 Back Out 节奏不同，不能解决当前观感问题。

### B. 复刻视频多轨结构并适配触摸（采用）

X 缩放、Y 缩放和旋转分别拥有自己的时长与延迟，并行作用于同一个运动状态；按钮用视频按钮参数，行动格用视频数值弹跳参数的收敛版。底层统一负责随机方向、基准变换、打断与恢复。

### C. 建立任意轨道的可视化动效资产系统

扩展能力最强，但当前只有按钮和行动格两类明确需求，制作编辑器资产会扩大试手感阶段的范围，本轮不做。

## 通用播放器

播放器记录目标节点的原始 `scale` 与 `angle`，每条轨道只修改一个内存状态字段，统一在 `onUpdate` 中把完整变换写回节点，避免两个 Tween 同时写整个 `Vec3` 而互相覆盖。

播放器必须满足：

- 新播放只停止播放器自己持有的 Tween，不调用 `stopAllByTarget`。
- 每次播放从基准或当前视觉状态计算，不累乘缩放误差。
- 随机旋转只随机正负方向，幅度由预设和强度决定。
- 停止、取消、禁用和销毁都恢复原始缩放与角度。
- 行动格旧动画被新动画打断时，旧的计分等待 Promise 也必须完成。
- 目标节点失效时停止写入，但不能阻塞结算。

纯 TypeScript 配置层提供尺寸衰减、强度限制和旋转幅度计算，供 Node 测试直接验证。

## 手机按钮动效

视频原本监听 hover/unhover；手机端映射为 `TOUCH_START` 与 `TOUCH_END/TOUCH_CANCEL`。按住时保持放大状态，但旋转会快速回正，不循环抖动。

默认参数：

- 参考宽度：`200px`；尺寸系数为 `clamp(200 / 实际宽度, 0.5, 1.0)`。
- 缩放目标：`1 + 0.2 × 尺寸系数`。
- X 放大：`0.2s`；Y 放大：`0.35s`。
- 旋转：`±5° × 尺寸系数`，`0.1s` 到达；延迟到 `0.1s` 后，用 `0.1s` 回正。
- 松开/取消：X 用 `0.2s`、Y 用 `0.35s`、旋转用 `0.1s` 回到基准。
- 所有轨道使用 `Back Out`。

当前两个按钮锚点均为中心。组件不擅自修改锚点，以免改变现有布局；测试约束接入目标必须保持中心锚点。

## 行动格结算动效

行动格采用视频“属性变化自动弹跳”的并行结构，但把原视频 `±15°` 收敛为基础 `±7°`，避免 100px 行动格在连锁增强后旋转过猛。

默认参数：

- 缩放增量：`0.2 × intensity`。
- X 放大：`0.1s`；Y 放大：`0.15s`。
- 随机旋转：`±7° × intensity`，`0.1s` 到达。
- X 恢复：延迟 `0.2s`，耗时 `0.2s`。
- Y 恢复：延迟 `0.25s`，耗时 `0.3s`。
- 旋转恢复：延迟 `0.15s`，耗时 `0.1s`。
- 计分同步点：触发后 `0.12s`，随后播放音效、浮字和分数区累加。
- 所有轨道使用 `Back Out`。

继续使用现有强度公式：第一格 `0.82`，每后一格 `+0.12`，连锁按 `log2(1 + repeatCount) × 0.1` 增长，配置上限 `1.8`，播放器绝对上限 `2`。

删除行动卡节点在打击后的固定方向位置抖动，避免它与新旋转/缩放争抢视觉；分数区自身的位置抖动保持不变。

## 参数与 Prefab

按钮组件和行动格组件继续把所有手感参数暴露到 Inspector。三个 Prefab 显式保存新字段，避免脚本默认值与序列化旧字段不一致：

- `assets/resources/gui/prefab/main_menu.prefab`
- `assets/resources/gui/prefab/game_main.prefab`
- `assets/resources/game/poker/prefab/board_cell.prefab`

## 验收

- 开始游戏和刷新按钮触摸后明显放大并随机向左或向右轻摆，长按钮的幅度自动减弱。
- 按住后不循环；松开、划出、连续快点后都精确恢复原缩放和角度。
- 5 个行动格按结算顺序分别弹起、歪斜和错峰恢复，而不是压扁一下。
- 后面的格子及多次连锁具有更大的缩放与旋转幅度，但不超过限制。
- 分数在行动格打击后短延迟出现，结算节奏不被完整 `0.55s` 回弹阻塞。
- 不改变按钮业务回调、Core 结算结果、Prefab 布局和节点命中区域。
- UI 动效契约测试、v0.4 全部测试和 TypeScript 类型检查通过。
