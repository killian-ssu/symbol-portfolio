# 视频粒子效果复刻设计

## 背景

- 参考视频：[《3分钟学会漂亮的2D粒子特效》](https://www.bilibili.com/video/BV1mUKPzoEgJ/)。
- 视频开头前两个目标效果是彩纸礼花与卡通爆炸；教程使用 Cocos Creator 3.8.6 的 `ParticleSystem2D`。
- 当前项目使用 Cocos Creator 3.8.7、手机竖屏设计分辨率 `720×1280`，已有 `FxAnchor` / `SettlementFxRoot`，但尚无正式粒子 Prefab。
- 本轮先建立独立预览与可复用资产，不接入行动格、结算、过关或奖励流程。

## 目标

1. 创建全屏一次性彩纸礼花模板 `fx_confetti_celebration_v1`。
2. 创建约 `240–280px` 的局部卡通爆炸模板 `fx_cartoon_explosion_v1`。
3. 两个模板完全使用 Cocos `ParticleSystem2D` 多层组合，不使用序列帧动画或自定义运行时粒子模拟。
4. 创建 `720×1280` 独立预览场景，可切换礼花/爆炸、手动重播和自动循环。
5. 所有颜色、数量、尺寸、寿命、速度、重力、旋转、发射位置和分层延迟均由 Prefab/Inspector 或 `@property` 控制。

## 非目标

- 不修改 `game_main`、行动格、分数结算、目标分、奖励或 Boss 流程。
- 不加入音效、屏幕震动、暂停、镜头缩放或游戏触发条件。
- 不直接截取视频画面或复制视频作者的贴图。
- 不制作 Codex Skill；等模板在正式游戏中调顺后再整理复用流程。

## 贴图资产

先用图像生成创建一张透明背景的原创形状图集，再裁切、清边和规范尺寸，产出四张 PNG：

| 文件 | 目标尺寸 | 用途 |
| --- | ---: | --- |
| `confetti_chip.png` | `32×32` | 白色略不规则方片/菱形；由不同发射器染成红、黄、蓝、绿、紫。 |
| `confetti_streak.png` | `32×128` | 白色细长、略弯、两端收窄的速度线。 |
| `explosion_blob_a.png` | `128×128` | 白色填充、深色手绘轮廓的不规则火团。 |
| `explosion_blob_b.png` | `128×128` | 与 A 轮廓明显不同的火团/烟团，减少重复印章感。 |

四张图片均为透明 RGBA，四周留安全透明边，不带投影、文字、背景或发光。白色填充用于粒子颜色乘算，深色轮廓在黄、橙、红和烟色层中保持可见。

目标目录：

```text
assets/resources/common/particle-fx/textures/
```

新 PNG 的 `.meta` 由当前根目录的 Cocos Creator 3.8.7 生成，不手写 UUID。

## 通用播放组件

新增 `ParticleFxPlayerComp`，挂在每个粒子 Prefab 根节点：

- Inspector 中配置多个 `ParticleSystem2D` 发射器及其开始延迟。
- `play()` 停止上一轮、清理存活粒子，并按延迟依次重播各发射器。
- `stopAndClear()` 取消未触发的延迟并清空所有发射器。
- 新一轮播放通过 revision/cancellation 隔离，旧回调不得启动粒子。
- 组件只调用 `resetSystem()` / `stopSystem()` 和调度延迟，不修改粒子的颜色、大小、速度、位置、纹理或混合参数。
- 模板默认 `Play On Load = false`、不自动删除，方便预览和以后池化复用。

## 模板 A：全屏彩纸礼花

稳定 ID / Prefab 名：`fx_confetti_celebration_v1`。

### 分层

- 竖屏画布内设置 3 个错开的爆发点，约在 `0s`、`0.18s`、`0.36s` 启动。
- 每个爆发点包含五种固定色方片发射器和一组白色速度线发射器。
- 方片使用同一张白色贴图，通过发射器颜色形成离散的红、黄、蓝、绿、紫调色板。
- 速度线使用独立细长贴图，开启方向跟随，数量远少于方片。

### 运动目标

- 方片高速向上和两侧喷出，初始方向有较大随机范围。
- 方片寿命约 `1.8–2.6s`，持续随机旋转，受向下重力影响形成抛物线，末段淡出。
- 白线寿命约 `0.45–0.8s`，速度高于方片，迅速拉开后淡出。
- 总表现约 `2.6s`；任一时刻活跃粒子不超过 `180`。
- 爆发覆盖大半个 `720×1280` 画面，但底部按钮区可在预览场景中临时置于更高层。

## 模板 B：局部卡通爆炸

稳定 ID / Prefab 名：`fx_cartoon_explosion_v1`。

### 分层

| 层 | 延迟范围 | 视觉作用 |
| --- | ---: | --- |
| 黄芯 | `0–0.02s` | 最先出现的小型高亮火团，快速放大。 |
| 橙焰 | `0.02–0.05s` | 中层主体，位置和尺寸有随机差异。 |
| 红色外焰 | `0.05–0.08s` | 扩张到最外侧，形成冲击轮廓。 |
| 深色烟团 | `0.08–0.12s` | 从后方和上方出现，缓慢上浮并淡出。 |
| 火星 | `0.06–0.10s` | 少量小粒子向外弹射，补充爆发速度感。 |

### 运动目标

- 黄、橙、红三层使用两张不规则黑边火团贴图交错，避免同形重复。
- 火团以较低移动速度和明显的尺寸增长为主，利用位置、角度、寿命和尺寸差异形成手绘团簇。
- 烟团速度较慢并向上漂移，颜色为深棕黑，不使用发光混合。
- 主爆炸约 `0.65s`，烟团延续到约 `0.95s`；任一时刻活跃粒子不超过 `45`。
- 根节点视觉直径约 `240–280px`，后续可整体缩放挂到行动格或道具 `FxAnchor`。

## 独立预览场景

路径：

```text
assets/dev/particle-fx-lab/particle_fx_lab.scene
```

- 画布 `720×1280`，使用深色无纹理背景以便检查透明边和颜色。
- 场景同时实例化两个模板，但一次只启用一个预览模式。
- 底部提供“礼花”“爆炸”“重新播放”三个按钮和当前模式标题。
- 默认进入礼花模式；Inspector 可开关自动循环。
- 礼花循环间隔约 `3.2s`，爆炸循环间隔约 `1.4s`，两个间隔均为 `@property`。
- 切换模式时必须取消旧模式的延迟、清空旧粒子并立即播放新模式。
- 预览场景不注册 `UIID`，不进入正式构建流程，不依赖 `game_main`。

## 移动端与渲染约束

- 只使用 2D 粒子，不引入 3D ParticleSystem、灯光或后处理。
- 所有模板为一次性发射；自动循环只存在于实验室控制器。
- 控制总活跃粒子：礼花 `≤180`，爆炸 `≤45`。
- 纹理尺寸不超过 `128×128`，保持透明裁切，优先复用材质与贴图。
- 粒子 Prefab 的层级、颜色、混合方式、发射参数和锚点均由 Prefab 决定；正式业务代码未来只能调用 `play()`。

## 验证

### 自动契约

- 两个稳定 Prefab 和四张透明 RGBA 贴图存在，图片尺寸符合设计。
- 两个 Prefab 只使用 `ParticleSystem2D`，不包含 3D ParticleSystem 或序列帧动画组件。
- 两个根节点均绑定 `ParticleFxPlayerComp`，所有 cue 都指向自身 Prefab 内的发射器。
- 礼花总粒子容量不超过 `180`，爆炸不超过 `45`。
- 所有粒子 `Play On Load = false`，两个模板均可重复 `play()`。
- 实验室画布为 `720×1280`，包含两个模板实例、三个按钮和循环间隔字段。
- 正式 `game_main`、`board_cell`、结算脚本没有新增粒子引用或触发调用。

### 手动视觉检查

- 礼花分别检查起爆、最高点、下落和完全消失四个阶段；方片与白线层次清楚。
- 爆炸分别检查 `0.1s`、`0.35s`、`0.65s`、`0.95s`；黄芯、橙焰、红外焰和黑烟顺序正确。
- 连续重播十次不得残留旧粒子或出现上一轮延迟串入下一轮。
- 在手机竖屏预览中无明显卡顿、透明黑边、白底方块或按钮遮挡。
