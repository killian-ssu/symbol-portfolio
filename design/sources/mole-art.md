# 午时已到：首轮美术与战斗动效落地

> 状态：地鼠主题历史美术方案，仅用于追溯旧素材结构；当前《子时已到》幽灵白盒规则以 `PROTOTYPE_RULES.md` 为准。

## 本轮优先级

1. 先完成玩家能连续感知到的战斗链：地鼠出洞 → 长按减速 → 锁定 → 松手齐射 → 命中爆炸 → 爆分。
2. 再替换固定画面资产：浅色场景背景、拆件牛仔猫、心、子弹和底部卡片。
3. 天赋与大量备用 icon 暂不全量导入，等升级系统的选择语义稳定后再匹配。

## 已使用素材与规格

- 背景：`午时已到/背景/背景.png`，铺满 720×1280。
- 玩家：帽头、正常/受击/失败表情、身体、持枪手拆成独立层；运行显示约 120px，源图保留约 2 倍清晰度。
- 地鼠：普通土帽、头带战士、无线电射手三种；基础单位和土堆缩为上一版约 `52%`，为成片单位和 Boss 留出层级。
- 土堆：闭合、裂开、小洞、完整洞口四态，另用前景洞沿遮挡地鼠下半身。
- 功能 icon：心、子弹、瞄准图约 96–128px 资源规格。
- 小粒子：石粒和灰白通用粒子最长边约 64px，在 Cocos 中按需要染色。
- 命中爆炸：保留红、黄、奶白三色六帧序列，不做去色。

## 动效时序

- 出洞：尘土和松土石粒提前分批抛出 → 土堆四态正播 → 地鼠延后钻出并拉伸 → 露头后做明显但小幅的浮动、挤压和摆动。
- 缩回：地鼠下沉并压扁 → 土堆四态倒播 → 闭合末段整体淡出。
- 锁定：素材只承担底环和准星；真实进度用程序绘制的高对比连续圆弧、12 格刻度和运动端点表达。完成后在目标中心叠加红色击杀骷髅标记。
- 耐力：不再塞进蓝色卡片，改为顶部独立蓝色水平专注条；耐力过低时会用缩放脉冲提示。
- 子弹时间：世界运动降为 0.26 倍，场景叠加中灰混色层；玩家、瞄准环和顶部 HUD 位于蒙板上方。
- 玩家射击：每一发都有“持枪层快速后撤与拉伸 → 小幅超调 → 回位”，身体同步反向位移、挤压和倾斜；连射越后面后坐越明显，最后一发较重。
- 弹道：短暂奶白核心线 + 珊瑚色弱外层 + 实体子弹残影 + Cocos `MotionStreak` 带状渐隐拖尾。
- 敌方投射物：石块旋转，删除固定胶囊核心；复用《远行商人》的 `MotionStreak` 与实心纹理作为柔光外层，再用轨迹历史绘制渐细的连续主光带，避免低速采样暴露为碎点。
- 命中：六帧彩色爆炸 + 红/黄/奶白粒子外抛 + 分数缩放弹出；连续命中追加 `×N`。
- 受击/失败：切换玩家表情；短暂受击后恢复正常，失败时保持失败表情。
