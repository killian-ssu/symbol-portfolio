# 道具与工具目录（历史 v0.5 / v0.3）

> 本文只作历史图标和 ID 追溯。当前玩家语言、42 件道具目录与实际效果见 `value-pipeline-design-v0.4.md`、`mushroom-shop-item-catalog-v0.4.md`、`relics.json` 与 `tools.json`；不得从本文下方恢复旧伙伴、倍率或随时换位规则。

本文档记录 2026-07-30 已落地的玩家名称、图标和文案。30 件道具按 `01`～`30` 图片顺序映射到现有稳定 ID；8 张工具按铁锹、司南、远镜、宝盒、锦囊、手杖、巧锁、明珠的图片顺序映射到现有稳定 ID。实际效果、条件、阶段、目标和数值以 `assets/resources/config/gameplay/relics.json` 与 `tools.json` 为准，稳定 ID 不随中文名称和图标变化。

## 1. 统一定义

- “此处”表示道具所在的行动格；“右侧”固定表示右边一格。
- “行动探索值+X”只增加文案指定的行动，不改变伙伴基础探索值。
- “伙伴探索值永久+X”会改变该类伙伴的基础探索值，本局后续回合和关卡都保留。
- “伙伴行动次数+X”会额外执行完整伙伴行动：先触发此处行动型道具，再结算该次行动探索值。
- “道具触发次数+X”只再次执行目标道具，不额外产生伙伴行动。
- 结算中生成的工具下一轮可用；每关开始时生成的工具立即可用。
- 伙伴牌与工具牌合计最多保留 6 张；奖励、信条或道具生成使总手牌暂时超出时，流程暂停，玩家选择并确认丢弃工具牌直至回到合计 6 张。
- 正常游玩且未处于结算动画或其他阻塞选择时，道具可随时在五个道具格之间拖拽换位，也可拖入删除区主动丢弃；伙伴牌是否已经落位不影响整理。

## 8. 实现约束

- 30 件道具、8 张工具必须通过配置严格校验；不再保留旧 40/10 目录为可执行内容。
- 玩家文案不得把“行动探索值+X”改写成含糊的“获得 X 探索值”。
- 道具和工具图标与 SpriteFrame 映射属于可替换美术层，不得作为玩法 ID。
- 玩家文案使用“伙伴牌/伙伴手牌/伙伴”，不使用旧职业名。
