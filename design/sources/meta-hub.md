# v0.8 五品阶局外驿站、展区与每日行情实现说明

## 1. 版本目标

v0.8 在 v0.7 局外首要闭环上补全收藏价值、每日变化与长期持有取舍，不增加永久战斗属性，也不改变局内道具规则。

底部导航从左到右固定为：

1. **商店**
2. **仓库**
3. **主界面**
4. **展区**
5. **图鉴**

局内“道具”和局外“藏品”仍是两个独立数据域。藏品可以复用局内资源图标，但不继承局内效果，也不参与肉鸽构筑。

## 2. 五品阶

藏品品阶只接受 `S/A/B/C/D`，顺序固定为 `S > A > B > C > D`：

- S：金色，带冠标/闪光预制层。
- A：紫色。
- B：蓝色。
- C：绿色。
- D：灰褐色。

品阶决定基础价值梯度、商店出现率、每日行情波幅、展区收益和卡片表现。五套底板、边框、光效和角标都在 Prefab 中预制，代码只切换显隐。

每日行情波幅为：

- D：±3%
- C：±5%
- B：±8%
- A：±12%
- S：±15%

商店品阶权重为 `D 40 / C 30 / B 18 / A 9 / S 3`。通关免费藏品只从 D/C/B 抽取，权重为 `60/30/10`；A/S 主要来自神秘商店。

## 3. 页面与交互

### 3.1 仓库

- 使用纵向 ScrollView，每行 5 格，Prefab 预制 30 个槽位。
- 筛选为“全部、S、A、B、C、D”。
- 每格包含阴影、品阶层、图标、名称、数量、锁定、展出和行情角标。
- 今日价高于昨日显示绿色上箭头，低于昨日显示红色下箭头，相同显示灰色横线。
- 点击藏品打开独立 Oops Dialog，显示描述、品阶、总数/锁定/展出/可用、基础价值、昨日价、今日价、涨跌金额与百分比、每 3 小时展区收益。
- 详情操作为锁定/解锁、赠送、前往展出、按今日行情出售 1 件。

展出副本仍计入仓库总数，但不可出售、赠送或再次展出。所有扣除统一使用：

```text
available = quantity - locked - exhibited
```

### 3.2 每日行情

- 使用“本地日期 + 藏品 ID”生成稳定报价，同一天重复进入不会改变。
- `今日价 = max(1, round(基础价值 × 当日波动系数))`。
- 趋势由今日整数价与昨日实际整数价比较，允许平价。
- 详情若在午夜前打开、午夜后确认出售，服务返回 `stale_quote`；界面关闭旧详情并要求使用刷新后的价格重新确认。
- 行情只影响仓库直接出售和未来拍卖参考价，不改变商店售价与展区收益。

### 3.3 神秘商店

- 每日生成 3 张普通神秘牌，逐张免费翻开并保存状态。
- 第 4 张为独立广告牌；广告完成后揭晓，仍需用金币购买。
- 同一天四件商品不得重复。
- 未揭晓时 `ShopOfferRow.config` 为 `null`，界面无法取得名称、图标、品阶或价格。
- 正面显示大图、品阶框、名称、已有数量、固定售价和已购买状态。
- 删除 v0.7 的广告领币与广告刷新，显示本地午夜换货倒计时。

### 3.4 展区

- 预制 3 个展位，三个展品必须不同。
- 每满 3 小时按藏品固定配置产生一次金币。
- 离线最多累计 8 次，即 24 小时。
- 每日行情不改变展区收益。
- “统一领取”同时领取三个展位的完整周期。
- 撤下或替换时自动结算完整周期；未完成周期清零。
- 选择器是预制的 30 格 ScrollView，只列出未锁定、未展出的可用藏品。

### 3.5 主界面与图鉴

- 主界面保留继续上次远行和开始新的远行，不增加战斗属性。
- 玩家界面统一使用“图鉴”，分类仍为场景、特别状况、局内道具、工具。
- 图鉴使用四列 ScrollView；未知条目显示剪影和“未发现”，不泄露真实名称，已发现条目可打开详情。
- 商店存在未翻牌时显示底栏角标；展区存在可领取金币时显示底栏角标。

## 4. 数据与迁移

- `collectibles.json` 升级为 v2，包含品阶、描述、固定商店价、基础价值、固定展区收益、商店权重、通关权重和图标。
- 档案键升级为 `travelling_merchant.meta_profile.v2`。
- v1→v2 保留金币、仓库、发现记录和教程；旧商店状态重新生成，展区初始化为空。
- `MetaProfileService` 是行情、商店、仓库可用数和展区收益的唯一规则源，不引用 Cocos。
- `MetaProfileRuntime` 负责资源、本地存储、平台桥接和界面通知。
- `MetaAdBridge` 只有 `shop_offer_reveal` 广告位；失败不改变牌面，可再次尝试。
- `MetaSocialBridge` 仍负责赠送成功回执；失败时归还已暂扣藏品。
- 未来拍卖直接消费 `DailyMarketQuote`，不得另建价格算法。

## 5. 首版仍不做

- 拍卖界面与玩家自由交易。
- 多货币、付费抽取和永久战斗属性。
- 完整经济长期平衡与服务端权威资产。
- 正式好友后台和广告 SDK；当前保留可替换桥接与编辑器演示实现。
