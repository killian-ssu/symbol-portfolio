# 《远行商人》当前 GDD（价值传递玩法）

版本：2026-08-01

## 1. 产品概述

《远行商人》是一款轻量构筑爆分游戏。玩家从三张伙伴手牌中持续选择，将五色伙伴放入 1—5 号位，让同一个当前价值依次经过五位伙伴并不断增加或翻倍，最终达到路段目标。

核心决策是：手牌信息不完整时，如何安排同色与异色伙伴的先后，并将五件简单道具组合成成长和爆发连锁。

世界观外皮尚未锁定。运行时暂用红帽、黄帽、绿帽、蓝帽、紫帽；机制和玩家文案统一使用中性的“价值、伙伴、同色、异色”。

## 2. 单轮核心循环

1. 出牌前和出牌过程中，价值区持续显示本轮初始价值，基础为 10。
2. 伙伴手牌维持 3 张；打出 1 张补 1 张。工具独立保留，与伙伴牌合计上限 6 张。
3. 伙伴按 1—5 号位落位。前四张只更新初始价值预览，第五张落位后开始结算。
4. 1 号位每次行动使当前价值 `+增加值`，基础增加值为 10。
5. 2—5 号位与前一位同色时，每次行动使当前价值 `×2`；异色时使当前价值 `+增加值`。
6. 此处全部行动结束后，当前价值只向右传递一次，不回传、不分批。
7. 5 号位结束后的当前价值就是本轮得分，并一次性加入本关进度。

## 3. 基础公式

```text
current_value = 10

for slot in 1...5:
  repeat action_count(slot) times:
    if slot == 1: current_value += increase_value
    else if same_color(slot, slot - 1): current_value *= 2
    else: current_value += increase_value

round_score = current_value after slot 5
```

| 排列 | 运算 | 本轮得分 |
|---|---|---:|
| AAAAA | `(10+10)×2×2×2×2` | 320 |
| ABCDE | `10+10+10+10+10+10` | 60 |
| ABBBC | `10+10+10→×2→×2→+10` | 130 |

不再识别牌型，不求五张伙伴分数和，不存在独立倍率区、道具向右发送触发或多个价值批次。

## 4. 伙伴、道具与工具

- 五种伙伴牌各 5 张，没有固定分数或个人能力；颜色只用于同色/异色判断。
- 30 件道具分为基础、成长、兑现和调整四类。道具只修改数值、此处行动、永久提升或工具获取。
- 当前道具文案必须明确条件、对象、数值和持续时间，不能用“相同时”“每格永久+20”这类省略对象的句式。
- 一件普通道具不能自动改写多个未来伙伴。风筝现为“前3位至少有2种伙伴时，5号位行动+1”，不再把后两张变成第3张。
- 8 张工具用于主动改变一张伙伴、换牌、增加初始价值、增加某处行动或复制一次明确操作。

## 5. 路线、信条与奖励

- 四章、16 个路段、每关最多 4 轮和 2 次伙伴手牌刷新保持不变。
- 六条启程信条支持首次同色、首次异色、多色初始价值、过关成长、章节工具和 5 号位加值。
- 奖励保留均衡、道具、工具三种布局和最多 2 次补给改选。
- 奖励界面始终可以跳过。五个道具位已满时，玩家只有主动选择新道具才进入替换流程。

## 6. UI 与动画

- HUD 只显示一个当前价值区，不显示牌型或倍率区。
- 出牌阶段显示 Core 给出的初始价值预览，不从 0 突然开始结算。
- 结算时当前价值跟随正在行动的伙伴，并限制在 HUD 范围内；旧行动格红色分数不再显示。
- 第 1 位结算较慢，之后逐位加速；本位最后一次数值反馈与向右粒子同时发生，二者都完成后才开始下一位。
- 相邻位置使用 5—10 个弧形粒子表现量级；`×2` 分两波传递，不按精确分数创建粒子。
- 伙伴手牌不显示旧的固定分数底板和分数文字。
- 动画时长、衰减、粒子数、弧高、缩放和锚点由 Prefab / Inspector 控制。

## 7. 当前验证状态

- 16 关目标仍为 250 至 1,000,000。
- 千局模拟中，改版风筝在胜局中的出现率为 19.5%，不再构成固定答案。
- 月之眼胜局出现率为 80.6%，但强度来自工具组件组合，不会单件自动排阵。
- 异色路线已形成鱼汤、镜子、斗笠、药瓶和抓钩组成的“种子—成长—兑现”链；专属构筑模拟完整通关率约 52%，终局可达百万量级。
- 通用异色策略仍有前两关核心奖励覆盖不足的问题；下一轮优先优化奖励引导，不继续无条件抬高后期成长。
