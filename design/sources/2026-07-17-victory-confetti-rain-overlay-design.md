# 胜利彩带雨与粉黄遮罩动效设计

日期：2026-07-17

## 目标

参考花瓣素材的竖向彩带飘落节奏，为《远行商人》的胜利画面制作一套可复用、移动端可控、全部由 Prefab / Inspector 调参的表现资产：

1. 全屏从顶部持续落下的双层彩带雨。
2. 四周高饱和粉色、中心暖黄色的强半透明动态遮罩 Shader。
3. 独立的 `720 × 1280` 胜利动效实验室，用于先调效果、后接正式胜利弹窗。

本轮不修改 `game_end_popup.prefab`、`GameEndPopupComp.ts`、`GameMainViewComp.ts` 或胜负流程。正式游戏接入必须等待用户在实验室体验并确认。

## 参考拆解

花瓣参考不是三点爆发礼花，而是约 6.9 秒的竖向彩纸/彩带飘落：粒子从画面上边界外生成，沿全宽分布，向下移动并持续旋转；大小、下落速度和水平漂移均有差异。

用户胜利稿的背景表现为：原游戏画面仍可辨认，屏幕四周由高饱和洋红覆盖，中央形成横向椭圆状暖黄区域，粉色和黄色之间柔和过渡。标题和按钮位于遮罩与大部分彩带之上，少量前景彩带从文字前经过。

## 方案选择

采用“两层 `ParticleSystem2D` 彩带雨 + 独立全屏 Sprite Shader”。不采用纯 Shader 彩带，因为无法获得可靠的单片旋转和前后景层次；不采用透明视频，因为体积大、参数不可调且不利于跨项目复用。

## 彩带雨资产

### 稳定资产

- 组合 ID：`fx_confetti_rain_v1`
- 后景 Prefab：`fx_confetti_rain_back_v1.prefab`
- 前景 Prefab：`fx_confetti_rain_front_v1.prefab`
- 每个 Prefab 内部固定拆成 `OpeningRoot` 和 `AmbientRoot`，分别挂载通用 `ParticleFxPlayerComp`。
- 根节点使用轻量通用分层播放器，只组合 `playOpening()`、`playAmbient()`、`playFull()` 和 `stopAndClear()`；业务/实验室不直接改发射参数。

拆成前后两个 Prefab，是为了让调用方能够按 `后景彩带 → 标题与按钮 → 前景彩带` 的节点顺序组合，不需要在运行时重写渲染顺序。

### 时间结构

- 开场高密度阶段：`3.0s`。
- 持续阶段：胜利界面存在期间保持约开场 `25%` 的密度。
- 实验室自动循环预览：每 `8.0s` 重播一次，既能看到开场，也能观察持续阶段。
- `ParticleSystem2D` 的视觉参数固定保存在 Prefab：高密度发射层使用有限 `duration`，低密度发射层使用持续发射；运行时不修改 `emissionRate`。

### 前后景比例

- 后景约占总视觉数量 `75%`：纸片较小、速度较慢、透明度略低，主要从标题后方落下。
- 前景约占 `25%`：数量较少、尺寸更大、速度略快，从标题与按钮前方经过。
- 两层都覆盖完整 `720px` 宽度，发射带位于屏幕上边界之外，避免粒子从屏幕中段凭空出现。

### 造型与颜色

- 复用 `confetti_chip.png` 作为小型纸片。
- 新增原创透明白色 `confetti_ribbon_curve.png`，提供弯曲长彩带轮廓；由粒子颜色统一着色。
- 色板：洋红、青蓝、明黄、翠绿、紫色、少量白色。
- 通过 `Start Spin / End Spin / Spin Var`、不同速度和水平扰动模拟翻转与摆动；不依赖业务 Tween。

### 移动端预算

- 两层总粒子容量控制在 `240` 以内。
- 后景承担主要密度；前景使用更少粒子换取更大尺寸，避免全屏透明粒子过度叠加。
- 只使用 `ParticleSystem2D`，不使用 3D 粒子系统。

## 粉黄遮罩 Shader

### 稳定资产

- Effect：`VictoryPinkGoldOverlay.effect`
- Material：`VictoryPinkGoldOverlay.mtl`
- 使用全屏白色 Sprite 承载，alpha blend，位于背景与后景彩带之上、标题与前景彩带之下。

### 视觉结构

- 边缘颜色：高饱和洋红/玫红。
- 中心颜色：暖黄到橙黄，形成横向椭圆光区。
- 粉黄之间使用双层 smoothstep 过渡，避免明显圆形硬边。
- 整体覆盖强度按用户选择设为 `70%–80%`，但保留底下游戏画面的形状与主要明暗。
- 中心位置、椭圆半径、粉色/黄色、整体透明度均为 Material Inspector 参数。

### 动态

- 中心黄光以很慢的幅度呼吸扩散和收缩。
- 叠加低强度二维噪声/流动扰动，使渐变边缘缓慢漂移。
- 不做明显颜料翻涌，不让 Shader 抢过标题和彩带。
- 动态使用 `cc_time`；业务代码不逐帧改材质参数。

## 独立实验室

新增 `assets/dev/victory-fx-lab/victory_fx_lab.scene`：

- 设计分辨率 `720 × 1280`。
- 使用项目现有背景 SpriteFrame 作为透明度参照，不启动 Core 或正式游戏流程。
- 节点层级固定为：背景 → 后景彩带 → 粉黄遮罩 → “满载而归”示意标题/按钮 → 前景彩带。
- 控制按钮：`完整重播`、`只看开场`、`模拟持续`、`遮罩开关`。`只看开场` 只播放两层 `OpeningRoot`，`模拟持续` 只播放两层 `AmbientRoot`，不动态重写任何粒子参数。
- 自动模式每 `8.0s` 完整重播。
- 所有位置、颜色、粒子参数、Shader 参数由场景/Prefab/Material 保存。

## 通用边界

- 新资产写入现有 `assets/resources/common/particle-fx/` 与 `assets/resources/common/shader/` 共享库。
- 原三点爆发礼花 `fx_confetti_celebration_v1` 保持不变。
- 实验室只负责播放和切换，不在运行时覆盖美术参数。
- 后续正式接入时，胜利状态启用 Shader 与双层彩带；失败状态保持现有深色表现。该接入不属于本轮。

## 验证

- 资源契约检查新贴图为 RGBA、新 Prefab 只使用 `ParticleSystem2D`、`playOnLoad=false`、`custom=true`、总容量不超过 240。
- 契约检查开场发射层为 `3.0s`，持续发射层存在，前后景 Prefab 和 Shader Material 均可按稳定路径找到。
- 契约检查实验室包含 720/1280、示意标题、四个控制入口与正确节点顺序。
- 契约检查 `game_end_popup`、`GameEndPopupComp` 和 `GameMainViewComp` 未引用新资产。
- 执行 `npx tsc --noEmit`、新动效契约、`npm run test:v04`。
- 在真实 Cocos 当前场景预览中检查：完整覆盖、3 秒密集转持续、前后层遮挡、粉黄强透明遮罩和移动端帧率。
