# 打击音效修订（2026-09-08）

Symbol 本轮要求：去掉子弹时间结束提示音，补充爆炸与穿透激光的不同打击声，普通攻击声提高约 20%。

## 当前表现

| 事件 | 声音与触发 |
| --- | --- |
| 子弹时间结束 | 只淡出进入声与空气底声、恢复音乐，不再新增结束音。 |
| 普通攻击 | 沿用原有的低频击发与高频瞬态，两层增益都乘以 1.2。锁敌、敌方攻击与 BGM 音量不随之提高。 |
| 爆炸天赋 | 低频冲击、短促碎裂声与衰减颗粒尾声，约 0.62 秒；在实际爆炸触发时播放一次。 |
| 穿透天赋 | 清亮的激光下滑音与轻微空气高频，约 0.32 秒；每束穿透光束播放一次。 |
| 导弹发射 | 短促点火、带轻微上扬哨音的空气推进声，约 0.56 秒；每枚导弹实际显形发射时播放一次，跟随 0.085 世界秒的错开发射。 |
| 导弹命中 | 较轻的小型低频冲击与清脆碎光尾声，约 0.34 秒；真正接触目标时播放一次，与爆炸天赋的大范围轰击区分。 |

范围爆炸与一束光线穿过多个目标，都不会按受击目标数量重复叠加声音。连续光束允许尾声重叠，但最多保留六个新增效果声部；重开、停止、音频上下文重建时清理。子弹时间中的新效果音按背景混音降低。

导弹使用独立飞行流程，上一轮没有接入声音，本轮补全发射和命中两个事件。发射前失去所有目标时保持静音；中途重新追踪不会重播发射声；飞行中失去所有目标不会播放命中声。命中声由世界时间中的实际碰撞触发，子弹时间或暂停不会让声音提前到达。推进声是一次性的短尾声，不是持续飞行循环。
