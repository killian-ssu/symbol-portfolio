# 2026-09-07 战斗难度与反馈调整

这轮依据 Symbol 的试玩反馈，目标是保留普通敌人一击击破的爽感，同时让敌群、攻击与 Boss 阶段能形成实际压力。

## 主要原因和改动

| 试玩问题 | 找到的实现原因 | 本轮行为 |
| --- | --- | --- |
| 一次长按清空大部分敌群 | 4.4秒耐力，单个锁定0.52秒，基础能锁约8只 | 耐力改为2.7秒，目标充足时锁5只；升级继续增加耐力与并行准星，没有新加锁定上限 |
| 远程没机会出手 | 被瞄准后整个可见阶段计时停止；原本还需要较久准备 | 攻击计时持续；显形后约0.18秒开始准备、约0.5–0.58秒前摇；保持单发，实际命中仍能打断 |
| 近战太慢、却能隔空扣血 | 移速50.4/37.8，205中心距离直接伤害 | 基础移速72/57.6，逐关温和增加；92附近才进入抓击，伤害发生时再检查距离，并显示抓痕 |
| 关卡压力不足 | 在场上限3–8，关卡目标8–18 | 首关单只教学保留；随后各关在场上限6–10，总目标12–30，补怪更快 |
| Boss 没展示能力 | 每个部位命中都重置攻击，破甲立刻开弱点 | 开场带3只小怪；3封印→一次反击→3弱点，九格生命最快需三轮；小怪最多5只，Boss 独占3点威胁预算 |
| 爆粒子不明显 | 8颗小粒子很快消失，最后击杀立即被奖励界面清空 | 12颗较大的圆点/星形、扩散环，约0.52秒；末次击杀留0.55秒反馈；群攻也使用同一击杀表现 |
| 玩家弹道像方条 | 全长直线叠实心纹理拖尾、三枚实体残影 | 三层曲面渐尖光尾，保留敌方已有拖尾 |
| 战斗文字多且一闪而过 | 单次射击、形态切换、得分、连击、尾波同时飘字 | 删除重复文字，连击集中显示×N；关键短提示加粗、描边并延长停留 |
| 弹窗发虚、暂停风格旧 | 半透明 Sprite 位于结算父节点上；暂停仍使用旧节点 | 遮罩移到独立兄弟节点；暂停新建同风格 Prefab，内容完全不透明、文字加粗 |

## 验证

- 类型检查与 `npm run check` 通过。
- `npm run check:combat` 直接执行当前战斗源代码，用最小场景适配器验证规则。30/60/120帧均锁到5只；已锁定远程可在长按时出弹；205距离不扣血、92距离可抓击；最高级群攻不跳过三轮 Boss 反击；弱点窗口保留已承诺锁定；小怪数量与威胁预算受限；末次击杀先播反馈再开奖。
- Cocos 编辑器的后台资源导入仍返回旧代码，原有完整预览冒烟因此因旧参数未通过，不能据此宣称新版本完整十关实机通过。
- 为核对新画面，在独立本机测试页中，将当前 TypeScript 编译后加载到真实 Cocos 引擎，并直接反序列化当前弹窗 Prefab。弹窗根透明度1、文字alpha255和加粗均已确认；Boss 开场小怪、首次三枚咒弹、渐尖光尾、胜利/失败/暂停均有截图证据。
- 真实引擎检查是测试页中直接加载磁盘源码，不会更新 Creator 自己的资源缓存。后续正常预览前需刷新工程资源。
- 最后将原“圆粒子”素材替换为真正绘制的圆点，并补上 Boss 独立预算。这两项的类型与规则检查通过；最后一次真实引擎截图复核受审批连接中断影响，状态待更新。

## 本次保留的设计判断

普通怪不增加血量。难度通过一次长按的机会成本、剩余敌人的行动、敌群密度和 Boss 的反击阶段来建立。已锁定不等于已打断；锁定不应冻结攻击，但必须兑现玩家已经承诺的命中。表现上优先确保玩家能看到动作和结果，再补文字说明。
