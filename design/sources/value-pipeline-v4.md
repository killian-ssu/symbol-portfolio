# 《远行商人》分数传递玩法 v0.4

版本：2026-08-03

状态：当前基础规则、构筑原则与结算表现真相源。商店、位置标签、42 件道具、分层成长与三档难度已迁移到正式 JSON、Core、存档、UI 和 Prefab；稳定 ID、运行时效果和数值以 `assets/resources/config/gameplay/` 为最高优先级。

## 1. 当前结论

一轮只有一个持续变化的当前分数。它从 1 号位置依次经过 2—5 号位置；每张蘑菇完成此处全部行动后再向右传递，5 号位置结束后的当前分数就是本轮得分。

五张蘑菇牌本身就是“向右传递”的基础语言。五朵魔法蘑菇共同编成一道孢子咒，当前分数表示魔法强度。玩法不使用牌型、蘑菇固定分数、独立倍率区、道具向右触发、反向传递或多个分数批次。道具只修改初始孢子、蘑菇孢子、此处行动次数或本次远行的永久成长。

## 2. 玩家可见名词

| 名词 | 精确定义 |
|---|---|
| 初始孢子 | 本轮开始传递前显示的分数，基础为 10；出牌阶段即可看见 |
| 当前分数 | 正在从 1 号位置向 5 号位置传递的唯一分数 |
| 目标分数 | 当前场景要求累计达到的分数 |
| 蘑菇孢子 | 第 1 朵或异类相接每次行动使当前分数增加的数值，基础为 10 |
| 此处 | 这件道具当前放置的位置 |
| 同类相接 | 当前蘑菇与上一张同类时发生；每次行动使当前分数 `×2` |
| 异类相接 | 当前蘑菇与上一张不同类时发生；每次行动使当前分数 `+蘑菇孢子` |
| 行动次数 | 此处完整执行基础规则的次数；候选上限为 8 |
| 位置标签 | 贴在一张具体蘑菇牌上的 `1—5` 数字；数字与位置相同时命中 |
| 永久 | 本次远行后续场景都保留 |
| 金币 | 商店购买、出售和换货使用的货币；本次远行金币与驿站金币是两份独立余额 |

卡面不能只写“相同时”“每 10 张牌”“每格永久 +20”或“每成长 50”这类省略对象的短句。每条玩家文案至少说清条件、对象、改变的数值和持续时间。

## 3. 基础公式

```text
current_score = initial_spores

for slot in 1...5:
  actions = min(8, 1 + 此处额外行动次数)
  repeat actions times:
    if slot == 1:
      current_score += mushroom_spores
    else if mushroom(slot) 与 mushroom(slot - 1) 同类:
      trigger 同类相接 -> current_score *= 2
    else:
      trigger 异类相接 -> current_score += mushroom_spores

round_score = current_score after slot 5
```

基础值：`initial_spores = 10`、`mushroom_spores = 10`、同类倍率固定为 `2`。基础、道具、位置标签和工具提供的行动次数合并计算。同类相接的额外行动仍然每次 `×2`，异类相接的额外行动仍然每次 `+蘑菇孢子`，不新建批次也不改成固定加分。

| 排列 | 运算 | 本轮得分 |
|---|---|---:|
| AAAAA | `(10+10)×2×2×2×2` | 320 |
| ABCDE | `10+10+10+10+10+10` | 60 |
| ABBBC | `10+10+10→×2→×2→+10` | 130 |

所有额外事件始终作用于同一个当前分数，不新建分数、不回传、不产生独立批次。

## 4. 位置标签

- 位置标签只含 `1—5` 五种数字，绑定一张具体蘑菇牌，不绑定整类蘑菇。
- 数字与所在位置相同时，普通标签使此处额外行动 1 次；炫彩标签额外行动 2 次。
- 标签行动重复此处基础规则，因此会读取同类相接、异类相接、蘑菇孢子与已有道具，但不发出新的标签命中事件。
- 工具改变这张牌的种类时保留位置标签；临时复制上一张蘑菇时只复制种类，不复制位置标签。
- 商店中一次购买提供三枚同号普通标签，玩家选择一类蘑菇，Core 优先给该类未标记的三张具体牌安装。三枚与单价 4 金币已写入正式配置，仍需实机平衡验证。
- 同号标签再次贴到已有同号普通标签的牌上时，可升级为额外行动 2 次。

## 5. 构筑原则

同类相接和异类相接不是两种流派，而是每次排列都要在手牌、位置标签、道具位置和当前分数之间权衡的基础事件。`×2` 天然随当前分数放大；蘑菇孢子从单次 `+4/+5`开始，通过成长数值、成长触发次数、位置行动次数和排列的分层放大成长到百万结果。单件道具不再一次发放数百或数千分。

道具职责可以分为即时分数、排列条件、永久成长、位置触发、位置标签、工具与手牌、商店经济等功能，但这些只是目录管理标签，不是强制玩家选定的流派。

前段用异类相接增加分数、后段用同类相接翻倍，只是众多自然结果之一。模拟只在远行结束后归纳实际构筑组合，不预先给代理指定同类、异类或混合策略。

工具只主动改变一张蘑菇牌、一个位置或一次明确操作。工具构筑的强度来自生成、使用成长和局部兑现的组合，不来自单件道具自动完成五张排列。

## 6. 道具与商店约束

一件普通或稀有道具可以提供简单而明显的偏好，但不能自动替玩家完成多个未来位置的排列。玩家获得它后，之后每轮仍应存在至少两种有意义的出牌选择。

默认不允许：

- 自动改写两张或以上尚未打出的蘑菇牌；
- 一件道具直接固定后三个位置的种类；
- 不经玩家选择就生成完整五连；
- 为解释道具而重新引入第二批分数或反向传递；
- 只靠一件道具就把商店购买和每轮排列固定成唯一答案。
- 单次直接加值高于基础初始孢子与基础蘑菇孢子 10；更大的结果应来自次数、成长、传递和乘法的组合。

旧效果“后两张变成第 3 张蘑菇”已经废弃。目录中的“交错菌丝”改为局部条件：`此处左侧已有至少2类蘑菇时，此处行动次数+1。` 玩家可以把它放在 3—5 号位置，不被硬性锁到 5 号。每轮自动获得“复制上一张蘑菇”的道具也已改为“弃一抽一”，避免单件工具把排列锁成全同类。

商店始终允许直接离开。五个道具位已满时，只有玩家主动购买新道具才进入出售或替换流程；换货后仍可直接离开。

道具可以在每轮打出第一张蘑菇前自由换位；第一张落位后，道具位置锁定到本轮结束。这个规则让商店构筑、道具摆位和实际出牌在同一轮中相互约束。

位置道具必须通过结算先后自然形成偏好，而不是只写“放在 5 号位才生效”。例如“扩散标记”命中后提高本轮后续蘑菇孢子，放得越早越能影响后续；“汇聚标记”按本轮此前标签命中数提高此处行动次数，放得越晚越容易积累。两件道具都仍有多个可用位置。

## 7. 显示与动效合同

### 出牌阶段

- HUD 只显示一个分数区，不显示牌型或倍率区。
- 尚未结算时显示 Core 提供的初始孢子，不从 0 突然开始。
- 行动格蘑菇不显示旧的右上角固定分数；蘑菇手牌也不显示旧分数底板或分数文字。

### 结算阶段

1. 第五张蘑菇落位后，当前分数从初始孢子开始。
2. 进入某个位置时，分数区移动到当前蘑菇头上，并按实际文字边界限制在 HUD 范围内。
3. 当前蘑菇下方依次显示 `同类相接 / ×2`、`异类相接 / +N`、`第 N 次行动`和失效等 Core 事件，当前分数同步变化。
4. 该位置最后一次数值反馈开始时，弧形孢子同时飞向下一位。
5. 下一位等待本位数值反馈和孢子都完成后才开始，保持因果顺序。
6. 第 1 个位置保留看清规则的时间，之后逐位缩短间隔和停留。
7. 5 号位置结束后，最终分数飞向当前场景卡的目标进度。

孢子不与分数一比一生成。按量级使用少量预制粒子；同类相接 `×2` 用两波孢子表达两朵蘑菇共鸣，异类相接用新颜色孢子汇入表达新的魔法加入。数量、弧高、时长、间隔、缩放、锚点、分数区偏移和屏幕留白全部由 Prefab / `@property` 配置。

## 8. 蘑菇主题的成长表现

一句话解释固定为：“商人用五朵魔法蘑菇编成一道孢子咒。魔法按排列依次穿过每朵蘑菇，逐渐增强，最后由第五朵释放，击破前方阻碍。”

玩家规则仍只使用“分数、目标分数、蘑菇、同类相接、异类相接、位置、此处”等常见词。场景、现象和道具名称可以使用菌雾、孢子雨、菌丝、菌环等包装词，但效果文案必须直接说清玩法对象。

纸面数值成长需要同步转成四种可见变化：

- 蘑菇成长：持有的永久成长达到量级门槛后，行动格内蘑菇出现更大的菌盖、附生小菇或发光纹路。
- 传递成长：小分数是零散孢子，中分数形成菌丝和孢子带，大分数形成孢子云、冲击波和更宽拖尾。
- 道具成长：成长道具的图标、边框或刻度随永久数值提高，不只让说明里的数字变大。
- 场景反馈：最终孢子撞向阻碍，按未达标、达标、明显超过目标分数分档表现裂纹、掀飞和场景恢复。

## 9. 新模拟验收

旧的预设同类、异类、混合构筑胜率只作历史对照。新版模拟器不向代理指定流派，主要检查：

1. 有意义出牌率：一次选择中，是否至少有两张牌分别服务于即时分数、位置标签、成长进度、道具条件或下一步准备，而且差距没有大到其中一个是假选项。
2. 单件排列收敛：只持有某件道具时，某一种同类相接/异类相接顺序是否占据绝大多数选择。
3. 构筑收敛率：胜局是否过度集中在同一件道具、同一道具组合或同一功能组合。
4. 商店行为：购买、跳过、换货、出售和中途转向是否都真实发生。
5. 事后组合：只在远行结束后按最终道具功能归纳自然组合，不用预设组合反推胜率。

42 件正式目录与完整结果见 `mushroom-shop-item-catalog-v0.4.md`。标准难度 8,000 局的有意义出牌率为 30.3%，成熟构筑收敛率为 24.9%，占比至少 5% 的成熟功能组合有 6 组，每件道具 400 次单件测试中没有一件导致固定排列。16 件局部道具没有硬编码唯一位置，也没有只剩一个可用位置的道具。

原候选单曲线 `250…1,000,000` 的 0.8% 通关率只证明成熟构筑能越过百万，不能代表新手或标准游玩体验。当前候选因此拆为三档：

- 简单：首次远行默认使用；每个场景最多 5 轮，终点 20,000。
- 标准：通过简单后解锁；每个场景最多 4 轮，终点 50,000。
- 困难：通过标准后解锁；每个场景最多 4 轮，终点 250,000。

三档不改变蘑菇、标签、道具、工具或商店规则，只改变场景目标与最多轮数。百万分保留为可追求的超额爆分里程碑；成熟样例单轮仍可达 156 万和 421 万。模拟除通关率外，同时记录成熟阶段抵达率、兑现阶段抵达率、5 次行动/100 蘑菇孢子出现率与单轮破万率，避免只用胜负隐藏成长过程。
