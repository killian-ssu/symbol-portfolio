## 1. v0.2 结论

v0.2 不再用“预设同类、异类或混合流派胜率”反推道具。模拟代理逐张比较即时分数、位置标签、永久成长、道具条件和下一张准备，最后才按实际获得的道具归纳构筑。

推荐结论是：

1. 保留 `2 件道具 + 1 组位置标签 + 1 张工具牌`。增加到 3 件道具会让旅费更快被高价道具吸走，反而降低转向和通关。
2. 位置标签命中时统一使当前分数 `+增加值`，不再根据同类或异类重复基础运算。这样标签是第三个可比较因素，不会因同类 `×2` 成为唯一答案。
3. 一组仍是 3 枚同号标签，价格仍是 4 旅费。玩家自由选择 3 张具体蘑菇牌安装，不强制同类或分散。
4. 换货价格从 3 降为 2，并用“每次换货后，增加值永久 +700”的成长件让换货成为构筑动作，不只是没看到好商品后的惩罚。
5. 第一章必须同时存在标签的即时兑现和永久成长。只给 `+50 / +100` 的固定分数会让偏标签玩家在第二章前掉队。

## 2. 位置标签候选规则

- 位置标签只有 `1—5` 五种数字，绑定一张具体蘑菇牌。
- 牌上数字与它所在位置相同时命中。普通标签使当前分数额外 `+增加值`；炫彩标签额外执行 2 次 `+增加值`。
- 标签额外加分不触发“每次行动后”道具，也不增加道具的行动成长计数。
- 工具改变这张牌的种类时保留位置标签；临时复制上一张蘑菇时只复制种类，不复制标签。
- 模拟代理倾向把同组标签集中在一类蘑菇上，用来验证“命中标签”与“此刻选同类还是异类”的冲突；这是模拟策略，不是玩家安装限制。

## 5. 模拟验收

模拟保留总体 `30%` 有意义出牌门槛，同时增加构筑成长曲线：

- 开局（第 1—4 场景）不低于 25%。
- 成长（第 5—8 场景）不低于 30%。
- 成熟（第 9—16 场景）不低于 32%，且比开局至少高 4 个百分点。
- 成熟构筑最高功能组合占比不高于 30%。
- 最高单件道具成熟占比不高于 65%。
- 占比至少 5% 的成熟组合不少于 5 组。
- 每件道具单独测试时，不得把一种同类/异类排列压成绝对主导。

单件测试不把联动道具丢进空环境：位置标签道具配置两组基础标签，工具道具配置两张可用工具，并分别与同环境无道具基线比较。

### 5.1 最终结果

| 指标 | v0.2 结果 | 验收 |
|---|---:|---|
| 有意义出牌率 | 31.6% | 通过 30% 门槛 |
| 开局 / 成长 / 成熟出牌率 | 27.8% / 32.7% / 36.6% | 通过，构筑越深决策越丰富 |
| 强制优势选择率 | 26.0% | 比 v0.1 的 29.9% 降低 |
| 成熟构筑收敛率 | 24.0% | 通过 30% 上限 |
| 占比至少 5% 的成熟组合 | 7 组 | 通过 |
| 最高单件成熟占比 | 43.3% | 通过 65% 上限 |
| 平均道具组合相似度 | 14.2% | 构筑保持分散 |
| 单件导致固定排列 | 0 / 42 | 通过 |
| 当前目标分数下通关率 | 10.6% | 高于无标签组 9.5% |
| 仅将第四章目标调为 75% 时通关率 | 15.3% | 作为难度校准候选，不是已锁定数值 |

同阶段对照中，有标签组相对无标签组的有意义出牌差值为：

- 开局 `-1.1` 个百分点：第一章仍以学习基础同类/异类为主。
- 成长 `+4.3` 个百分点：标签、成长和道具开始产生真实冲突。
- 成熟 `+8.4` 个百分点：标签系统没有把出牌压成固定顺序，而是让后程选择明显增加。

### 5.2 自然形成的成熟构筑

占比至少 5% 的 7 组为：

1. 永久成长 + 位置标签：24.0%。
2. 排列条件 + 位置标签：15.7%。
3. 排列条件 + 永久成长：12.7%。
4. 行动与位置 + 排列条件：9.9%。
5. 位置标签 + 工具与手牌：6.6%。
6. 行动与位置 + 位置标签：5.8%。
7. 永久成长 + 工具与手牌：5.8%。

这些是模拟结束后的事后归纳，不是开局流派。最强组合也只占 24.0%，没有出现所有玩家都追同一条路线的结果。

### 5.3 商店行为

每次远行平均购买 5.24 件道具、3.47 组位置标签和 2.38 张工具牌；9.0% 的商店被直接离开，平均换货 0.54 次，47.9% 的远行出售过道具，44.9% 发生过主功能转向。这说明购买、存钱、换货、出售和中途改变组合都真实发生。

## 6. 已否决的试验

| 试验 | 观察 | 结论 |
|---|---|---|
| 开局免费赠送 1 组标签 | 标签更早出现，但前 5 关的有意义出牌下降 | 否决；早期单一标签目标更像明确答案 |
| 位置标签价格 4 降为 3 | 平均购买从约 3.4 组升到 4.6 组，平均推进反而下降 | 否决；便宜只是加重过度投资 |
| 每章首组标签大幅折扣 | 有意义出牌提高，但代理被鼓励继续购买标签，通关率降低 | 否决 |
| 一组标签从 3 枚增到 4 枚 | 选择率上升，但推进没有改善 | 否决；覆盖率不是核心矛盾 |
| 工具牌价格 3 降为 2 | 工具库存上升，实际使用和有意义出牌没有同比增长 | 否决 |
| 道具货架从 2 件增到 3 件 | 通关率降到 3.9%，构筑收敛升到 32.5% | 否决；更多展示不等于更多有效选择 |

## 7. 实现边界

v0.2 只说明这套候选值得进入可玩原型，不等于已经代替正式运行时规则。真正接入时必须同步完成：

1. 正式 JSON 配置、类型、严格校验器和稳定 ID 迁移。
2. Core 中的位置标签实例、商店合法性、购买/出售/换货、道具换位锁定和完整 trace。
3. UI 只播放 Core 结果，不重算同类、异类、标签命中、分数或商店价格。
4. 实机人工体验重点检查“生长标记”是否过早成为必拿，以及成熟阶段 36.6% 的选择率是真正可感知的权衡，还是仅在数学上接近。
5. “复写菌袋”在工具环境的最高单一排列占比为 57.5%，未越过 65% 失败线，但明显高于工具基线 34.0%，需在实机中观察它是否过度鼓励连续同类。
