# 《远行商人》当前 GDD（蘑菇分数传递玩法）

版本：2026-08-03

## 1. 产品概述

《远行商人》是一款轻量构筑爆分游戏。

> 商人用五朵魔法蘑菇编成一道孢子咒。魔法按排列依次穿过每朵蘑菇，逐渐增强，最后由第五朵释放，击破前方阻碍。

玩家从三张蘑菇手牌中持续选择，将五类蘑菇放入 1—5 号位置，让同一个当前分数依次增加或翻倍，最终达到场景的目标分数。

核心决策是：手牌信息不完整时，如何安排同类相接与异类相接的先后，并把位置标签、五件简单道具、工具和商店购买组合成成长与爆发连锁。

玩家规则统一使用“分数、目标分数、蘑菇、同类相接、异类相接”等常见词。当前分数表示孢子魔法的强度；主题包装不代替玩法对象。

## 2. 单轮核心循环

1. 出牌前和出牌过程中，分数区持续显示本轮初始孢子，基础为 10。
2. 蘑菇手牌维持 3 张；打出 1 张补 1 张。工具独立保留，与蘑菇牌合计上限 6 张。
3. 蘑菇按 1—5 号位置落位。第五张落位后，从 1 号位置开始结算。
4. 第 1 朵每次行动使当前分数 `+蘑菇孢子`，基础蘑菇孢子为 10。
5. 2—5 号位置发生同类相接时，每次行动使当前分数 `×2`；发生异类相接时，每次行动使当前分数 `+蘑菇孢子`。
6. 基础、道具、标签和工具提供的行动次数合并计算，每处最多 8 次；此处全部行动结束后再向右传递，不回传、不分批。
7. 5 号位置结束后的当前分数就是本轮得分，并一次性加入本关进度。

## 3. 基础公式

```text
current_score = initial_spores

for slot in 1...5:
  actions = min(8, 1 + 此处额外行动次数)
  repeat actions times:
    if slot == 1: current_score += mushroom_spores
    else if same_type(slot, slot - 1): trigger 同类相接 -> current_score *= 2
    else: trigger 异类相接 -> current_score += mushroom_spores

round_score = current_score after slot 5
```

| 排列 | 运算 | 本轮得分 |
|---|---|---:|
| AAAAA | `(10+10)×2×2×2×2` | 320 |
| ABCDE | `10+10+10+10+10+10` | 60 |
| ABBBC | `10+10+10→×2→×2→+10` | 130 |

不再识别牌型，不求五张蘑菇牌的分数和，不存在独立倍率区、道具向右发送触发或多个分数批次。

## 4. 蘑菇、位置标签、道具与工具

- 五类蘑菇牌各 5 张，没有固定分数或个人能力；种类只用于判断同类相接或异类相接。
- 位置标签绑定具体蘑菇牌。牌上数字与所在位置相同时，普通标签使此处额外行动 1 次，因此会重复此处的同类相接或异类相接规则。
- 正式目录包含 42 件道具：保留原 30 个稳定 ID，并新增 12 件位置标签与商店经济道具。所有单次直接加值都不超过基础数值 10，大分来自成长数值、成长触发次数、位置行动次数和排列的分层放大。
- 当前道具文案必须明确条件、对象、数值和持续时间，不能用“相同时”“每格永久 +20”这类省略对象的句式。
- 一件普通道具不能自动改写多张未来蘑菇牌。旧效果“后两张变成第 3 张”已经废弃。
- 8 张工具用于主动改变一张蘑菇牌、换牌、增加初始孢子、让某处增加行动次数或复制一次明确操作。

## 5. 商店与构筑

- 四章、16 个场景和每关 2 次蘑菇手牌重抽保持不变。简单难度每关最多 5 轮，标准与困难最多 4 轮，详见第 7 节。
- 每个场景过关后进入局内商店：货架包含 2 件道具、1 组位置标签和 1 张工具牌；玩家可以连续购买、出售、换货或直接离开并保留金币。
- 道具可以在每轮出第一张蘑菇前自由换位；第一张落位后，道具位置锁定到本轮结束。
- 同类相接和异类相接只是每次出牌都要使用的两种基础事件，不作为预设流派。构筑结果由玩家实际购买、摆放、出牌、出售和转向后再归纳。
- 商店始终可以直接离开。五个道具位已满时，只有玩家主动购买新道具才进入出售或替换流程。

## 6. UI 与动画

- HUD 只显示一个当前分数区，不显示牌型或倍率区。
- 出牌阶段显示 Core 给出的初始孢子，不从 0 突然开始结算。
- 结算时当前分数跟随正在行动的蘑菇，并限制在 HUD 范围内；旧行动格红色分数不再显示。
- 第 1 个位置结算较慢，之后逐位加速；本位最后一次数值反馈与向右孢子同时发生，二者都完成后才开始下一位。
- 相邻位置使用少量弧形孢子表现量级；`×2` 分两波传递，不按精确分数创建粒子。
- 蘑菇手牌不显示旧的固定分数底板和分数文字。
- 动画时长、衰减、粒子数、弧高、缩放和锚点由 Prefab / Inspector 控制。

## 7. 当前验证状态与下一轮指标

- 原 `250…1,000,000` 单曲线的 0.8% 通关率已降为历史上限验证，不再作为默认难度候选。
- 正式运行时设置简单、标准、困难三档场景目标。首次远行默认简单，通过后再依次解锁标准与困难，不在第一次进入时让玩家先回答难度问题。
- 简单/标准/困难终点分别为 20,000 / 50,000 / 250,000；简单每个场景最多 5 轮，其余两档 4 轮。百万分不再是新手首次通关的强制门槛，而是三档都可追求的超额爆分里程碑。
- 旧模拟按预设同类、异类、混合策略追求胜率，只能作为历史对照，不能证明玩家每次出牌有选择。
- 新模拟的主要指标改为：三档通关率与成熟体验漏斗、有意义出牌率、单件道具导致的排列收敛、最终构筑收敛、商店跳过/换货/出售/转向，以及运行结束后自然形成的构筑组合。
- 正式 42 件道具、商店经济、分层成长和完整模拟结果在 `mushroom-shop-item-catalog-v0.4.md` 中定义；当前重点是实机复核商店决策、标签排列与成熟构筑的体感。

完整规则、设计约束和表现顺序见 `value-pipeline-design-v0.4.md`；主题与玩家用词见 `worldview-naming-ai-handoff.md`；稳定效果和数值仍以运行时 JSON 为准。
