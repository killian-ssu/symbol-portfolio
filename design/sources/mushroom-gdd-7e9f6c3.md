# 《远行商人》当前 GDD（蘑菇触发 + 标签/炫彩 + 局部道具）

版本：2026-08-11（正式 v0.4）

## 1. 一句话玩法

从 3 张蘑菇手牌中连续打出 5 张牌；一段连续同类蘑菇依次触发 1、2、3、4、5 次。玩家把可升级标签和固定炫彩装到具体牌上，再把局部道具放进五格，让所有构筑始终围绕“这张牌在这里触发”生长。

## 2. 单轮循环

1. 蘑菇手牌维持 3 张；打出 1 张后补 1 张。
2. 依次放入第 1—5 格；道具只作用于自己所在格。
3. 第 5 张落位后，从 0 分开始按第 1—5 格结算。
4. 每段同类连段的第 N 张蘑菇基础触发 N 次；换类型后新连段从 1 次重新开始。
5. 炫彩、道具和全局 Buff 可以继续增加蘑菇触发次数，但所有次数只相加、不相乘。
6. 一张蘑菇的所有触发完成后，它的加分、乘分和金币标签各结算 1 次，不跟随蘑菇触发次数重复。
7. 第 5 格结束后的本轮分数加入当前场景进度。

## 3. 基础公式

```text
round_score = 0

for card in cards[1...5]:
  resolved_type = resolve_colorful(card)
  streak = resolved_type == left.resolved_type ? streak + 1 : 1
  triggers = streak
  triggers += fixed_retrigger_colorful(card)
  triggers += additive_local_item_triggers(card, slot)

  repeat triggers times:
    round_score += card.mushroom_score
    apply_local_item_trigger_effect(card, slot)

  apply_add_label_once(card)
  apply_multiply_label_once(card)
  apply_coin_label_once(card)
  apply_after_slot_item_multiplier(card, slot)
```

| 排列 | 触发数 | 初始牌面下本轮得分 |
|---|---|---:|
| ABCDE | `1+1+1+1+1` | 50 |
| ABBCC | `1+1+2+1+2` | 70 |
| AAAAA | `1+2+3+4+5` | 150 |

不同类只是正常触发 1 次，没有“异类相接”事件。合法连锁不设玩法上限；技术看门狗只处理死循环或损坏数据。

## 4. 普通标签与炫彩

| 类别 | ID | 层级/效果 | 容量规则 |
|---|---|---|---|
| 标签 | `score_plus_5` | `+10 / +50 / +200` | 同名再次获得时升级 |
| 标签 | `score_multiply_2` | `×2 / ×2.5 / ×3` | 同名再次获得时升级 |
| 标签 | `coin_plus_1` | 该蘑菇结算后获得 `1 / 2 / 4` 金币 | 同名再次获得时升级 |
| 炫彩 | `retrigger_once` | 固定额外触发 1 次 | 不升级、不递归 |
| 炫彩 | `copy_left_type` | 万能蘑菇，可视为任意一种蘑菇 | 相邻任一侧为它时视为同类；不改变原本颜色 |

标签与炫彩都绑定一张具体牌并跟随它进入手牌、抽牌堆和弃牌堆。每张牌最多 3 种不同标签和 2 种不同炫彩；炫彩不是标签，也不占标签容量。

卡面以两层信息表达：右上角显示这张具体蘑菇当前自身分数；蘑菇下方只显示加分、乘分、金币三个普通标签角标，底图上叠加当前层级数字，三个角标并排时宽度基本等于牌宽。再触发与万能蘑菇不伪装成标签，后续使用独立炫彩效果；卡面摘要只说明当前效果，不重复解释升级流程。

## 5. 局部道具

正式目录共 30 件，分成七类职责：

| 职责 | 目的 | 代表例子 |
|---|---|---|
| 即时规模 | 拿到即可帮助过渡 | 夹心饭团、鱼骨汤 |
| 具体牌/群体成长 | 投资可以被后续道具继续消费的资产 | 乌羽笔、不化冰、偷光镜 |
| 道具自成长 | 少量可替换会损失的局部养成 | 温玉、旧蓑衣、破斗笠 |
| 触发转换 | 把同类、标签、炫彩或蘑菇分数变成额外触发 | 引路灯、余烬炉、酒葫芦 |
| 分数兑现 | 把已成长的牌和触发次数放大为爆分 | 蜜烤鸡、桌上春、灰信鸽 |
| 标签接口 | 让标签/炫彩与格子构筑相连 | 月之眼、消散叶 |
| 经济支持 | 增加购买和换货机会 | 浮石、海边灯塔 |

道具名只负责把它塑造成一件容易记住的东西，不负责复述效果。命名优先跟随图标，允许食物、旅途小物和奇物混杂；规则对象与数值全部留在效果文案中，不再用大量重复的“孢囊、培养皿、年轮、弹簧、回声”硬接功能。

培养类效果把成长永久写入 25 张具体牌。更换培养道具后，牌上已获得的分数不会消失；只有少数明确写着“此道具”的自成长会随道具被替换而离场。这保证了前期投资能够接到中后期兑现件。

所有触发道具都只做加法。例如：

- 引路灯：此格有再触发炫彩时，额外触发 1 次。
- 余烬炉：此格有 3 枚普通标签时，额外触发 2 次。
- 消散叶：此格有任意炫彩时，额外触发 1 次。

不存在“触发次数×2”的道具。

## 6. 商店与成型过渡

- 前三章第 1—5 个战斗场景完成后都开启普通商店，固定展示 2 件道具和 2 个卡牌强化；第四章第 1—4 关后同样开启，最终 Boss 后直接胜利。工具牌不进入正常商店。
- 加分与金币标签一次购买后直接随机安装到 3 张合法蘑菇，不再进入“点任意一张确认三张”的伪选择；表现上仍从牌库飞出这 3 张具体牌，逐张盖下标签后倒序收回。乘分标签和两种炫彩仍从 3 张候选中选 1 张。
- 单张卡牌强化才从完整 25 张牌库抽出 3 张合法候选，在主界面屏幕中央的独立候选区放大并高亮；底部手牌区不承载此次选择，安装后回到牌库并返回同一商店。
- 玩家可从局内牌库入口随时检查全部 25 张具体牌；同类牌不合并，每张牌分别显示自身长期分数、普通标签和炫彩。牌库从入口错峰展开，关闭时倒序收回。
- 商店卡常驻只显示商品图标与金币按钮；点击图标或长按后在该商品下方展开较大的名称和说明气泡，标题约 35、说明约 25。说明正文统一左对齐并保持一段连续短文，不用手工换行拆成安装说明与效果说明；加分、乘分、金币、永久/成长/额外沿用各自语义色。道具当前三档稀有度的标题依次使用绿/蓝/金；标签与炫彩使用默认标题色。一次安装 3 张的标签用三枚小角标叠放表达，两种炫彩也必须展示配置中的代表图标。商店阶段隐藏剩余探索回合，但保留牌库入口供核对构筑。
- 金币余额由游戏界面顶部 HUD 常驻显示，商店换货处只显示本次换货价格。结算分数区固定在原 HUD 位置，不再随 1—5 格移动。
- 完整随机远行开场获得 4 金币；首次五路段教程为保证三间指定商店的标准价格链，单独从 5 金币开始。第 1—4 章的战斗过关收入依次为 3/4/5/6 金币，Boss 额外获得 3 金币。凡是局内加金币，先弹黄色 `+N金币`，随后爆出预制金币粒子并逐枚飞入金币 HUD，余额随抵达实时增加；每次播放都从 Prefab 保存的金币粒子尺寸开始，抵达时缩小不得污染下一次播放。不再显示“过关金币”句子。高价道具仍需储蓄、金币标签、出售或经济道具支持。
- 计分反馈统一使用语义颜色：蘑菇自身普通加分为白色，标签/道具/全局效果的额外加分为绿色，金币为黄色，乘分为红色。商店摘要使用相同颜色标记关键数值，并用斜体/强调色突出“永久、额外”等关键词。
- 同一格的结算反馈必须按 Core 事件顺序逐条弹出，不把多个数字成组叠放。例如每次触发都同时有蘑菇自身分与额外分时，多次触发应呈现“白→绿→白→绿”。后续格可逐渐加快，但不得改变因果顺序。
- 单张安装的乘分标签升级时，候选中保底出现至少 1 张可升级载体；3 张批量标签优先覆盖还没有该标签的蘑菇，再进入升级。
- 每章保留一格道具随机位和一格卡牌强化随机位，同时各用一格做结构保护：
  - 第 1 章：即时种子、公共/道具成长，加分或金币标签。
  - 第 2 章：成长接触发，加分标签或再触发炫彩。
  - 第 3 章：触发接兑现，乘分标签进入保护位。
  - 第 4 章：稳定出现兑现件与乘分标签。

保护位只保证“能搭桥的职责会出现”，不保证指定套装，也不根据玩家低分暗中发完整答案。

## 7. 终页特别状况

- 每章开始时从该章 5 条状况中抽取并公开 1 条；前四关只供准备，第 5 关才持续生效。
- 特别状况没有“派指定颜色 4—6 张”的应对任务、解除进度或额外应对回合。三回合本来就用于组织得分，Boss 不再用抽牌运气要求玩家完成第二套目标。
- 20 条规则只改变当前玩法本来就存在的价值：位置触发、同类额外触发、标签、局部道具、位置顺序或目标倍率。规则必须由 `PipelineEngine/BossRuleManager` 实际执行，不能只显示文案。
- Boss UI 只显示持续生效的负面规则；旧 `BossResponseBlock` 对当前规则整体隐藏。前三章 Boss 通过后照常获得金币并进入商店，最终 Boss 后直接结算胜利。
- 章初见闻弹窗保持轻量，只显示章节名称、“第五路段 · Boss 规则名”和一句规则；不再补充“全程生效、目标不变、终页应对”等无决策信息。

## 8. 目标曲线与爆分边界

| 难度 | 最多探索轮数 | 最终目标 |
|---|---:|---:|
| 简单 | 3 | 700,000 |
| 标准 | 3 | 1,000,000 |
| 困难 | 3 | 2,000,000 |

四章每章 5 个场景，共 20 关。每章前 4 关为普通路段，第 5 关是终页；终页通过后所有蘑菇分数自动永久 +1。目标体验是：前期靠同类连段就能看到增长，中期让永久资产成形，后期用触发和倍率爆分。标准最终目标为百万，一亿属于极端观察线；正常局不应被迫进入科学计数法。

自动测试已覆盖 1/2/3/4/5 连段触发、标签一次结算、20 关推进、前三章 Boss 后商店、批量直接安装、持续 Boss 规则、信条、奇遇代价与 v4 快照。目标数组仍是首轮实机校准值；后续应重点记录每章购买数、被标签的具体牌数、各关通过轮数和第 4 章单轮分布，不只看极端最高分。

`npm run sim:opening` 使用当前 `PipelineEngine` 做 50,000 组无构筑开局样本：主动追同类时，旧规则单轮均值/P90 为 `68.6/80`，当前连段规则为 `72.5/90`，五连上限由 `90` 提到 `150`。简单第 1 关与标准第 1 关在无构筑样本中稳定通过；标准第 2 关完全不购物时，主动追连段约 `50.6%` 通过，说明第 1 关后的商店是预期中的首个构筑节点。该脚本只诊断开局基础规则，不代替带 30 件道具和真实购买决策的全局胜率校准。

## 10. 新手教程与第二次远行

- 新档读取完成后直接进入固定简单、无信条和见闻的五路段首次流程。第 1 路段通关就立即把档案转为“扶持远行”，但已开始的本次流程仍按冻结配置走完第一章的 5 条直路，不在途中插入岔路。只有在第 1 路段内失败才保留本局金币、道具和标签并重试原关；通过后的任何失败都正常结算，下次不再重播开场教学。第 5 路段胜利即结束首次流程，教学完成界面只保留居中的“返回驿站”；返回后驿站会引导玩家点击“开始远行”，再进入第二次扶持远行，不进入第一局的商店或第二章。
- 第一关固定真实红/蓝/绿三张牌，手指点击中间蓝牌。第一张蓝牌落位后，统一羊皮纸规则弹窗依次演示“从左到右，依次释放”和“同类相接，递增释放”。之后 Core 连续补入两张真实蓝牌，前三格只接受蓝牌；三连完成后再固定补入两张非蓝牌，最后两格完全放开。规则弹窗使用实际木桩格、蘑菇图标和局内爆分数字组件；Photoshop 参考图不进入运行时。
- 前三间教程商店使用标准 2 件道具 + 2 种标签货架，指定必买顺序改为“夹心饭团 → 乌羽笔 → 加分标签”，以正式 5、5、4 金价格形成 `8→3、6→1、4→0`。其他三件商品保持可见，指定购买完成前不可购买、换货或离店。手指先指向指定商品并打开详情；详情出现后下一次点击任意位置只关闭详情，随后手指移到真实购买按钮。首店购买后还会单独指向右下角“离开商店”。前两次购买提示标题为“购买道具”，第三次为“购买标签”；第三店操作文案为“购买加分标签，让3张蘑菇获得额外力量。”第二间离开后立即强制把第 1 格夹心饭团拖到第 2 格，让乌羽笔提前在第 1 格成长；交换完成后立即结束该段遮罩和操作提示，不再出现“观察连锁”弹窗，也不锁定随后必须先出某种颜色。从第 2 路段开始只连续扶持三波：每波从真实牌库随机组成“二同色 + 一异色”的混合手牌，玩家打出第一张后只追加 1—2 张同色牌，之后恢复普通随机；选择手中对子通常可自然形成三连，拿到两张续牌时可冲四连，但脚本不会把整手或后续五张都改成同色。购买加分标签后的下一路段仍保证混合手牌的对子中至少有一张真实已贴标签牌。第 5 路段是唯一专用教学例外：先从真实牌库给出 3 张蓝蘑菇，连续补入第 4 张蓝蘑菇；第 4 张打出后可见手牌清空，此时才显示不遮挡行动格的“刷新手牌”提示，手指紧贴右下真实刷新按钮。刷新消耗 1 次真实次数并保证抽到仅 1 张蓝蘑菇，再引导打出该牌完成五同类；第 5 张一打出，操作窗口必须在结算表演前立即消失。这个例外只用于首次教程第 5 路段，不扩散到其他手牌或后续远行。
- 第二次远行固定简单难度和信条“同行”，开放完整见闻与 Boss 状况；每章第 1 路段为直路，第 2 路段固定给出一次真实岔路，因此玩家在第二次远行的第 2 路段首次遇到岔路。每间普通商店仍是 2 道具 + 2 标签，只占用其中各 1 格顺序提供“乌羽笔→酒葫芦→不化冰→老抓钩→偷光镜→灰信鸽→桌上春→暖陶碗”和“金币→加分→万能→再触发→乘分”。每个目标购买、过期或出现 3 次后推进；奇遇商店缺少对应格时顺延。进入第四章后清除扶持阶段；提前失败则下局继续扶持。
- `npm run sim:guided` 使用不少于 2,000 个固定种子和同类优先/合理购买策略校验第二轮。验收线是第四章到达率≥85%、曾出现单轮 3 万分的样本≥80%，且不设强制失败、不暗改目标或坏牌。当前正式数值尚未通过该门槛；在完成后续数值决策前，不应把模拟目标写成已达成，也不应在 UI 层暗加分。
