# 《远行商人》游戏策划案

版本：MVP v0.1  
日期：2026-05-19  
目标平台：微信小游戏  
开发引擎：Cocos Creator  
类型：竖屏 / 轻量 Roguelike 构筑 / 牌型结算 / 数值连锁

---

## 1. 项目定位

《远行商人》是一款适合微信小游戏场景的竖屏轻量策略 Roguelike 游戏。

玩家扮演一名远行商人，在一场神秘旅途中通过探索、采集、开矿、搜罗、交易等行动积累盘缠。玩家不需要真正攻击敌人，而是在每个神秘场景中完成盘缠目标，穿过山神、树影、狐火、海雾等异象关隘。

核心体验目标：

- 低认知负担：每次只有 3 张手牌，5 个行动格，玩家能快速理解。
- 短局爽感：单局约 10-15 分钟，适合微信小游戏。
- 构筑乐趣：每小关后 3 选 1 强化，形成不同流派。
- 连锁爆发：通过道具、工具牌、同源牌型产生数值爆发。
- 东方神秘商旅气质：不是战斗打怪，而是远行、献礼、交易、穿越异象。

## 2. 设计原则

### 2.1 首版必须简化

MVP 阶段不做以下系统：

- 不做金币经济。
- 不做商店购买。
- 不做路线选择。
- 不做基础牌点数。
- 不做复杂负面牌库。
- 不做局外成长。
- 不做每关独立新场景。

首版聚焦：

- 5 种货源牌。
- 5 格行动区。
- 3 手牌。
- 4 章 16 小关。
- 每小关最多 4 次探索。
- 每关后 3 选 1 构筑奖励。
- 工具牌与道具连锁。

### 2.2 玩家每局主要做三类决策

1. 当前手牌怎么打，是否刷新。
2. 如何凑出更高倍率牌型。
3. 过关奖励选哪一个构筑方向。

### 2.3 不是战斗，是通过关隘

游戏中不使用“攻击”“伤害”“敌人血量”等强战斗表达。

建议使用：

- 盘缠目标
- 探索轮
- 路段
- 场景
- 异象
- 随身物
- 货源牌
- 工具牌

## 3. 核心术语

| 术语 | 含义 |
|---|---|
| 货源牌 | 基础牌，打入行动格参与结算 |
| 工具牌 | 一次性功能牌，不占行动格 |
| 行动格 | 中部 5 个出牌格 |
| 探索轮 | 打满 5 个行动格并结算一次 |
| 盘缠 | 当前关卡累计得分 |
| 盘缠目标 | 当前小关需要达到的目标分 |
| 随身物 | 类似遗物/小丑牌的全局或格子道具 |
| 底座道具 | 绑定在某个行动格上的道具 |
| 同源 | 多张货源牌颜色/类型相同 |
| 路段 | 16 个小关中的一个 |
| 章节 | 4 个大场景之一 |

## 4. 单局结构

单局共 16 个路段，分为 4 章，每章 4 个路段。

一整局只有 4 个主要场景：

| 章节 | 场景名 | 路段 1-3 | 路段 4 |
|---|---|---|---|
| 第 1 章 | 山神索礼 | 普通目标递增 | 山神 Boss 规则 |
| 第 2 章 | 树影客栈 | 普通目标递增 | 树影 Boss 规则 |
| 第 3 章 | 狐火渡口 | 普通目标递增 | 狐火 Boss 规则 |
| 第 4 章 | 海雾集市 | 普通目标递增 | 海雾 Boss 规则 |

每个路段通过后，立即进入一次 3 选 1 构筑奖励，然后自动进入下一个路段。

不做商店，不做选路，不做金币奖励。

## 5. 单关流程

每个路段最多进行 4 次探索轮。

流程：

1. 进入路段，显示当前场景、盘缠目标、探索次数。
2. 玩家抽 3 张手牌。
3. 玩家将货源牌打入 5 个行动格。
4. 工具牌可直接使用，不占行动格。
5. 手牌少于 3 张时自动补满。
6. 5 个行动格填满后，自动结算一次探索轮。
7. 结算后累计盘缠。
8. 如果盘缠达到目标，立即通关。
9. 如果未达到目标，并且探索轮未用完，进入下一探索轮。
10. 如果 4 次探索轮结束仍未达到目标，则本局失败。

关键规则：

- 达到盘缠目标后立即过关，不需要打完 4 次探索。
- 每个路段固定 2 次刷新机会。
- 刷新只替换手牌，不清空行动格。
- 刷新不消耗任何货币。

UI 推荐显示：

```text
第1章 山神索礼
第3路段
盘缠 320 / 500
探索 2 / 4
刷新 1 / 2
```

## 6. 货源牌

货源牌是基础牌，负责打入 5 个行动格，形成同源牌型并产生盘缠。

首版共有 5 种货源：

| 货源 | 颜色 | 图标方向 | 含义 |
|---|---|---|---|
| 探路 | 青色 | 罗盘 / 脚印 | 找路、发现、开图 |
| 采集 | 绿色 | 叶子 / 草药 | 草药、木材、果实 |
| 开矿 | 金色 | 矿镐 / 矿石 | 矿石、盐、玉石 |
| 搜罗 | 紫色 | 旧罐 / 眼睛 | 古物、遗物、奇货 |
| 交易 | 红色 | 铜钱 / 握手 | 买卖、议价、换货 |

### 6.1 基础收益

首版不做点数。所有货源牌初始收益相同：

```text
每张货源牌基础收益 = 10
```

后续通过构筑强化改变不同货源的收益。

例如：

- 探路基础收益 +2。
- 所有交易牌基础收益 +3。
- 打在第 3 格的采集牌收益翻倍。
- 开矿牌在三同源及以上时额外 +2。

### 6.2 初始牌库

MVP 建议初始牌库为：

| 货源 | 数量 |
|---|---:|
| 探路 | 5 |
| 采集 | 5 |
| 开矿 | 5 |
| 搜罗 | 5 |
| 交易 | 5 |

合计 25 张货源牌。

工具牌通过关后奖励加入牌库。

## 7. 牌型系统

牌型只看货源类型，不看点数。

牌型命名优先直观，让玩家立刻理解“同色越多越强”。

| 牌型 | 条件 | 倍率 |
|---|---|---:|
| 五同源 | 5 张同货源 | x5 |
| 四同源 | 4 张同货源 | x3 |
| 三同源 | 3 张同货源 | x2 |
| 双同源 | 2+2 同货源 | x2 |
| 五源齐备 | 5 种货源各 1 张 | x3 |
| 散货 | 不满足以上 | x1 |

识别优先级建议：

1. 五同源
2. 五源齐备
3. 四同源
4. 三同源
5. 双同源
6. 散货

说明：

- 五源齐备是一个独立流派，用来避免玩法只追求单色。
- 双同源指 5 张牌中出现两个对子，例如 2 探路 + 2 交易 + 1 开矿。
- 如果后续出现特殊道具，可以让某些牌型同时视为另一个牌型。

## 8. 结算公式

首版结算公式：

```text
本轮收益 = 5 张货源牌收益总和 x 牌型倍率 x 道具倍率
```

其中：

- 货源牌收益包含基础收益、货源强化、格子强化、工具牌标签。
- 牌型倍率由牌型决定。
- 道具倍率由随身物触发决定。

示例 1：五同源

```text
5 张开矿
每张开矿收益 10
基础收益总和 = 50
牌型 = 五同源 x5
本轮收益 = 50 x 5 = 250
```

示例 2：工具牌加价印

```text
探路 10
采集 10
开矿 10，贴有 x2 标签，所以计算为 20
搜罗 10
交易 10
基础收益总和 = 60
牌型 = 五源齐备 x3
本轮收益 = 60 x 3 = 180
```

示例 3：道具加成

```text
基础收益总和 = 50
牌型 = 三同源 x2
道具倍率 = x1.5
本轮收益 = 50 x 2 x 1.5 = 150
```

## 9. 手牌与刷新

### 9.1 手牌规则

- 手牌上限：3。
- 打出 1 张货源牌后，如果手牌少于 3，立即从牌库补 1 张。
- 使用 1 张工具牌后，如果手牌少于 3，也立即补 1 张。
- 牌库抽空时，弃牌堆洗回牌库。

### 9.2 刷新规则

- 每个路段固定 2 次刷新。
- 刷新会弃掉当前手牌，并重新抽到 3 张。
- 刷新不会清空已放入行动格的牌。
- 刷新不消耗金币或资源。
- 道具可以增加刷新次数或强化刷新后的手牌。

## 10. 工具牌

工具牌是功能牌，不占行动格，使用后进入弃牌堆。

MVP 先做 3 张工具牌。

| 工具牌 | 效果 | 设计目的 |
|---|---|---|
| 染货布 | 选择 1 张货源牌，将其改成指定货源 | 帮助凑同源牌型 |
| 加价印 | 选择 1 张货源牌，贴上 x2 标签，本次探索轮结算时该牌收益翻倍 | 制造单牌爆发 |
| 空货箱 | 复制 1 张手牌中的货源牌，加入手牌 | 提高构筑稳定性 |

### 10.1 工具牌使用细则

染货布：

- 可选择手牌中的货源牌。
- 可选择已经放入行动格的货源牌。
- 不能选择工具牌。
- 改变货源后立即刷新牌型预览。

加价印：

- 可选择手牌中的货源牌。
- 可选择已经放入行动格的货源牌。
- 目标牌获得本轮有效的 x2 标签。
- 结算后标签消失。

空货箱：

- 只能复制手牌中的货源牌。
- 复制出来的牌保留当前货源类型。
- 如果复制目标带有临时 x2 标签，默认不复制临时标签。
- 复制牌加入手牌，如果手牌超过 3，可以临时允许到 4 张，直到玩家打出或使用一张牌。

## 11. 行动格与道具底座

界面中部有 5 个行动格。

每个行动格既是出牌位置，也是一个道具底座。

这让《远行商人》的道具系统相比传统遗物有更多空间：

- 有些道具影响全局。
- 有些道具只影响所在格。
- 有些道具影响相邻格。
- 有些道具复制其他格子的道具效果。
- 有些 Boss 规则会压制某个格子。

行动格编号：

```text
格1  格2  格3  格4  格5
```

建议在代码中将格子编号固定为 `0-4`。

## 12. 随身物系统

随身物是本作的核心构筑系统，类似遗物或小丑牌，但结合 5 个行动格底座。

随身物分两类：

| 类型 | 说明 |
|---|---|
| 全局随身物 | 不绑定格子，影响整局规则或结算 |
| 底座随身物 | 绑定在某个行动格，只在该格或相邻格触发 |

### 12.1 MVP 随身物列表

| 名称 | 类型 | 效果 |
|---|---|---|
| 旧罗盘 | 底座 | 本格打出探路牌时，该牌收益 x2 |
| 药草袋 | 全局 | 所有采集牌基础收益 +3 |
| 矿灯 | 全局 | 每张开矿牌收益 +2；若本轮为三同源及以上，额外再 +2 |
| 破货架 | 底座 | 本格与任一相邻格同源时，两张牌收益各 +5 |
| 红算盘 | 全局 | 每次形成交易牌三同源及以上，本轮倍率 +0.5 |
| 旧货铃 | 全局 | 每使用 1 张工具牌，本轮收益 +10 |
| 双层箱 | 底座 | 本格货源牌收益计算两次 |
| 狐火灯 | 全局 | 每次刷新后，新手牌中第一张货源牌自动贴 x2 标签 |
| 海市镜 | 底座 | 结算时复制左侧相邻底座道具的触发效果 |
| 山神符 | 全局 | 每章 Boss 关第一次负面效果无效 |
| 旅人靴 | 全局 | 每个路段刷新次数 +1 |
| 百色绳 | 全局 | 五源齐备倍率 +1 |
| 同源牌匣 | 全局 | 三同源、四同源、五同源倍率各 +0.5 |
| 中格铜印 | 底座 | 第 3 格的牌收益 x2 |
| 货郎旗 | 全局 | 每次探索轮开始，随机 1 张手牌基础收益 +5 |

### 12.2 道具触发时机

建议统一为以下触发时机：

| 时机 | 说明 |
|---|---|
| onRoundStart | 探索轮开始 |
| onCardPlaced | 货源牌放入行动格 |
| onToolUsed | 工具牌使用 |
| beforeScore | 结算计算前 |
| onScore | 结算过程中 |
| afterScore | 结算结束后 |
| onRefresh | 手牌刷新后 |

### 12.3 道具位规则

- 最多持有 5 个随身物。
- 底座随身物必须放在某个行动格上。
- 全局随身物也占用 1 个随身物位，但不绑定具体格子。
- 如果道具位已满，获得新道具时进入替换界面。
- 替换时，被替换的道具永久移出本局。

## 13. Boss 负面机制

负面机制只出现在每章第 4 个路段。

不做常驻负面牌库，避免首版复杂度过高。

| 场景 | Boss 规则 | 设计目的 |
|---|---|---|
| 山神索礼 | 每次探索轮开始，随机 1 个行动格被“山印”压住，该格牌收益减半 | 让玩家注意格子位置 |
| 树影客栈 | 每次探索轮中，第 5 张打出的牌被“树影”遮住，只计算收益，不参与牌型 | 打乱凑牌型节奏 |
| 狐火渡口 | 每次探索轮开始，随机指定 1 种货源为“狐火”，该货源本轮收益减半，但仍参与牌型 | 让玩家临时调整目标颜色 |
| 海雾集市 | 每次结算前，随机 1 张已打出的货源牌变为随机货源 | 检验改色与稳定性构筑 |

### 13.1 Boss 规则显示

Boss 路段 UI 需要显示一条短规则：

```text
山印：每轮一格收益减半
树影：第5张牌不参与牌型
狐火：随机货源收益减半
海雾：结算前随机变色
```

Boss 规则不需要长文本，点击规则标签后可弹出详细说明。

## 14. 三选一构筑奖励

每个路段通关后，出现 3 个奖励选项。

奖励池由三类组成：

1. 货源强化
2. 工具牌
3. 随身物

### 14.1 货源强化奖励

| 奖励 | 效果 |
|---|---|
| 探路熟练 | 探路基础收益 +2 |
| 采集熟练 | 采集基础收益 +2 |
| 开矿熟练 | 开矿基础收益 +2 |
| 搜罗熟练 | 搜罗基础收益 +2 |
| 交易熟练 | 交易基础收益 +2 |
| 广见闻 | 随机 2 种货源基础收益 +1 |
| 专精 | 选择 1 种货源基础收益 +3 |

### 14.2 工具牌奖励

| 奖励 | 效果 |
|---|---|
| 获得染货布 | 将 1 张染货布加入牌库 |
| 获得加价印 | 将 1 张加价印加入牌库 |
| 获得空货箱 | 将 1 张空货箱加入牌库 |

### 14.3 随身物奖励

| 奖励 | 效果 |
|---|---|
| 获得普通随身物 | 从普通随身物池中随机 1 个 |
| 获得稀有随身物 | 从稀有随身物池中随机 1 个 |
| 替换随身物 | 选择 1 个已有随身物替换为新随身物 |
| 升级随身物 | 选择 1 个已有随身物强化效果 |

MVP 阶段可以先不做稀有度，只做统一随机池。

## 16. 流派方向

### 16.1 同源爆发流

核心：

- 追求三同源、四同源、五同源。
- 通过染货布、空货箱和同源牌匣提高稳定性。

关键组件：

- 染货布
- 空货箱
- 同源牌匣
- 破货架
- 矿灯

体验：

- 简单直接，适合新手。
- 凑出五同源时反馈强。

### 16.2 五源齐备流

核心：

- 追求 5 种货源各 1 张。
- 稳定触发 x3 或更高倍率。

关键组件：

- 百色绳
- 染货布
- 旧罗盘
- 旅人靴

体验：

- 看似杂色，实际稳定。
- 能和工具牌、刷新构筑结合。

### 16.3 工具连锁流

核心：

- 多使用工具牌。
- 用工具牌触发随身物收益。

关键组件：

- 旧货铃
- 加价印
- 空货箱
- 狐火灯

体验：

- 玩家会在结算前先进行一连串操作。
- 适合制造“这轮爆了”的感觉。

### 16.4 格子构筑流

核心：

- 利用底座道具和行动格位置。
- 让某些格子变成高收益格。

关键组件：

- 双层箱
- 中格铜印
- 海市镜
- 旧罗盘
- 破货架

体验：

- 有一定策略深度。
- 是本作和同类牌型游戏区分开的重点。

## 17. UI 布局

游戏为竖屏界面。

### 17.1 顶部区域

显示：

- 游戏名或章节名。
- 当前章节与路段。
- 盘缠目标进度。
- 探索次数。
- 刷新次数。

示例：

```text
远行商人
第1章 山神索礼
盘缠 320 / 500
探索 2 / 4
刷新 1 / 2
```

### 17.2 中上场景区域

显示：

- 当前场景插画。
- 场景名称。
- Boss 规则标签。

普通路段场景表现可以保持一致，仅目标数值递增。

Boss 路段增加特殊动效或视觉压迫：

- 山神索礼：石印、山雾。
- 树影客栈：影子、灯火。
- 狐火渡口：蓝绿狐火、水面。
- 海雾集市：雾、错位摊位。

### 17.3 中部行动区

显示 5 个行动格。

每个行动格：

- 可拖入货源牌。
- 显示绑定随身物。
- 显示临时状态，例如山印、树影、x2。
- 可点击查看详情。

### 17.4 底部手牌区

显示：

- 3 张手牌，扇形或横向展开。
- 中间刷新按钮。
- 左下牌库按钮。
- 右下牌型按钮。

按钮：

```text
牌库
刷新
牌型
```

### 17.5 结算表现

结算反馈顺序：

1. 显示牌型名称。
2. 显示货源收益总和。
3. 显示牌型倍率。
4. 逐个触发随身物。
5. 显示最终盘缠增加值。
6. 更新盘缠进度条。

示例：

```text
三同源 x2
货源收益 62
旧货铃 +10
本轮盘缠 +134
```

- 东方民俗
- 商旅远行
- 神秘但不恐怖
- 旧纸、墨线、铜器、木纹
- 温暖手绘质感
- 卡牌仪式感

可以参考的气质方向：

- 《苏丹的游戏》的卡牌仪式感、旧纸和神秘质感。

## 22. 首轮验证目标

原型阶段需要重点验证：

1. 玩家是否能在 30 秒内理解“打满 5 格结算”。
2. 3 手牌是否足够轻量，又不至于无聊。
3. 5 同源、五源齐备是否都能形成流派。
4. 工具牌是否能明显提高玩家掌控感。
5. 道具底座是否带来了区别于同类游戏的策略感。
6. 每小关 3 选 1 是否比商店更适合微信小游戏节奏。
7. 单局是否能控制在 10-15 分钟。
8. 第 8 路段前是否能形成初步构筑。
9. 第 12 路段后是否开始出现连锁爆发。
10. 第 16 路段是否能成为一次爽感检验。

## 23. 一局体验示例

第 1 路段：

- 玩家进入山神索礼。
- 目标盘缠 160。
- 玩家通过三同源和散货两次探索达到目标。
- 过关后获得 3 选 1：探路收益 +2 / 获得染货布 / 获得旧罗盘。

第 2 路段：

- 玩家选择旧罗盘。
- 旧罗盘绑定到第 1 格。
- 第 1 格打出探路牌收益 x2。
- 玩家开始有意识地把探路牌放到第 1 格。

第 4 路段 Boss：

- 山神索礼 Boss 出现山印。
- 每轮随机一个行动格收益减半。
- 玩家需要避开山印格，或者用工具牌调整收益。

第 8 路段：

- 玩家已经拥有 2-3 个随身物。
- 染货布和空货箱帮助凑出四同源。
- 结算开始出现明显爆发。

第 16 路段：

- 玩家构筑成型。
- 海雾随机变色干扰最终牌型。
- 如果玩家拥有染货布、百色绳、同源牌匣等构筑，可以稳定冲过最终目标。

## 24. 当前版本结论

《远行商人》MVP 的核心不是复杂牌库，而是：

```text
3 手牌轻决策
+ 5 格探索轮
+ 同源牌型倍率
+ 工具牌微调
+ 随身物连锁
+ 每关 3 选 1 构筑
= 微信小游戏可接受的轻量肉鸽爽感
```

首版开发应优先完成可玩闭环，而不是追求内容量。

最小可验证版本只需要：

- 色块牌
- 5 个行动格
- 简单结算
- 3 张工具牌
- 10-15 个随身物
- 16 个目标数值

只要这个版本能让玩家在第 5-8 路段开始期待“下一次 3 选 1 会不会让我爆起来”，核心方向就是成立的。
